Gerenciamento de dependências

Nesta aula, você vai aprender como gerenciar as dependências de um projeto Python. Vamos entender como utilizar o arquivo requirements.txt, instalar pacotes e controlar as versões das bibliotecas utilizadas pelo projeto.

O gerenciamento de dependências é essencial em projetos profissionais, principalmente em automação de testes, pois garante que diferentes ambientes utilizem versões compatíveis das mesmas bibliotecas.

💡 Para lembrar:

Uma dependência é uma biblioteca ou pacote externo que o seu projeto precisa para funcionar.

O gerenciamento dessas dependências permite saber o que está instalado, qual versão está sendo utilizada e como reproduzir o ambiente em outro computador.

📦 O que são dependências?

Quando criamos um projeto Python, muitas vezes precisamos utilizar bibliotecas que não fazem parte diretamente do código que escrevemos.

Por exemplo, um projeto de automação de testes pode utilizar bibliotecas como:

  • pytest — execução de testes.
  • requests — comunicação HTTP.
  • selenium — automação de navegadores.

Essas bibliotecas são dependências do projeto.

💡 Exemplo:

Se um teste utiliza pytest, o projeto depende do pytest para executar aquele teste.

📥 Instalação de pacotes

O pip é utilizado para instalar pacotes Python. Podemos instalar uma biblioteca utilizando:

Terminal
1
python -m pip install requests

Nesse exemplo, o pacote requests será instalado no ambiente Python atualmente utilizado.

Também podemos instalar vários pacotes de uma vez:

Terminal
1
python -m pip install pytest requests
💡 Boa prática:

Utilize python -m pip para garantir que o pip utilizado está associado ao interpretador Python desejado.

📄 requirements.txt

O arquivo requirements.txt é utilizado para registrar as dependências de um projeto Python.

Um exemplo de arquivo pode ser:

requirements.txt
1
2
3
pytest==8.4.1
requests==2.32.4
selenium==4.34.2

Cada linha representa uma dependência que o projeto precisa. Neste exemplo, também estamos especificando a versão de cada biblioteca.

🔢 Versionamento de pacotes

Bibliotecas Python possuem versões. Por exemplo:

exemplos.txt
1
2
3
requests==2.32.4
requests>=2.30.0
requests<3.0.0

Podemos utilizar diferentes operadores para definir quais versões são aceitas.

  • == — versão exata.
  • >= — versão maior ou igual.
  • <= — versão menor ou igual.
  • > — versão maior.
  • < — versão menor.
💡 Exemplo:

requests==2.32.4 significa que o projeto deve utilizar exatamente a versão 2.32.4.

🧩 Major, Minor e Patch

Muitas bibliotecas utilizam um padrão de versionamento conhecido como Versionamento Semântico.

Uma versão como:

versão.txt
1
2.32.4

pode ser dividida conceitualmente em:

  • 2 — Major.
  • 32 — Minor.
  • 4 — Patch.
💡 Atenção:

Uma mudança de versão major pode indicar alterações incompatíveis.

Alterações minor normalmente adicionam funcionalidades mantendo compatibilidade.

Alterações patch geralmente estão relacionadas a correções e ajustes.

📋 Listando pacotes instalados

Podemos verificar quais pacotes estão instalados utilizando:

Terminal
1
python -m pip list

Também podemos consultar informações específicas sobre um pacote:

Terminal
1
python -m pip show requests

❄️ pip freeze

O comando pip freeze mostra os pacotes instalados junto com suas versões.

Terminal
1
2
3
pytest==8.4.1
requests==2.32.4
selenium==4.34.2

Podemos redirecionar essa saída diretamente para um arquivo:

Terminal
1
python -m pip freeze > requirements.txt

📥 Instalando todas as dependências

Quando recebemos um projeto que possui um requirements.txt, não precisamos instalar cada pacote manualmente.

Podemos instalar todas as dependências utilizando:

Terminal
1
python -m pip install -r requirements.txt
💡 Na prática:

Esse comando é muito útil quando outro desenvolvedor ou QA precisa configurar o projeto em uma nova máquina.

🔄 Atualizando pacotes

Podemos atualizar um pacote utilizando:

Terminal
1
python -m pip install --upgrade requests

Depois de atualizar uma dependência, é importante revisar o ambiente e, quando apropriado, atualizar o arquivo de dependências utilizado pelo projeto.

🗑️ Removendo pacotes

Para remover uma biblioteca:

Terminal
1
python -m pip uninstall requests

🧪 Dependências em projetos de QA

Em automação de testes, o gerenciamento de dependências ajuda a manter o ambiente previsível.

Por exemplo, podemos ter um projeto com:

requirements.txt
1
2
3
pytest==8.4.1
requests==2.32.4
selenium==4.34.2

Dessa maneira, quando outro QA configurar o projeto, poderá instalar as mesmas dependências utilizando um único comando.

✅ Boas práticas

Para manter o projeto organizado:

• Utilize ambientes virtuais.
• Registre as dependências do projeto.
• Controle as versões das bibliotecas quando necessário.
• Evite instalar pacotes desnecessários.
• Revise dependências antes de atualizá-las.
• Mantenha o arquivo de dependências atualizado.
• Não versione a pasta .venv no Git.

🚀 Desafio

Crie um projeto Python chamado projeto_dependencias e pratique o gerenciamento de pacotes.

🎯 Requisitos:

• Crie e ative um ambiente virtual.
• Instale o pytest.
• Instale o requests.
• Verifique os pacotes instalados com pip list.
• Consulte informações do requests com pip show.
• Gere um requirements.txt.
• Confira as versões registradas no arquivo.
• Remova o requests.
• Reinstale as dependências utilizando requirements.txt.
• Verifique novamente os pacotes instalados.

🧠 Resumo da aula

O que você aprendeu:

• Dependências são bibliotecas necessárias para o funcionamento de um projeto.
• pip install instala pacotes Python.
• pip uninstall remove pacotes.
• pip list mostra os pacotes instalados.
• pip show apresenta informações sobre um pacote.
• pip freeze lista os pacotes com suas versões.
• requirements.txt registra as dependências do projeto.
• pip install -r requirements.txt instala todas as dependências registradas.
• O versionamento ajuda a controlar quais versões das bibliotecas são utilizadas.
• Gerenciar dependências corretamente torna os projetos mais previsíveis e reproduzíveis.
