Listas em Python

Nesta aula, você vai aprender a trabalhar com listas, uma das estruturas de dados mais importantes do Python. Vamos aprender como criar listas, acessar seus elementos através de índices, adicionar e remover itens e organizar os dados utilizando métodos como append(), insert(), remove() e pop(). Também veremos como ordenar os elementos de uma lista.

📋 Criando listas

Uma lista é uma coleção de valores armazenados dentro de colchetes []. Uma lista pode armazenar vários valores e esses valores podem ser de diferentes tipos.

listas.py
1
2
3
4
5
6
7
frutas = [ "maçã", "banana", "laranja" ]
numeros = [10, 20, 30, 40]
misturada = [ "Python", 10, True ]
print(frutas)

▶ Resultado

Terminal
> ['maçã', 'banana', 'laranja']
💡 Para lembrar:

Listas são representadas por colchetes e podem armazenar vários elementos.

Exemplo:

nomes = ["Ana", "Carlos", "Maria"]

🔢 Índices

Assim como acontece com as strings, os elementos de uma lista possuem índices. O primeiro elemento está no índice 0, o segundo no índice 1 e assim por diante.

💡 Exemplo:

Para a lista:

frutas = ["maçã", "banana", "laranja"]

Temos:

frutas[0] → "maçã"
frutas[1] → "banana"
frutas[2] → "laranja"
indices.py
1
2
3
4
5
6
frutas = [ "maçã", "banana", "laranja" ]
print(frutas[0])
print(frutas[1])
print(frutas[2])
Terminal
> maçã
> banana
> laranja

🔙 Índices negativos

Também podemos acessar elementos começando pelo final da lista. O índice -1 representa o último elemento, -2 o penúltimo e assim por diante.

indices_negativos.py
1
2
3
4
5
frutas = [ "maçã", "banana", "laranja" ]
print(frutas[-1])
print(frutas[-2])
Terminal
> laranja
> banana

➕ Adicionando elementos

Podemos adicionar novos elementos a uma lista utilizando métodos específicos. Os dois principais métodos para isso são append() e insert().

📌 append()

O método append() adiciona um novo elemento ao final da lista.

append.py
1
2
3
4
5
frutas = [ "maçã", "banana" ]
frutas.append( "laranja")
print(frutas)
Terminal
> ['maçã', 'banana', 'laranja']

📍 insert()

O método insert() permite adicionar um elemento em uma posição específica da lista. Sua sintaxe é:

lista.insert(posicao, valor)

insert.py
1
2
3
4
5
frutas = [ "maçã", "laranja" ]
frutas.insert(1, "banana")
print(frutas)
Terminal
> ['maçã', 'banana', 'laranja']
💡 Diferença:

append() adiciona no final.

insert() permite escolher a posição.

➖ Removendo elementos

Python possui diferentes formas de remover elementos de uma lista. Nesta aula vamos conhecer remove() e pop().

🗑️ remove()

O método remove() remove um elemento informando o seu valor.

remove.py
1
2
3
4
5
frutas = [ "maçã", "banana", "laranja" ]
frutas.remove( "banana")
print(frutas)
Terminal
> ['maçã', 'laranja']

📤 pop()

O método pop() remove um elemento utilizando seu índice. Quando nenhum índice é informado, ele remove o último elemento da lista.

pop.py
1
2
3
4
5
6
7
frutas = [ "maçã", "banana", "laranja" ]
removida = frutas.pop(1)
print(removida)
print(frutas)
Terminal
> banana
> ['maçã', 'laranja']
💡 Diferença entre remove() e pop():

remove() → remove pelo valor.

pop() → remove pelo índice e pode retornar o elemento removido.

🔤 Ordenação

Podemos organizar os elementos de uma lista em ordem utilizando o método sort(). Por padrão, os valores são organizados em ordem crescente ou alfabética.

ordenacao.py
1
2
3
4
5
6
numeros = [50, 10, 40, 20, 30]
numeros.sort()
print(numeros)
Terminal
> [10, 20, 30, 40, 50]

🔽 Ordem decrescente

Para ordenar uma lista do maior para o menor, podemos utilizar o argumento reverse=True.

ordem_decrescente.py
1
2
3
4
5
numeros = [10, 50, 20, 40, 30]
numeros.sort(reverse=True)
print(numeros)
Terminal
> [50, 40, 30, 20, 10]

🧠 Resumo da aula

O que você aprendeu:

• Listas armazenam vários elementos em uma única estrutura.
• Listas são criadas utilizando [].
• Os elementos possuem índices que começam em 0.
• Índices negativos permitem acessar elementos começando pelo final.
• append() adiciona um elemento no final da lista.
• insert() adiciona um elemento em uma posição específica.
• remove() remove um elemento pelo seu valor.
• pop() remove um elemento pelo índice e pode retornar o elemento removido.
• sort() organiza os elementos da lista.
• sort(reverse=True) organiza os elementos em ordem decrescente.
