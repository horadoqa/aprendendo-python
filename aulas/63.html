Projeto de análise de dados

Nesta aula, vamos colocar em prática os conceitos de análise e visualização de dados aprendidos nas aulas anteriores. Vamos trabalhar com um conjunto de dados, realizar sua limpeza, analisar as informações, criar visualizações e, finalmente, tirar conclusões baseadas nos resultados.

🎯 Objetivo do projeto:

Aprender a seguir um fluxo completo de análise de dados utilizando Python, desde a leitura de um dataset até a apresentação das conclusões.

🔎 Etapas do projeto

Uma análise de dados normalmente passa por várias etapas. Neste projeto, vamos seguir este fluxo:

  • 1. Dataset — obter e conhecer os dados.
  • 2. Limpeza — corrigir problemas e preparar os dados.
  • 3. Análise — encontrar padrões e informações importantes.
  • 4. Visualização — transformar os resultados em gráficos.
  • 5. Conclusões — interpretar os resultados encontrados.
💡 Pense como um processo investigativo:

Primeiro coletamos as evidências, depois verificamos sua qualidade, analisamos os dados e finalmente apresentamos o que descobrimos.

📂 1. Dataset

Um dataset é um conjunto de dados que pode ser utilizado para análise. Neste projeto, vamos trabalhar com dados relacionados a vendas.

Imagine um arquivo chamado vendas.csv contendo informações como:

  • Produto.
  • Categoria.
  • Cidade.
  • Quantidade vendida.
  • Preço.
  • Data da venda.

🐼 Importando o dataset

Para analisar o arquivo, podemos utilizar a biblioteca Pandas. O primeiro passo é importar a biblioteca e utilizar read_csv() para carregar os dados.

df = pd.read_csv( "vendas.csv" )

🧹 2. Limpeza dos dados

Dados reais nem sempre estão perfeitos. Podemos encontrar valores ausentes, duplicados, tipos incorretos ou informações inconsistentes. Por isso, a limpeza é uma etapa fundamental da análise.

🔎 Procurando valores ausentes

limpeza.py
1
2
3
4
print(df.isnull().sum())
df = df.dropna()
print(df.isnull().sum())

O método isnull() ajuda a identificar valores ausentes. Já o dropna() pode ser utilizado para remover linhas que possuem valores ausentes.

♻️ Procurando duplicados

duplicados.py
1
2
3
print(df.duplicated().sum())
df = df.drop_duplicates()
⚠️ Atenção:

Nem todo valor ausente ou registro duplicado deve simplesmente ser excluído. Em um projeto real, precisamos entender o motivo do problema antes de decidir como tratá-lo.

🔢 Verificando tipos

Também precisamos verificar se cada coluna possui o tipo de dado correto.

tipos.py
1
2
3
print(df.dtypes)
df[ "preco" ] = pd.to_numeric( df[ "preco" ])

📊 3. Análise dos dados

Depois de limpar os dados, podemos começar a procurar informações relevantes. Por exemplo:

  • Qual produto vendeu mais?
  • Qual cidade teve maior volume de vendas?
  • Qual categoria gerou mais receita?
  • Qual foi o valor total das vendas?

💰 Calculando a receita

Podemos criar uma nova coluna para calcular a receita de cada venda.

analise.py
1
2
3
4
df[ "receita" ] = df[ "quantidade" ] * df[ "preco" ]
total = df[ "receita" ].sum()
print(total)

📦 Agrupando os dados

O groupby() permite agrupar registros de acordo com uma determinada categoria. Por exemplo, podemos descobrir quanto cada cidade vendeu.

agrupamento.py
1
2
3
vendas_cidade = df.groupby( "cidade" )[ "receita" ].sum()
print(vendas_cidade)

🏆 Produto mais vendido

produto.py

2
3
produtos = df.groupby( "produto" )[ "quantidade" ].sum()
print(produtos.sort_values( ascending= False ))

📈 4. Visualização

Depois de analisar os dados, podemos utilizar gráficos para apresentar os resultados de forma visual.

Vamos criar um gráfico mostrando a receita por cidade.

import matplotlib.pyplot as plt
vendas_cidade = df.groupby( "cidade" )[ "receita" ].sum()

plt.ylabel( "Receita" )
plt.show()

🧠 5. Conclusões

A etapa final da análise é interpretar os resultados. Não basta apenas criar gráficos ou calcular valores: precisamos explicar o que os dados estão mostrando.

📌 Exemplo de conclusão:

A análise mostrou que a maior parte da receita está concentrada em produtos da categoria de eletrônicos. A cidade com maior faturamento apresentou também um volume maior de vendas. Esses resultados podem ajudar a empresa a identificar quais produtos e regiões possuem maior desempenho.

Uma boa conclusão deve responder às perguntas levantadas durante a análise e destacar os resultados mais importantes.

import pandas as pd
import matplotlib.pyplot as plt
# Carregando os dados
df = pd.read_csv( "vendas.csv" )
# Limpando os dados
df = df.drop_duplicates()
df = df.dropna()
# Criando a receita
df[ "receita" ] = df[ "quantidade" ] * df[ "preco" ]
# Analisando
total = df[ "receita" ].sum()
print( "Receita total:" , total)
# Visualizando
df.groupby( "cidade" )[ "receita" ].sum().plot( kind= "bar" )
plt.show()

✅ Boas práticas em projetos de análise

  • Conheça os dados antes de começar a análise.
  • Não altere os dados sem entender o problema.
  • Documente as transformações realizadas.
  • Utilize nomes de variáveis claros.
  • Escolha gráficos adequados para cada pergunta.
  • Não confunda correlação com causalidade.
  • Sempre valide os resultados encontrados.
  • Apresente conclusões baseadas nos dados.
