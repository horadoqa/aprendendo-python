Testes

Nesta aula, você vai aprender os fundamentos dos testes automatizados em Python. Vamos conhecer o módulo unittest, o framework pytest e entender como criar testes unitários.

Testes automatizados ajudam a verificar se o código está funcionando conforme o esperado e permitem identificar problemas rapidamente quando uma alteração é realizada.

💡 Para lembrar:

Um teste automatizado executa uma verificação automaticamente e compara o resultado obtido com o resultado esperado.

Se os resultados forem iguais, o teste passa. Caso contrário, o teste falha.

🧪 O que são testes unitários?

Testes unitários verificam pequenas partes isoladas de uma aplicação, normalmente funções ou métodos.

Por exemplo, imagine uma função responsável por somar dois números:

calculadora.py
1
2
3
def somar(a, b):
     return a + b

Podemos criar um teste para verificar se a função retorna o resultado esperado.

🎯 Exemplo:

Se chamarmos somar(2, 3), esperamos receber 5.

✅ Asserções

Uma asserção verifica se uma condição é verdadeira. Nos testes, usamos asserções para comparar o resultado obtido com o resultado esperado.

Um exemplo simples:

exemplo.py
1
assert 2 + 3 == 5

Nesse exemplo, o Python verifica se 2 + 3 == 5 é verdadeiro. Como a condição é verdadeira, nenhuma falha acontece.

💡 Importante:

Se uma asserção falhar, o teste deve indicar que o comportamento esperado não foi encontrado.

🧰 unittest

O unittest é um framework de testes que faz parte da biblioteca padrão do Python. Isso significa que não precisamos instalar um pacote adicional para utilizá-lo.

Vamos criar um teste para nossa função somar().

test_calculadora.py

import unittest
from calculadora import somar
class TestCalculadora( unittest.TestCase):
     def test_somar(self):
         resultado = somar(2, 3)
         self.assertEqual(resultado, 5)

O método assertEqual() verifica se dois valores são iguais.

Para executar os testes com unittest:

🚀 pytest

O pytest é um framework bastante utilizado para automação de testes em Python. Ele possui uma sintaxe simples e oferece diversos recursos para criação e execução de testes.

Diferentemente do unittest, podemos criar um teste simples sem precisar criar uma classe.

test_calculadora.py
1
2
3
4
5
from calculadora import somar
def test_somar():
     resultado = somar(2, 3)
     assert resultado == 5

Observe que o teste utiliza apenas uma função e a palavra-chave assert.

📥 Instalando pytest

❌ Quando um teste falha

Um teste falha quando o resultado obtido é diferente do resultado esperado.

test_exemplo.py
1
2
3
def test_soma():
     resultado = 2 + 2
     assert resultado == 5

Nesse exemplo, o resultado será 4, mas estamos esperando 5. Portanto, o teste irá falhar.

Terminal
> FAILED test_exemplo.py
> assert 4 == 5

⚖️ unittest x pytest

Os dois podem ser utilizados para criar testes automatizados, mas possuem estilos diferentes.

unittest

• Faz parte da biblioteca padrão do Python.
• Utiliza classes e métodos de teste.
• Possui vários métodos de asserção.
• É uma opção tradicional para testes em Python.

pytest

• Precisa ser instalado.
• Possui sintaxe mais simples.
• Utiliza assert diretamente.
• Possui diversos recursos e plugins.
• É muito utilizado em projetos de automação.
