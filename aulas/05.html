Condições em Python

Nesta aula, você vai aprender como fazer o programa tomar decisões utilizando estruturas condicionais. Vamos conhecer if, elif e else, aprender a criar condições aninhadas e combinar diferentes condições utilizando os operadores and, or e not.

🤔 O comando if

O comando if permite executar um determinado trecho de código somente quando uma condição for verdadeira. Em Python, o código que pertence ao if é definido pela indentação.

💡 Para lembrar:

Pense no if como uma pergunta:

"Se esta condição for verdadeira, o que devo fazer?"

💻 Código

if.py
1
2
3
4
5
idade = 20
if idade >= 18:
     print( "Você é maior de idade.")
# A condição é verdadeira

▶ Resultado

Terminal
> Você é maior de idade.

🔀 if e else

Quando precisamos executar um código caso a condição seja verdadeira e outro código caso ela seja falsa, utilizamos o else.

if_else.py
1
2
3
4
5
6
7
idade = 16
if idade >= 18:
     print( "Maior de idade.")
else:
     print( "Menor de idade.")
💡 Para lembrar:

O else não possui uma condição própria. Ele será executado quando a condição do if for falsa.

🔢 elif

O elif significa "else if". Ele permite verificar uma nova condição quando a condição anterior for falsa. Podemos utilizar vários elif em uma mesma estrutura condicional.

🪆 Condições aninhadas

Uma condição aninhada acontece quando colocamos um if dentro de outro if. Isso permite criar decisões mais específicas, verificando uma condição somente depois que outra condição foi satisfeita.

💡 Exemplo:

Primeiro podemos verificar se uma pessoa é maior de idade. Depois, dentro desse if, podemos verificar se ela possui uma carteira de motorista.

         print( "Precisa de carteira.")

🧠 Operador and

O operador and permite combinar duas ou mais condições. O resultado será verdadeiro somente quando todas as condições forem verdadeiras.

🔀 Operador or

O operador or também combina condições. Porém, basta que uma das condições seja verdadeira para que o resultado seja verdadeiro.

🔄 Operador not

O operador not inverte o resultado de uma condição. Se uma condição for True, o not transforma o resultado em False. Se for False, transforma em True.

🚀 Desafio

Crie um programa que receba a idade de uma pessoa e informe sua classificação:

  • Menor de 12 anos → Criança
  • De 12 a 17 anos → Adolescente
  • De 18 a 59 anos → Adulto
  • 60 anos ou mais → Idoso

Depois, adicione uma segunda condição para informar se a pessoa possui direito a meia-entrada. Utilize if, elif, else e, em pelo menos uma parte do programa, um operador lógico.

💡 Dica:

Comece criando a variável:

idade = int(input("Digite sua idade: "))

Depois, utilize as estruturas condicionais para verificar cada faixa de idade.

🧠 Resumo da aula

O que você aprendeu:

• if executa um código quando uma condição é verdadeira.
• else executa um código quando a condição do if é falsa.
• elif permite verificar condições adicionais.
• Condições aninhadas são estruturas condicionais dentro de outras estruturas condicionais.
• and exige que todas as condições sejam verdadeiras.
• or retorna verdadeiro quando pelo menos uma condição é verdadeira.
• not inverte o resultado de uma condição.
• A indentação é fundamental para definir os blocos de código em Python.
• Condições permitem criar programas capazes de tomar decisões.
