Conjuntos em Python

Nesta aula, você vai aprender a trabalhar com conjuntos, também conhecidos como sets. Conjuntos são estruturas utilizadas para armazenar valores únicos, sem elementos duplicados. Vamos aprender como criar conjuntos, realizar união, interseção e diferença, além de utilizar conjuntos para remover valores duplicados.

🟢 O que é um set?

Um set é uma estrutura de dados que armazena elementos únicos. Isso significa que valores repetidos são automaticamente eliminados. Os conjuntos são criados utilizando chaves {}.

💡 Para lembrar:

Uma lista pode conter valores repetidos:

numeros = [1, 2, 2, 3, 3, 3]

Já um conjunto mantém apenas os valores únicos:

numeros = {1, 2, 3}

♻️ Removendo duplicados

Uma das utilizações mais comuns dos conjuntos é remover valores duplicados de uma lista. Basta transformar a lista em um conjunto utilizando set().

duplicados.py
1
2
3
4
5
6
numeros = [1, 2, 2, 3, 3, 4, 5, 5]
unicos = set(numeros)
print(numeros)
print(unicos)
Terminal
> [1, 2, 2, 3, 3, 4, 5, 5]
> {1, 2, 3, 4, 5}
💡 Dica:

Para remover duplicados de uma lista:

lista = list(set(lista))

O set() elimina os valores repetidos e o list() transforma o resultado novamente em uma lista.

🤝 União

A união combina os elementos de dois conjuntos. Elementos repetidos aparecem apenas uma vez. Podemos utilizar o operador | ou o método union().

uniao.py
1
2
3
4
5
6
7
grupo_a = {1, 2, 3, 4}
grupo_b = {3, 4, 5, 6}
resultado = grupo_a | grupo_b
print(resultado)
Terminal
> {1, 2, 3, 4, 5, 6}
Outra forma:

resultado = grupo_a.union(grupo_b)

O resultado é o mesmo.

🔗 Interseção

A interseção retorna apenas os elementos que existem nos dois conjuntos. Podemos utilizar o operador & ou o método intersection().

intersecao.py
1
2
3
4
5
6
7
grupo_a = {1, 2, 3, 4}
grupo_b = {3, 4, 5, 6}
resultado = grupo_a & grupo_b
print(resultado)
Terminal
> {3, 4}
💡 Para lembrar:

União → junta os elementos.

Interseção → encontra os elementos em comum.

➖ Diferença

A diferença retorna os elementos que estão no primeiro conjunto, mas não estão no segundo. Utilizamos o operador - ou o método difference().

diferenca.py
1
2
3
4
5
6
7
grupo_a = {1, 2, 3, 4}
grupo_b = {3, 4, 5, 6}
resultado = grupo_a - grupo_b
print(resultado)
Terminal
> {1, 2}
⚠️ Atenção:

A ordem importa na diferença.

grupo_a - grupo_b não necessariamente produz o mesmo resultado que:

grupo_b - grupo_a

🗑️ Removendo elementos

Podemos remover elementos de um conjunto utilizando métodos como remove() e discard(). O método remove() gera um erro se o elemento não existir. Já discard() não gera erro caso o elemento não esteja presente.

numeros.remove(20)
numeros.discard(50)
print(numeros)
Terminal
> {10, 30, 40}

📚 Operações com conjuntos

Principais operações:

A | B → União

A & B → Interseção

A - B → Diferença

A.union(B) → União

A.intersection(B) → Interseção

A.difference(B) → Diferença

🧠 Resumo da aula

O que você aprendeu:

• set representa um conjunto de valores únicos.
• Conjuntos não permitem elementos duplicados.
• set() pode ser utilizado para remover duplicados de uma lista.
• | realiza a união entre conjuntos.
• & realiza a interseção entre conjuntos.
• - realiza a diferença entre conjuntos.
• union() realiza uma união.
• intersection() realiza uma interseção.
• difference() realiza uma diferença.
• remove() remove um elemento e gera erro se ele não existir.
• discard() remove um elemento sem gerar erro caso ele não exista.
