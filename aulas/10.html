Tuplas em Python

Nesta aula, você vai aprender a trabalhar com tuplas, uma estrutura de dados muito parecida com as listas. Vamos aprender como criar tuplas, acessar seus elementos através de índices, utilizar índices negativos, descobrir o tamanho de uma tupla e percorrer seus valores. Também vamos entender uma das principais diferenças entre listas e tuplas: tuplas são imutáveis.

📦 Criando tuplas

Uma tupla é uma coleção de valores que, normalmente, é criada utilizando parênteses. Assim como uma lista, uma tupla pode armazenar vários elementos.

tuplas.py
1
2
3
4
5
6
frutas = ( "maçã", "banana", "laranja" )
numeros = (10, 20, 30, 40)
print(frutas)
print(numeros)

▶ Resultado

Terminal
> ('maçã', 'banana', 'laranja')
> (10, 20, 30, 40)
💡 Para lembrar:

Listas normalmente utilizam [].

Tuplas normalmente utilizam ().

🔢 Índices

Assim como acontece com as listas, os elementos de uma tupla possuem índices. O primeiro elemento está no índice 0, o segundo no índice 1 e assim por diante.

indices.py
1
2
3
4
5
6
cores = ( "azul", "verde", "vermelho" )
print(cores[0])
print(cores[1])
print(cores[2])
Terminal
> azul
> verde
> vermelho

🔙 Índices negativos

Também podemos acessar os elementos de uma tupla começando pelo final. O índice -1 representa o último elemento, enquanto -2 representa o penúltimo.

negativos.py
1
2
3
4
5
frutas = ( "maçã", "banana", "laranja" )
print(frutas[-1])
print(frutas[-2])
Terminal
> laranja
> banana

📏 Tamanho da tupla

Podemos utilizar a função len() para descobrir quantos elementos existem dentro de uma tupla.

tamanho.py
1
2
3
4
frutas = ( "maçã", "banana", "laranja" )
quantidade = len(frutas)
print(quantidade)
Terminal
> 3

🔒 Tuplas são imutáveis

Uma das principais características das tuplas é que elas são imutáveis. Isso significa que, depois de criada, não podemos alterar diretamente seus elementos.

imutavel.py
1
2
3
4
cores = ( "azul", "verde", "vermelho" )
cores[0] = "amarelo"

⚠️ Resultado

Terminal
> TypeError: 'tuple' object does not support item assignment
💡 Importante:

Se você precisa de uma estrutura que possa ser alterada depois de criada, normalmente utilizará uma lista.

Se os dados não devem ser alterados, uma tupla pode ser uma boa escolha.

🔄 Percorrendo uma tupla

Podemos utilizar o comando for para percorrer todos os elementos de uma tupla. Esse recurso será muito utilizado em programas que precisam analisar vários valores.

percorrendo.py
1
2
3
4
5
6
frutas = ( "maçã", "banana", "laranja" )
for fruta in frutas:
     print(fruta)
Terminal
> maçã
> banana
> laranja

🔎 Métodos de tuplas

As tuplas possuem alguns métodos úteis. Dois deles são count(), que conta quantas vezes um valor aparece, e index(), que informa a posição de um determinado valor.

metodos.py
1
2
3
4
5
6
numeros = (10, 20, 10, 30, 10)
print( numeros.count(10))
print( numeros.index(20))
Terminal
> 3
> 1

⚖️ Lista x Tupla

Listas e tuplas possuem várias características em comum, mas existe uma diferença fundamental entre elas.

📋 Lista

• Utiliza [].
• Pode ser alterada depois de criada.
• Possui métodos como append(), insert(), remove() e pop().

📦 Tupla

• Utiliza ().
• Não pode ter seus elementos alterados diretamente.
• É útil para representar conjuntos de valores que não devem ser modificados.

📤 Desempacotamento

🧠 Resumo da aula

O que você aprendeu:

• Tuplas são estruturas de dados que armazenam vários valores.
• Tuplas normalmente são criadas utilizando ().
• Os elementos possuem índices que começam em 0.
• Índices negativos permitem acessar elementos começando pelo final.
• len() informa a quantidade de elementos.
• Tuplas são imutáveis.
• count() conta ocorrências de um valor.
• index() encontra a posição de um valor.
• Tuplas podem ser percorridas com for.
• É possível desempacotar uma tupla em várias variáveis.
• Listas são indicadas quando os dados precisam ser alterados; tuplas são úteis quando os dados devem permanecer fixos.
