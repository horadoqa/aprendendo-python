AULA 72

Generators e yield

Nesta aula, vamos conhecer os Generators, um recurso muito importante do Python para trabalhar com sequências de valores de maneira eficiente. Vamos aprender como utilizar yield, next(), for e generator expressions.

🎯 Objetivo da aula:

Aprender a criar funções generator e entender como o Python produz valores sob demanda, evitando armazenar toda a sequência na memória de uma vez.

🔥 O que é um Generator?

Um generator é uma forma especial de criar um iterador utilizando uma função.

Em vez de criar todos os valores de uma vez, um generator produz cada valor somente quando ele é necessário.

💡 Ideia principal:

Uma função tradicional normalmente calcula um resultado e utiliza return.

Uma função generator utiliza yield para produzir um valor e pausar sua execução.

Quando o próximo valor é solicitado, a execução continua de onde havia parado.

🔄 return x yield

Podemos comparar uma função tradicional com uma função generator.

return.py

def numeros():
     valores = [1, 2, 3]
     return valores
print(numeros())

Nesse caso, a lista inteira é criada e retornada.

Agora podemos utilizar yield:

yield.py
1

3
4

def numeros():
     yield 1
     yield 2
     yield 3

Agora a função não retorna uma lista. Ela cria um generator que produz os valores conforme são solicitados.

🏭 Como funciona o yield?

Quando Python encontra yield, ele entrega o valor para quem chamou a função e pausa a execução.

Quando o próximo valor é solicitado, a função continua exatamente do ponto onde havia parado.

yield → produz um valor → pausa → continua depois

Observe o exemplo:

     print("Continuação")
     yield 20

🛑 StopIteration

Quando o generator não possui mais valores para produzir, uma chamada adicional de next() provoca a exceção StopIteration.

stop.py
1
2
3
4
5
def numeros():
     yield 1
     yield 2
gerador = numeros()

Depois que os valores 1 e 2 forem consumidos, não haverá mais valores disponíveis.

💡 Importante:

Normalmente não precisamos tratar StopIteration manualmente quando utilizamos um generator em um loop for. O próprio Python cuida disso.

🔍 O for por baixo dos panos

O loop for utiliza o protocolo de iteração do Python. Internamente, ele obtém um iterador e solicita os próximos valores até que aconteça StopIteration.

for → iter() → next() → StopIteration

Podemos observar uma ideia semelhante manualmente:

manual.py
1
2
3
4
5
6
valores = [10, 20, 30]
iterador = iter(valores)
print(next(iterador))
print(next(iterador))
print(next(iterador))

O generator segue esse mesmo conceito de iteração, mas produz os valores sob demanda.

🧠 Lazy Evaluation

Generators utilizam uma estratégia chamada lazy evaluation, ou avaliação preguiçosa.

Isso significa que os valores não precisam ser calculados todos de uma vez. Eles são produzidos somente quando solicitados.

Lista:
Calcula e armazena os valores.

Generator:
Produz os valores conforme são necessários.

🔢 Generator com loop

🎯 Generator com condições

Também podemos utilizar condições dentro de uma função generator. Por exemplo, podemos produzir somente números pares.

pares.py
1
2
3
4
5
6
def pares(limite):
     for numero in range(limite):
         if numero % 2 == 0:
             yield numero
print(list(pares(10)))
Terminal
> [0, 2, 4, 6, 8]

⚡ Generator Expressions

Assim como temos list comprehensions, também podemos criar generators utilizando uma sintaxe compacta chamada generator expression.

Observe a diferença:

expressions.py
1
2
lista = [x * 2 for x in range(5)]
gerador = (x * 2 for x in range(5))

Os colchetes [] criam uma lista.

Os parênteses () criam um generator expression.

💡 Dica:

Se você precisa armazenar todos os resultados, uma lista pode ser adequada.

Se deseja produzir os valores sob demanda, um generator pode ser uma opção melhor.

📦 Exemplo prático — Processando arquivos

Generators são especialmente úteis quando precisamos processar grandes quantidades de dados.

Imagine um arquivo contendo milhares de linhas. Em vez de carregar todas as linhas na memória, podemos produzir uma linha por vez.

arquivo.py
1
2
3
4
5
6
def linhas(nome):
     with open(nome, encoding="utf-8") as arquivo:
         for linha in arquivo:
             yield linha.strip()
for linha in linhas("dados.txt"):

Nesse exemplo, cada linha pode ser processada conforme é solicitada, sem precisar criar uma grande lista contendo todo o conteúdo do arquivo.

🚀 Vantagens dos Generators

  • Podem economizar memória.
  • Produzem valores sob demanda.
  • São úteis para grandes volumes de dados.
  • Permitem criar sequências infinitas.
  • Podem deixar determinados algoritmos mais eficientes.
⚠️ Atenção:

Um generator não deve ser confundido com uma lista.

Depois que seus valores são consumidos, eles não ficam disponíveis novamente no mesmo generator.

🧠 O estado da função

Uma característica importante de um generator é que ele preserva seu estado entre uma chamada e outra.

estado.py
1
2
3
4
5
6
7
def exemplo():
     print("A")
     yield 1
     print("B")
     yield 2
gerador = exemplo()

Ao chamar next(), a execução começa. Ao encontrar yield, ela pausa. Na próxima chamada, continua exatamente depois daquele yield.

⚖️ Lista x Generator

Lista:

[x * 2 for x in range(1000000)]

Cria e armazena todos os resultados.


Generator:

(x * 2 for x in range(1000000))

Produz os resultados conforme são consumidos.

Para sequências muito grandes, essa diferença pode ser importante para o consumo de memória.

🚀 Mini projeto — Gerador de dados

Vamos criar um pequeno generator para simular a produção de dados. Imagine que um sistema recebe números continuamente.

projeto.py

def gerar_dados():
     numero = 1
     while numero <= 10:
         yield {
             "id": numero
         }
         numero += 1
for dado in gerar_dados():
     print(dado)

Esse padrão pode ser utilizado em situações nas quais os dados são produzidos aos poucos.
