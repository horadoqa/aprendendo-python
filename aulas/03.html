Operadores em Python

Nesta aula, você vai aprender como utilizar operadores em Python para realizar cálculos, comparar valores, combinar condições e atribuir valores às variáveis. Também veremos a precedência, que determina a ordem em que as operações são executadas.

➕ Operadores aritméticos

Os operadores aritméticos são utilizados para realizar operações matemáticas com números.

  • + — adição.
  • - — subtração.
  • * — multiplicação.
  • / — divisão.
  • // — divisão inteira.
  • % — resto da divisão.
  • ** — exponenciação.
💡 Para lembrar: Os operadores aritméticos permitem que o programa realize cálculos matemáticos diretamente no código.

⚖️ Operadores de comparação

Os operadores de comparação são utilizados para comparar valores. O resultado de uma comparação sempre será um valor booleano: True ou False.

  • == — igual a.
  • != — diferente de.
  • > — maior que.
  • < — menor que.
  • >= — maior ou igual a.
  • <= — menor ou igual a.
💡 Atenção: O operador == é usado para comparar valores. Já o operador = é usado para atribuir um valor a uma variável.
comparacao.py
1
2
3
4
5

idade = 20
print(idade == 20)
print(idade != 18)
print(idade > 18)
print(idade < 18)
print(idade >= 20)

🧠 Operadores lógicos

Os operadores lógicos permitem combinar ou inverter condições.

  • and — retorna True quando todas as condições forem verdadeiras.
  • or — retorna True quando pelo menos uma condição for verdadeira.
  • not — inverte o valor lógico de uma condição.
logicos.py

idade = 25
tem_carteira = True
print( idade >= 18 and tem_carteira)
print( idade < 18 or tem_carteira)
print( not tem_carteira)
# Resultado: True, True, False

📝 Operadores de atribuição

Os operadores de atribuição são utilizados para armazenar valores em variáveis. Além do operador =, Python possui operadores que permitem realizar uma operação e atribuir o resultado à própria variável.

  • = — atribuição.
  • += — adiciona e atribui.
  • -= — subtrai e atribui.
  • *= — multiplica e atribui.
  • /= — divide e atribui.

📐 Precedência de operadores

Quando uma expressão possui vários operadores, Python segue uma ordem de prioridade para decidir qual operação será executada primeiro.

De forma simplificada, podemos lembrar desta ordem:

  1. () — parênteses.
  2. ** — exponenciação.
  3. *, /, //, % — multiplicação e divisões.
  4. +, - — adição e subtração.
  5. Comparações e operadores lógicos.
💡 Exemplo: Na expressão 10 + 2 * 3, a multiplicação acontece primeiro. Portanto, o resultado será 16. Podemos utilizar parênteses para deixar a ordem explícita: (10 + 2) * 3 resulta em 36.

O que você aprendeu:

• Operadores de comparação verificam relações entre valores.
• Comparações retornam True ou False.
