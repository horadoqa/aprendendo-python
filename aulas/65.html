Scikit-learn

Nesta aula, vamos começar a criar modelos de Machine Learning utilizando a biblioteca Scikit-learn. Vamos conhecer três tipos importantes de problemas: regressão, classificação e clustering.

🎯 Objetivo da aula:

Aprender a identificar diferentes tipos de problemas de Machine Learning e conhecer modelos básicos do Scikit-learn para resolvê-los.

🧠 O que é Scikit-learn?

O Scikit-learn é uma das principais bibliotecas Python para Machine Learning. Ela oferece ferramentas para treinamento, avaliação e utilização de diversos algoritmos.

Entre os recursos disponíveis estão algoritmos para:

  • Regressão.
  • Classificação.
  • Clustering.
  • Pré-processamento.
  • Avaliação de modelos.
  • Separação de dados para treino e teste.

🔄 Fluxo básico

Independentemente do algoritmo utilizado, muitos projetos seguem uma estrutura parecida:

Dados → Separação → Treinamento → Previsão → Avaliação

Primeiro preparamos os dados, depois treinamos um modelo e finalmente utilizamos dados de teste para verificar seu desempenho.

📈 1. Regressão

A regressão é utilizada quando queremos prever um valor numérico.

Alguns exemplos:

  • Prever o preço de uma casa.
  • Prever vendas de uma empresa.
  • Estimar temperatura.
  • Prever o consumo de energia.
💡 Pergunta típica de regressão:

"Qual será o preço desta casa?"

A resposta é um número, como R$ 450.000.

Um dos algoritmos mais simples para começar é a Regressão Linear.

from sklearn.linear_model import LinearRegression
X = [[1], [2], [3], [4], [5]]
y = [2, 4, 6, 8, 10]
modelo = LinearRegression()
modelo.fit(X, y)
previsao = modelo.predict([[6]])
print(previsao)

O método fit() treina o modelo com os dados fornecidos. Depois utilizamos predict() para fazer uma previsão.

🧠 Resumindo:

Regressão → resultado numérico.

🏷️ 2. Classificação

A classificação é utilizada quando queremos colocar uma observação em uma categoria.

Exemplos:

  • E-mail é spam ou não é spam.
  • Cliente vai cancelar ou não vai cancelar.
  • Imagem contém gato ou cachorro.
  • Transação é normal ou suspeita.
💡 Pergunta típica de classificação:

"Este e-mail é spam?"

A resposta pode ser uma categoria: spam ou não spam.

🔢 Regressão Logística

🔵 3. Clustering

O clustering, ou agrupamento, é diferente dos exemplos anteriores. Aqui não fornecemos necessariamente um label para cada exemplo.

O algoritmo tenta encontrar grupos de elementos semelhantes dentro dos próprios dados.

💡 Exemplo:

Imagine uma loja que possui milhares de clientes. Podemos utilizar clustering para encontrar grupos de clientes com comportamentos semelhantes.

Por exemplo:

  • Clientes que compram frequentemente.
  • Clientes que gastam pouco.
  • Clientes que compram produtos específicos.

🔵 K-Means

⚖️ Regressão x Classificação x Clustering

📈 Regressão
Prevê um valor numérico.

Exemplo: preço = R$ 500.000

🏷️ Classificação
Prevê uma categoria.

Exemplo: spam = sim

🔵 Clustering
Encontra grupos semelhantes nos dados.

Exemplo: grupo 1, grupo 2, grupo 3

📏 Avaliando o modelo

Depois de fazer previsões, precisamos medir o desempenho do modelo. Para classificação, uma métrica simples é a acurácia.

acuracia = accuracy_score( y_test, previsoes)
print(acuracia)
💡 Importante:

A métrica utilizada depende do problema. Regressão e classificação possuem formas diferentes de avaliar seus resultados.

⚠️ Erros comuns

  • Treinar e testar o modelo exatamente com os mesmos dados.
  • Ignorar dados ausentes ou inconsistentes.
  • Escolher um algoritmo sem entender o tipo do problema.
  • Avaliar o modelo apenas por uma impressão visual.
  • Confundir regressão com classificação.
  • Acreditar que um modelo mais complexo será sempre melhor.
