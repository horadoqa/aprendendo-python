SQL

Nesta aula, você vai conhecer os fundamentos de SQL, uma linguagem utilizada para trabalhar com bancos de dados relacionais. Vamos aprender como criar e consultar tabelas e como realizar as principais operações de manipulação de dados: SELECT, INSERT, UPDATE e DELETE.

💡 Para lembrar:

SQL significa Structured Query Language.

Ela permite conversar com um banco de dados, realizando operações como consultar, inserir, alterar e excluir informações.

🗄️ O que é um banco de dados?

Um banco de dados é utilizado para armazenar informações de forma organizada, permitindo que aplicações possam consultar e manipular esses dados.

Em bancos de dados relacionais, as informações normalmente são organizadas em tabelas.

Exemplo:

Imagine uma tabela chamada usuarios.

Ela pode armazenar informações como:

id
nome
email
idade

📋 Tabelas

Uma tabela é composta por colunas e linhas.

Colunas
Representam os campos ou características armazenadas.

Linhas
Representam os registros armazenados na tabela.

💡 Atenção:

O SQL possui pequenas diferenças de sintaxe dependendo do banco utilizado, como PostgreSQL, MySQL, SQL Server ou SQLite.

Os exemplos desta aula apresentam conceitos gerais de SQL.

🔎 SELECT — Consultando dados

O comando SELECT é utilizado para consultar informações armazenadas em uma tabela.

Para buscar todas as colunas de todos os usuários, podemos utilizar:

select.sql
1
SELECT * FROM usuarios;
Resultado:

A consulta retorna todas as colunas e registros existentes na tabela usuarios.

🎯 Selecionando colunas específicas

Não precisamos consultar todas as colunas. Podemos escolher exatamente quais informações queremos retornar.

colunas.sql
1
SELECT nome, email FROM usuarios;

Nesse exemplo, somente as colunas nome e email serão retornadas.

🎯 Filtrando resultados

O comando WHERE permite definir uma condição para filtrar os registros.

where.sql
1
SELECT * FROM usuarios
WHERE idade > 18;
Nesse exemplo, somente usuários com idade maior que 18 anos serão retornados.

➕ INSERT — Inserindo dados

O comando INSERT INTO é utilizado para adicionar novos registros a uma tabela.

insert.sql
1
2
3
4
5
INSERT INTO usuarios (nome, email, idade)
VALUES
( 'Maria' ,
'maria@email.com' , 25
);
💡 Para lembrar:

INSERT INTO indica a tabela onde queremos inserir os dados.

VALUES define os valores que serão armazenados.

✏️ UPDATE — Atualizando dados

O comando UPDATE permite alterar informações de registros existentes.

update.sql
1
2
UPDATE usuarios
SET idade = 26 WHERE nome = 'Maria' ;
⚠️ Cuidado com UPDATE!

Sempre tenha atenção ao utilizar UPDATE.

A cláusula WHERE define quais registros serão alterados.

Sem ela, dependendo do banco e do comando, você pode alterar todos os registros da tabela.

🗑️ DELETE — Excluindo dados

O comando DELETE é utilizado para remover registros de uma tabela.

delete.sql
1
DELETE FROM usuarios WHERE id = 1;
⚠️ Muito cuidado!

Assim como no UPDATE, a cláusula WHERE é extremamente importante.

Sem uma condição adequada, o comando DELETE pode remover vários registros ou até mesmo todos os registros da tabela.

⚖️ Comparando os comandos

SELECT
Consulta dados.

INSERT
Adiciona dados.

UPDATE
Altera dados.

DELETE
Remove dados.

🧪 SQL para QA

Conhecer SQL é muito importante para profissionais de QA, principalmente quando precisamos validar informações diretamente no banco de dados.

Podemos, por exemplo, verificar se uma informação enviada através de uma API realmente foi salva no banco.

Exemplo de cenário:

1. O teste envia uma requisição para cadastrar um usuário.

2. A API retorna sucesso.

3. O QA consulta o banco utilizando SELECT.

4. O QA verifica se os dados foram realmente persistidos.
validacao.sql
1
2
3
4
SELECT *
FROM usuarios
WHERE email = 'maria@email.com' ;
🎯 Pense como QA:

A API retornar 200 ou 201 não significa automaticamente que os dados foram persistidos corretamente.

Uma consulta SQL pode ajudar a confirmar o estado real do banco de dados.

📝 Exercício

Imagine uma tabela chamada produtos com as seguintes colunas:

id
nome
preco
estoque

Crie comandos SQL para:

  • Inserir um novo produto.
  • Consultar todos os produtos.
  • Consultar somente nome e preço.
  • Alterar o preço de um produto.
  • Excluir um produto específico.
💡 Desafio extra:

Crie uma consulta que retorne somente os produtos cujo estoque seja maior que zero.

Dica:
Utilize WHERE.
