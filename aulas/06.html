Repetição em Python

Nesta aula, você vai aprender como executar um determinado trecho de código várias vezes utilizando estruturas de repetição. Vamos conhecer os comandos while, for e range(), além de aprender como controlar um loop utilizando break e continue.

🔄 O comando while

O comando while repete um bloco de código enquanto uma determinada condição for verdadeira. Ele é muito útil quando não sabemos exatamente quantas vezes uma ação deverá ser repetida.

💡 Para lembrar:

Pense no while como:

"Enquanto esta condição for verdadeira, continue executando."

💻 Código

while.py
1
2
3
4
5
6
7
contador = 1
while contador <= 5:
     print(contador)
     contador += 1
# O loop termina quando contador chegar a 6

▶ Resultado

Terminal
> 1
> 2
> 3
> 4
> 5
⚠️ Cuidado com loops infinitos:

É importante garantir que a condição do while eventualmente se torne falsa. No exemplo acima, contador += 1 faz com que o contador avance até que o loop seja encerrado.

🔁 O comando for

O comando for é utilizado para percorrer uma sequência de valores. Ele é especialmente útil quando sabemos quantas vezes queremos repetir uma determinada operação ou quando precisamos percorrer uma coleção de elementos.

for.py
1
2
3
4
5
nomes = [ "Ana", "João", "Maria" ]
for nome in nomes:
     print(nome)
Terminal
> Ana
> João
> Maria
💡 Para lembrar:

O for pega cada elemento da sequência, um de cada vez, e executa o bloco de código para aquele elemento.

🔢 range()

A função range() gera uma sequência de números que pode ser utilizada principalmente com o for. Ela é muito útil quando queremos repetir uma ação uma quantidade determinada de vezes.

💡 Atenção:

O valor final informado no range() não é incluído. Por exemplo, range(5) gera os valores 0, 1, 2, 3 e 4.
range.py
1
2
3
4
5
6
for numero in range(5):
     print(numero)
# Começa em 0 e termina antes de 5
# Resultado: 0, 1, 2, 3, 4

🎯 range() com início e fim

Também podemos informar um valor inicial e um valor final. Nesse caso, a sequência começa no primeiro valor e termina antes do segundo.

range_inicio.py
1
2
3
4
for numero in range(1, 6):
     print(numero)
# Resultado: 1, 2, 3, 4, 5

👣 range() com passo

O terceiro parâmetro do range() permite definir o passo da sequência. Assim podemos, por exemplo, contar de dois em dois.

range_passo.py
1
2
3
4
for numero in range(0, 10, 2):
     print(numero)
# Resultado: 0, 2, 4, 6, 8

🛑 break

O comando break interrompe imediatamente o loop. Ele é útil quando encontramos uma condição que indica que não precisamos continuar a repetição.

break.py
1
2
3
4
5
6
7
for numero in range(1, 11):
     if numero == 5:
         break
     print(numero)
# O loop termina ao encontrar o 5
Terminal
> 1
> 2
> 3
> 4

⏭️ continue

O comando continue não encerra o loop. Ele apenas interrompe a execução daquela iteração e faz o programa passar para a próxima repetição.

continue.py
1
2
3
4
5
6
7
for numero in range(1, 6):
     if numero == 3:
         continue
     print(numero)
# O número 3 é ignorado
Terminal
> 1
> 2
> 4
> 5

🎮 Programa interativo com while

Agora vamos utilizar um while para criar um pequeno programa interativo. O programa continuará perguntando a senha até que o usuário informe a senha correta.

senha.py
1
2
3
4
5
6
7
8
senha = ""
while senha != "python123":
     senha = input( "Digite a senha: ")
print( "Acesso permitido!")
# O loop termina quando a senha estiver correta
💡 Observe:

O while verifica a condição antes de cada repetição. Enquanto a senha for diferente de "python123", o programa continuará solicitando uma nova tentativa.

🧪 Pequeno programa com for

Podemos utilizar o for para executar uma tarefa uma quantidade determinada de vezes. No exemplo abaixo, o programa simula cinco tentativas de execução de um teste.

teste.py
1
2
3
4
5
6
for tentativa in range(1, 6):
     print( f"Executando teste {tentativa}")
print( "Testes finalizados.")
# São realizadas 5 execuções

▶ Resultado

Terminal
> Executando teste 1
> Executando teste 2
> Executando teste 3
> Executando teste 4
> Executando teste 5
> Testes finalizados.

⚖️ break x continue

É importante entender a diferença entre os dois comandos.

🛑 break

Encerra completamente o loop.

⏭️ continue

Pula a iteração atual e continua com a próxima repetição.

🚀 Desafio

Crie um programa que peça ao usuário para informar números. O programa deve continuar solicitando números até que o usuário digite 0.

Regras:

  • Se o número for positivo, mostre "Número positivo".
  • Se o número for negativo, mostre "Número negativo".
  • Se o usuário digitar 0, utilize break para encerrar o programa.
  • Utilize while para controlar a repetição.
💡 Dica:

Comece com:

while True:

Depois, receba o número com input() e utilize as condições para decidir quando continuar ou quando utilizar break.

🧠 Resumo da aula

O que você aprendeu:

• while repete um código enquanto uma condição for verdadeira.
• for percorre elementos de uma sequência.
• range() cria uma sequência de números para ser utilizada em repetições.
• range() não inclui o valor final.
• Podemos definir início, fim e passo no range().
• break encerra completamente um loop.
• continue pula a iteração atual e continua o loop.
• É importante evitar loops infinitos quando utilizamos while.
• Estruturas de repetição permitem automatizar tarefas que precisam ser executadas várias vezes.
