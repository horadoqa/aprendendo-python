Automação de planilhas

Nesta aula, vamos aprender como utilizar Python para trabalhar automaticamente com planilhas do Excel. Vamos utilizar a biblioteca openpyxl para ler e escrever dados, alterar células, criar planilhas e gerar relatórios automaticamente.

🎯 Objetivo da aula:

Aprender a automatizar tarefas repetitivas em planilhas, como leitura de dados, preenchimento de células, criação de relatórios e atualização de informações.

📊 Por que automatizar planilhas?

Planilhas são muito utilizadas para armazenar, organizar e analisar informações. Porém, realizar as mesmas tarefas manualmente todos os dias pode consumir muito tempo.

Com Python, podemos automatizar essas tarefas e processar grandes quantidades de dados de forma rápida e consistente.

💡 Exemplos de automação:

• Ler dados de uma planilha.
• Criar novas planilhas.
• Preencher células automaticamente.
• Alterar valores.
• Criar relatórios.
• Calcular resultados.
• Aplicar filtros e formatação.
• Processar várias linhas automaticamente.

🐍 Conhecendo o openpyxl

O openpyxl é uma biblioteca Python utilizada para trabalhar com arquivos Excel no formato .xlsx.

Para utilizá-la, primeiro precisamos instalar o pacote:

🧪 Automação de planilhas para QA

A automação de Excel pode ser muito útil em atividades de QA. Podemos utilizar Python para gerar dados, processar resultados de testes e criar relatórios automaticamente.

  • Gerar massas de teste.
  • Ler dados utilizados nos testes.
  • Comparar resultados esperados e obtidos.
  • Criar relatórios de execução.
  • Consolidar resultados de diferentes testes.
  • Atualizar planilhas automaticamente.
  • Gerar evidências de testes.
💡 Exemplo:

Imagine uma planilha contendo os resultados de 100 testes automatizados. Um script Python pode ler os resultados, calcular a quantidade de testes aprovados e reprovados e gerar um relatório final em Excel.

🛠️ Projeto prático — Relatório de testes

Vamos criar um pequeno relatório contendo resultados de testes automatizados.

import openpyxl
resultados = [
     [ "Login" , "Passou" ],
     [ "Cadastro" , "Passou" ],
     [ "Checkout" , "Falhou" ]
]
planilha = openpyxl.Workbook()
aba = planilha.active
aba.append([ "Teste" , "Resultado" ])
for resultado in resultados:
     aba.append(resultado)
planilha.save( "relatorio_testes.xlsx" )

▶ Resultado do relatório

> Login | Passou
> Cadastro | Passou
> Checkout | Falhou

✅ Boas práticas

  • Faça uma cópia da planilha antes de automatizar alterações importantes.
  • Utilize nomes claros para arquivos e abas.
  • Valide os dados antes de gravá-los.
  • Evite sobrescrever arquivos sem necessidade.
  • Separe a lógica de processamento da lógica de geração do relatório.
  • Utilize funções para organizar scripts maiores.
  • Registre erros durante o processamento.

🚀 Desafio da aula

Crie um programa que leia uma planilha contendo resultados de testes automatizados e gere uma nova planilha com um resumo da execução. O relatório deverá apresentar:

  • Nome do teste.
  • Resultado do teste.
  • Quantidade de testes executados.
  • Quantidade de testes aprovados.
  • Quantidade de testes reprovados.
  • Percentual de aprovação.
🏆 Desafio extra:

Formate o relatório automaticamente.

Utilize:
• Cabeçalhos em negrito.
• Cores diferentes para Passou e Falhou.
• Uma coluna para o percentual de aprovação.
• Uma célula destacando o resultado final.
• Nome do arquivo contendo a data da execução.
