Variáveis e tipos de dados em Python

Nesta aula, você vai aprender como armazenar informações em variáveis e conhecer alguns dos principais tipos de dados do Python: int, float, str e bool. Também veremos como descobrir o tipo de uma variável usando type() e como converter valores entre diferentes tipos.

📦 Variáveis

Uma variável é um nome que usamos para guardar uma informação na memória do programa. Em Python, basta escolher um nome e utilizar o operador = para atribuir um valor.

💡 Para lembrar: Pense em uma variável como uma "caixa" que possui um nome e guarda um valor dentro dela.

🔢 Tipos de dados

Python possui diferentes tipos de dados. Nesta aula, vamos trabalhar com quatro tipos muito importantes:

  • int — números inteiros, como 10 ou -5.
  • float — números com casas decimais, como 10.5.
  • str — textos, como "Python".
  • bool — valores lógicos: True ou False.

🔄 Conversão de tipos

Podemos converter um valor de um tipo para outro utilizando funções como int(), float() e str().

💡 Exemplo: Um texto contendo o número "25" pode ser convertido para o número inteiro 25 utilizando int().
