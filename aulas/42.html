Type hints

Nesta aula, você vai aprender como utilizar type hints em Python para indicar quais tipos de dados uma variável, parâmetro ou função deve receber ou retornar.

A tipagem ajuda a tornar o código mais claro, facilita a manutenção e permite que ferramentas de desenvolvimento encontrem possíveis problemas antes mesmo da execução do programa.

💡 Para lembrar:

Type hints são anotações que descrevem os tipos esperados no código.

Python continua sendo uma linguagem de tipagem dinâmica. As anotações não transformam Python em uma linguagem estaticamente tipada.

🏷️ Anotações de tipos

Podemos informar o tipo esperado de uma variável utilizando dois pontos :.

tipos.py
1
2
3
4
nome: str = "Maria"
idade: int = 25
altura: float = 1.65
aprovado: bool = True

Nesse exemplo, estamos indicando que nome deve ser uma string, idade um inteiro, altura um número decimal e aprovado um booleano.

💡 Atenção:

O Python não impede automaticamente que um valor de outro tipo seja atribuído à variável. As type hints funcionam principalmente como documentação e podem ser analisadas por ferramentas como linters, IDEs e verificadores de tipos.

⚙️ Type hints em funções

Também podemos informar os tipos esperados pelos parâmetros de uma função.

funcoes.py
1
2
3
def somar(a: int, b: int) -> int:
     return a + b

Nesse caso, estamos indicando que os parâmetros a e b devem ser inteiros e que a função deve retornar um inteiro.

🔎 Observe:

a: int → tipo esperado do parâmetro.

-> int → tipo esperado do retorno da função.

🔤 Type hints com strings

Podemos indicar que uma função recebe e retorna textos utilizando str.

usuario.py
1
2
3
def saudacao(nome: str) -> str:
     return f"Olá, {nome}!"

📋 List

Podemos indicar que uma variável ou parâmetro representa uma lista. Em Python moderno, podemos informar também o tipo dos elementos armazenados na lista.

listas.py
1
2
3
4
5
nomes: list[str] = [
     "Maria",
     "João",
     "Ana"
]

Nesse exemplo, list[str] indica uma lista cujos elementos esperados são strings.

💡 Tipagem dos elementos:

list[str] → lista de strings.
list[int] → lista de inteiros.
list[float] → lista de números decimais.

📦 Listas em funções

Também podemos utilizar type hints para indicar que uma função recebe uma lista e retorna uma lista.

processamento.py
1
2
3
4
5
def dobrar_numeros( numeros: list[int] ) -> list[int]:
     resultado = []
     for numero in numeros:
         resultado.append(numero * 2)
     return resultado

📖 Dict

Para dicionários, podemos informar o tipo das chaves e dos valores utilizando dict[chave, valor].

dicionarios.py
1
2
3
4
5
usuario: dict[str, str] = {
     "nome": "Maria",
     "email": "maria@email.com"
}

Nesse exemplo: dict[str, str] significa que as chaves são strings e os valores também são strings.

💡 Exemplos:

dict[str, int] → chave string e valor inteiro.

dict[int, str] → chave inteira e valor string.

❓ Optional

Às vezes uma variável pode receber um determinado tipo de valor ou None. Para representar esse comportamento, podemos utilizar Optional.

Uma forma tradicional de escrever isso é:

optional.py
1
2
3
4
from typing import Optional
nome: Optional[str] = None

Isso significa que nome pode conter uma string ou None.

🔎 Exemplo:

Optional[str]

significa:

str ou None.

⚙️ Optional em funções

Também podemos utilizar Optional em parâmetros e retornos de funções.

busca.py
1
2
3
4
5
6
from typing import Optional
def buscar_usuario(id: int) -> Optional[str]:
     if id == 1:
         return "Maria"
     return None

O retorno dessa função pode ser uma string quando o usuário é encontrado ou None quando não é encontrado.

🆕 Tipagem moderna

Em versões modernas do Python, podemos utilizar o operador | para representar diferentes tipos possíveis.

Por exemplo, em vez de:

antigo.py
1
from typing import Optional

Podemos utilizar a sintaxe moderna:

moderno.py
1
2
3
nome: str | None = None
def buscar(id: int) -> str | None:
💡 Tipagem moderna:

str | None representa uma string ou None.

Essa sintaxe é uma alternativa moderna ao uso de Optional[str].

📋 Listagem moderna

A partir do Python 3.9, podemos utilizar diretamente tipos como list e dict para especificar os tipos dos elementos.

Forma moderna:

moderno.py
1
2
3
4
nomes: list[str] = []
idades: list[int] = []
usuarios: dict[str, int] = {}
valores: list[float] = []
🧠 Comparação:

Forma antiga:
List[str]

Forma moderna:
list[str]

Para projetos novos utilizando versões modernas do Python, a segunda forma costuma ser preferível.

📖 Dicionários com tipagem moderna

O mesmo conceito pode ser aplicado aos dicionários.

usuarios.py
1
2
3
4
5
usuarios: dict[str, int] = {
     "Maria": 25,
     "João": 30,
     "Ana": 22
}

🧪 Type hints no QA

Type hints são especialmente úteis em projetos de automação de testes, pois ajudam a deixar claro quais tipos de dados as funções esperam receber.

Imagine uma função utilizada para validar uma resposta de uma API:

validacao.py
1
2
3
4
5
def validar_status( status: int ) -> bool:
     return status == 200
resultado: bool = validar_status(200)

A anotação deixa explícito que a função recebe um código de status inteiro e retorna um valor booleano.

🎯 Benefício para QA:

Type hints tornam funções de automação mais previsíveis e facilitam a leitura do código, principalmente em projetos maiores.

🧠 Resumo da aula

O que você aprendeu:

• Type hints permitem documentar os tipos esperados no código.
• Variáveis podem receber anotações como nome: str e idade: int.
• Parâmetros de funções podem possuir type hints.
• O retorno de uma função pode ser indicado com ->.
• List pode representar listas tipadas usando a forma tradicional.
• Dict pode representar dicionários tipados usando a forma tradicional.
• Optional representa um tipo que também pode ser None.
• A sintaxe moderna utiliza list[str] e dict[str, int].
• O operador | pode representar múltiplos tipos, como str | None.
• Type hints ajudam na documentação, manutenção e qualidade do código.
• Em QA, type hints podem tornar funções de automação mais claras e previsíveis.
