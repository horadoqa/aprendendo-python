Introdução à Programação Orientada a Objetos

Nesta aula, você vai conhecer os principais conceitos da Programação Orientada a Objetos (POO) em Python. Vamos aprender o que são classes, objetos, atributos e métodos.

🧩 O que é POO?

A Programação Orientada a Objetos é um paradigma de programação que organiza o código utilizando objetos.

Esses objetos podem representar coisas do mundo real ou conceitos do sistema. Por exemplo, em um sistema de testes podemos ter objetos como Cliente, Produto, Teste ou Relatório.

💡 Para lembrar:

POO permite organizar o código agrupando dados e comportamentos dentro de objetos.

🏗️ Classes

Uma classe funciona como um modelo ou uma estrutura para criar objetos.

Podemos imaginar uma classe como uma planta de uma casa. A planta define como a casa será construída, mas não representa uma casa específica.

💡 Exemplo:

A classe Cliente pode definir quais informações e comportamentos um cliente terá.

👤 Objetos

Um objeto é uma instância de uma classe.

Se a classe é o modelo, o objeto é uma utilização concreta desse modelo.

🏠 Exemplo:

Classe: Casa
Objetos: minha casa, sua casa, casa da empresa.

Todos os objetos seguem a estrutura definida pela classe.

Podemos criar vários objetos a partir da mesma classe.

📦 Atributos

Atributos são características ou informações que pertencem a um objeto.

Um cliente, por exemplo, pode possuir atributos como nome, idade e email.

💡 Exemplo:

Um objeto Cliente pode ter:

nome → "Maria"
idade → 25
email → "maria@email.com"

🔑 O self

Dentro de uma classe, utilizamos self para acessar o próprio objeto.

⚙️ Métodos

Métodos são funções que pertencem a uma classe.

Eles representam comportamentos que um objeto pode executar.

🧪 POO aplicada ao QA

A Programação Orientada a Objetos é muito utilizada em automação de testes. Podemos criar classes para representar páginas, usuários, produtos e diferentes componentes da aplicação.

🎯 Exemplo:

Podemos criar uma classe LoginPage para representar uma tela de login.

Seus atributos podem representar informações da página e seus métodos podem representar ações, como fazer login.

🔗 Classe, objeto, atributo e método

🧠 Pense assim:

Classe → modelo que define a estrutura.

Objeto → instância criada a partir da classe.

Atributo → característica ou dado do objeto.

Método → comportamento ou ação que o objeto pode executar.

🚀 Desafio

Crie uma classe chamada Produto.

🎯 Requisitos:

• Crie os atributos nome e preco.
• Crie um método chamado mostrar_dados().
• O método deve mostrar o nome e o preço do produto.
• Crie pelo menos dois objetos da classe.
• Execute o método para cada objeto.

O que você aprendeu:

• POO significa Programação Orientada a Objetos.

• Classes funcionam como modelos para criar objetos.
