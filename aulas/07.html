Exercícios de lógica em Python

Nesta aula, vamos colocar em prática os conceitos aprendidos nas aulas anteriores. Você vai criar pequenos programas utilizando variáveis, input(), condições, operações matemáticas e estruturas de repetição. O objetivo é desenvolver seu raciocínio lógico e começar a resolver problemas utilizando Python.

🧮 1. Calculadora

Vamos começar criando uma calculadora simples. O programa receberá dois números e uma operação, realizando o cálculo escolhido pelo usuário.

💡 O que vamos praticar:

input(), conversão com float(), condições com if, elif e else, além dos operadores matemáticos.

numero1 = float( input( "Digite o primeiro número: "))
numero2 = float( input( "Digite o segundo número: "))
operacao = input( "Digite +, -, * ou /: ")
if operacao == "+":
     resultado = numero1 + numero2
elif operacao == "-":
     resultado = numero1 - numero2
elif operacao == "*":
     resultado = numero1 * numero2
elif operacao == "/":
     resultado = numero1 / numero2
else:
     resultado = "Operação inválida"
print( f"Resultado: {resultado}")

▶ Resultado

Terminal
> Digite o primeiro número: 10
> Digite o segundo número: 5
> Digite +, -, * ou /: *
> Resultado: 50.0

✖️ 3. Tabuada

A tabuada é um excelente exercício para praticar estruturas de repetição. Vamos utilizar for e range() para gerar os resultados automaticamente.

tabuada.py
1
2
3
4
5
6
numero = int( input( "Digite um número: "))
for i in range(1, 11):
     resultado = numero * i
     print( f"{numero} x {i} = {resultado}")

▶ Resultado

Terminal
> Digite um número: 5
> 5 x 1 = 5
> 5 x 2 = 10
> 5 x 3 = 15
> ...
> 5 x 10 = 50

📊 4. Média de notas

Vamos criar um programa que recebe três notas, calcula a média e informa se o aluno foi aprovado, ficou de recuperação ou foi reprovado.

nota1 = float( input( "Nota 1: "))

nota3 = float( input( "Nota 3: "))
media = (nota1 + nota2 + nota3) / 3
print( f"Média: {media:.1f}")
if media >= 7:
     print( "Aprovado!")
elif media >= 5:
     print( "Recuperação.")
💡 Desafio:

Adicione um else para informar "Reprovado." quando a média for menor que 5.

🎯 6. Jogo de adivinhação

Para finalizar a aula, vamos criar um pequeno jogo. O computador terá um número secreto e o jogador deverá tentar adivinhar qual é. Esse exercício combina while, if, elif, else e input().

numero_secreto = 7
tentativa = 0
while tentativa != numero_secreto:
     tentativa = int( input( "Adivinhe o número: "))
     if tentativa < numero_secreto:
         print( "Tente um número maior.")
     elif tentativa > numero_secreto:
         print( "Tente um número menor.")
print( "Parabéns! Você acertou!")
