Automação Web

Nesta aula, vamos aprender os conceitos básicos de automação web utilizando Python. Diferente do Web Scraping, que normalmente busca extrair informações de uma página, a automação web permite controlar um navegador para executar ações como acessar páginas, clicar em elementos, preencher formulários e navegar entre telas.

🎯 Objetivo da aula:

Aprender como automatizar tarefas em navegadores utilizando ferramentas como Selenium e Playwright.

🌐 O que é automação web?

Automação web consiste em utilizar um programa para controlar um navegador automaticamente. O programa pode realizar ações que normalmente seriam executadas manualmente por uma pessoa.

💡 Exemplos de ações:

• Abrir um site.
• Navegar para uma página.
• Clicar em botões.
• Preencher campos.
• Selecionar opções.
• Enviar formulários.
• Verificar textos.
• Capturar informações da página.
• Validar comportamentos de uma aplicação.

🔎 Web Scraping x Automação Web

Na aula anterior, vimos Web Scraping. Embora as duas técnicas possam trabalhar juntas, seus objetivos geralmente são diferentes.

  • Web Scraping — normalmente busca extrair informações de páginas.
  • Automação Web — controla o navegador e executa ações.
  • Automação de testes — utiliza o navegador para verificar se uma aplicação funciona conforme o esperado.
💡 Exemplo:

Um scraper pode coletar o preço de um produto.

Uma automação pode abrir o site, pesquisar o produto, preencher filtros, clicar em botões e verificar se o preço apresentado está correto.

🧪 Selenium

O Selenium é uma das ferramentas mais conhecidas para automação de navegadores. Ele permite controlar navegadores como Chrome, Firefox e Edge através de código.

🔎 Localizando elementos

Para interagir com uma página, precisamos localizar os elementos HTML que queremos utilizar. Podemos procurar elementos por diferentes estratégias, como ID, class ou outros seletores.

from selenium import webdriver
from selenium.webdriver.common.by import By
navegador = webdriver.Chrome()
navegador.get( "https://example.com" )
titulo = navegador.find_element( By.TAG_NAME, "h1" )
print (titulo.text)

📝 Preenchendo formulários

Uma das tarefas mais comuns em automação web é preencher formulários. Podemos localizar um campo de entrada e utilizar o método send_keys() para inserir informações.

from selenium import webdriver
from selenium.webdriver.common.by import By
navegador = webdriver.Chrome()
navegador.get( "https://exemplo.com/login" )
usuario = navegador.find_element( By.ID, "usuario" )
usuario.send_keys( "maria" )
# O campo foi preenchido

⚠️ Segurança:

Nunca coloque senhas reais diretamente no código, principalmente quando o projeto será compartilhado ou versionado no Git.

Em projetos reais, utilize variáveis de ambiente ou mecanismos apropriados para armazenar credenciais.

🎭 Playwright

O Playwright é outra ferramenta moderna para automação de navegadores. Ele possui suporte para navegadores como Chromium, Firefox e WebKit.

Para instalar o Playwright:

terminal
1
pip install playwright

Depois da instalação, os navegadores utilizados pelo Playwright podem ser instalados com:

💻 Primeiro exemplo com Playwright

playwright.py

from playwright.sync_api import sync_playwright
with sync_playwright() as p:
     navegador = p.chromium.launch()
     pagina = navegador.new_page()
     pagina.goto( "https://example.com" )
     print ( pagina.title() )
     navegador.close()

📝 Formulários com Playwright

O Playwright também facilita o preenchimento de formulários. Podemos localizar um campo e utilizar fill() para inserir um valor.

from playwright.sync_api import sync_playwright
with sync_playwright() as p:
     navegador = p.chromium.launch()
     pagina = navegador.new_page()
     pagina.goto( "https://exemplo.com/login" )
     pagina.locator( "#usuario" ).fill( "maria" )
     pagina.locator( "#enviar" ).click()

⚖️ Selenium ou Playwright?

As duas ferramentas podem ser utilizadas para automação web e testes automatizados. A escolha depende das necessidades do projeto, da equipe e do ecossistema utilizado.

  • Selenium — ferramenta tradicional e muito utilizada no mercado.
  • Playwright — ferramenta moderna com recursos voltados para automação e testes web.
  • Ambas permitem controlar navegadores programaticamente.
💡 Para QA:

Selenium e Playwright podem ser utilizados para automatizar cenários de testes end-to-end, verificando se uma aplicação funciona corretamente através da interface do navegador.

⏳ Esperas e sincronização

Aplicações web modernas carregam informações de forma dinâmica. Por isso, uma automação precisa considerar o momento correto para interagir com cada elemento.

⚠️ Evite:

Utilizar vários comandos sleep() apenas para "dar tempo" para a página carregar.

Sempre que possível, utilize mecanismos de espera apropriados da ferramenta para aguardar a condição necessária.

🧪 Automação Web para QA

A automação web é especialmente importante para profissionais de QA porque permite transformar cenários de teste manuais em testes automatizados.

  • Acessar uma aplicação.
  • Realizar login.
  • Preencher formulários.
  • Clicar em botões.
  • Navegar entre páginas.
  • Validar mensagens.
  • Verificar resultados.
  • Reproduzir cenários de regressão.

🛠️ Projeto prático — Testando um formulário

Imagine uma página de login contendo os campos:

  • Usuário
  • Senha
  • Botão Entrar

Um teste automatizado pode seguir este fluxo:

  1. Abrir o navegador.
  2. Acessar a página de login.
  3. Localizar o campo de usuário.
  4. Preencher o usuário.
  5. Localizar o campo de senha.
  6. Preencher a senha de teste.
  7. Clicar no botão de login.
  8. Verificar se a página esperada foi exibida.
🎯 Mentalidade de QA:

A automação não deve apenas "clicar em coisas". Ela deve executar ações e verificar resultados esperados.

Ação → Resultado esperado → Validação

Para cada cenário, defina claramente o resultado esperado.
