NumPy

Nesta aula, vamos conhecer o NumPy, uma das principais bibliotecas Python para trabalhar com números, arrays e operações matemáticas. O NumPy é muito utilizado em áreas como análise de dados, ciência de dados, inteligência artificial, testes e processamento de grandes volumes de informações.

🎯 Objetivo da aula:

Aprender a criar arrays utilizando NumPy, realizar operações matemáticas e entender como a vetorização permite trabalhar com vários valores de maneira eficiente.

📦 Instalando o NumPy

O NumPy não faz parte da biblioteca padrão do Python. Para utilizá-lo, precisamos instalar o pacote utilizando o pip:

terminal
1
pip install numpy

🐍 Importando o NumPy

Depois da instalação, podemos importar a biblioteca no nosso programa. A convenção mais utilizada é chamar o NumPy de np:

exemplo.py
1
2
import numpy as np
print (np.__version__)

🔢 Arrays

Um dos principais recursos do NumPy são os arrays. Um array pode armazenar vários valores e permite realizar operações matemáticas diretamente sobre todos os seus elementos.

Podemos criar um array utilizando np.array():

arrays.py
1
2
3
4
import numpy as np
numeros = np.array( [10, 20, 30, 40, 50])
print (numeros)

▶ Resultado

> [10 20 30 40 50]

🔢 Operações entre arrays

Também podemos realizar operações entre dois arrays. Os elementos correspondentes serão utilizados na operação.

import numpy as np

print (soma)
💡 Importante:

No exemplo acima, o NumPy realiza a operação elemento por elemento:

10 + 1 = 11
20 + 2 = 22
30 + 3 = 33

⚡ Vetorização

Vetorização é a capacidade de realizar uma operação sobre vários elementos de uma vez, sem precisar escrever um for para cada elemento.

Em Python puro, poderíamos fazer:

python.py
1
2
3
numeros = [10, 20, 30, 40]
resultado = []
for numero in numeros: resultado.append(numero * 2)

Com NumPy, podemos realizar a mesma operação de maneira vetorizada:

numpy.py
1
2
3
import numpy as np
numeros = np.array( [10, 20, 30, 40])
resultado = numeros * 2
🚀 Por que isso é importante?

A vetorização permite escrever operações sobre grandes conjuntos de dados de maneira mais expressiva e, em muitos casos, mais eficiente do que executar loops Python elemento por elemento.

🧪 NumPy no dia a dia do QA

O NumPy pode ser útil em atividades de QA que envolvem grandes quantidades de dados. Por exemplo, podemos utilizá-lo para realizar cálculos, comparar resultados, analisar métricas e preparar dados para testes.

💡 Exemplo:

Imagine que um teste produziu os seguintes tempos de resposta em milissegundos:

[120, 150, 110, 180, 140]

Com NumPy podemos calcular rapidamente a média, o menor e o maior tempo:
metricas.py
1
2
3
4
5
6
7
8
import numpy as np
tempos = np.array([
     120, 150, 110, 180, 140
])
print ( "Média:" , np.mean(tempos))
print ( "Máximo:" , np.max(tempos))

🚀 Desafio da aula

Crie um programa utilizando NumPy para analisar os resultados de cinco testes automatizados. Cada teste terá um tempo de execução em segundos.

O programa deverá:

  • Criar um array com os tempos dos testes.
  • Calcular o tempo médio.
  • Encontrar o menor tempo.
  • Encontrar o maior tempo.
  • Criar um novo array multiplicando todos os tempos por 2.
  • Utilizar vetorização para realizar pelo menos uma operação.
🏆 Desafio extra:

Considere que qualquer teste com tempo superior a 2.0 segundos deve ser considerado lento. Crie uma operação vetorizada que identifique os testes que ultrapassaram esse limite.
