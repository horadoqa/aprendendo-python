Caminhos e diretórios em Python

Nesta aula, você vai aprender a trabalhar com arquivos, pastas e caminhos utilizando o módulo pathlib. Vamos aprender a criar, mover, renomear e excluir arquivos e diretórios de forma simples e segura.

📁 O que são caminhos e diretórios?

Um caminho indica onde um arquivo ou diretório está localizado no computador.

Por exemplo:

💡 Exemplo de caminho:

projetos/testes/relatorio.txt

Nesse exemplo, projetos é uma pasta, testes é outra pasta e relatorio.txt é o arquivo.

Um diretório é simplesmente outro nome utilizado para representar uma pasta.

🐍 Conhecendo o pathlib

O pathlib é um módulo da biblioteca padrão do Python que facilita o trabalho com caminhos de arquivos e diretórios.

Para utilizá-lo, podemos importar a classe Path:

pathlib.py
1
2
from pathlib import Path

🛣️ Criando um caminho

Podemos criar um objeto Path passando o caminho que queremos representar.

caminho.py
1
2
3
from pathlib import Path
arquivo = Path( "relatorio.txt" )
print (arquivo)
Terminal
> relatorio.txt

🔎 Verificando se existe

O método exists() permite verificar se um arquivo ou diretório existe.

from pathlib import Path
arquivo = Path( "relatorio.txt" )

Terminal

📂 Arquivo ou diretório?

Podemos verificar se um caminho representa um arquivo ou um diretório utilizando is_file() e is_dir().

3
4

from pathlib import Path
caminho = Path( "relatorio.txt" )
print ( caminho. is_file ())
print ( caminho. is_dir ())

📁 Criando diretórios

O método mkdir() permite criar uma nova pasta.

criar_pasta.py
1
2
3
4
5
from pathlib import Path
pasta = Path( "relatorios" )
pasta. mkdir ()
print ( "Pasta criada!" )
💡 Atenção:

Se a pasta já existir, o mkdir() pode gerar um erro.

Para evitar isso, podemos utilizar exist_ok=True.
criar_pasta_segura.py
1
2
3
from pathlib import Path
pasta = Path( "relatorios" )
pasta. mkdir ( exist_ok= True )

✏️ Escrevendo em arquivos

O objeto Path também possui métodos que facilitam a leitura e escrita de arquivos.

Podemos utilizar write_text() para escrever um texto diretamente em um arquivo.

📦 Movendo arquivos

O método rename() pode ser utilizado tanto para renomear quanto para mover arquivos.

Para mover um arquivo, informamos o novo caminho como destino.

mover.py
1
2
3
4
from pathlib import Path
arquivo = Path( "teste.txt" )
arquivo. rename ( "documentos/teste.txt" )
💡 Importante:

Para mover um arquivo para uma pasta diferente, a pasta de destino precisa existir.

✏️ Renomeando arquivos

Também podemos utilizar rename() para alterar o nome de um arquivo.

renomear.py

2
3
4
from pathlib import Path
arquivo = Path( "teste.txt" )

🗑️ Excluindo arquivos

Para excluir um arquivo, podemos utilizar o método unlink().

excluir.py
1
2
3
4
5
from pathlib import Path
arquivo = Path( "teste.txt" )
arquivo. unlink ()
print ( "Arquivo excluído!" )
⚠️ Cuidado:

unlink() remove o arquivo do sistema de arquivos.

Antes de excluir, é uma boa prática verificar se o arquivo realmente existe utilizando exists().

2

from pathlib import Path
arquivo = Path( "teste.txt" )
if arquivo. exists ():
     arquivo. unlink ()
     print ( "Arquivo excluído!" )

🧪 pathlib no QA

O trabalho com arquivos e diretórios aparece frequentemente em automações e testes. Com pathlib, podemos criar estruturas de teste, localizar arquivos, organizar evidências e limpar arquivos temporários.

🎯 Exemplos no QA:

• Criar pastas para evidências dos testes.
• Localizar arquivos de evidência.
• Renomear screenshots.
• Mover relatórios para diretórios específicos.
• Criar arquivos de massa de teste.
• Excluir arquivos temporários após a execução.
• Verificar se um relatório foi gerado.

🔧 Exemplo prático

Podemos criar uma pasta para armazenar os resultados de um teste e depois criar um arquivo de evidência dentro dela.

evidencia.py

from pathlib import Path
pasta = Path( "evidencias" )
pasta. mkdir ( exist_ok= True )
arquivo = pasta / "resultado.txt"
arquivo. write_text ( "Teste aprovado" )
print ( "Evidência criada!" )
💡 Dica:

O operador / pode ser utilizado com objetos Path para construir caminhos de forma simples:

pasta / "resultado.txt"
