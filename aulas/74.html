AULA 74

Context Managers

Nesta aula, vamos aprender o que são Context Managers em Python e como eles ajudam a controlar recursos de maneira segura e organizada. Vamos entender o funcionamento da instrução with, conhecer os métodos __enter__() e __exit__() e criar nossos próprios context managers.

🎯 Objetivo da aula:

Aprender a utilizar context managers para garantir que determinados recursos sejam corretamente preparados, utilizados e liberados, mesmo quando ocorre um erro durante a execução.

🔥 O que é um Context Manager?

Um Context Manager é um objeto que controla o início e o fim de uma determinada operação.

Ele é especialmente útil quando precisamos trabalhar com recursos que devem ser liberados depois de utilizados.

Alguns exemplos são:

  • Arquivos.
  • Conexões com banco de dados.
  • Locks e recursos compartilhados.
  • Conexões de rede.
  • Recursos temporários.
💡 Ideia principal:

Um context manager define o que deve acontecer ao entrar e ao sair de um determinado contexto.

🚪 A instrução with

A forma mais comum de utilizar um context manager é através da instrução with.

Um exemplo muito conhecido é a leitura de arquivos:

arquivo.py
1
2
3
with open( "dados.txt" ) as arquivo:
     conteudo = arquivo.read()
print(conteudo)

Quando o bloco do with termina, o arquivo é fechado automaticamente.

with → preparar recurso → executar código → liberar recurso

🛡️ Por que utilizar with?

Sem um context manager, precisaríamos controlar manualmente a abertura e o fechamento de um recurso.

manual.py
1
2
3
4
5
arquivo = open( "dados.txt" )
conteudo = arquivo.read()
print(conteudo)
arquivo.close()

O problema é que, se ocorrer uma exceção antes de close(), o recurso pode não ser liberado corretamente.

O with ajuda a resolver esse problema automaticamente.

🔄 try e finally

Antes de conhecer context managers, é importante entender que o mesmo comportamento poderia ser implementado utilizando try e finally.

     utilizar(recurso)

O context manager encapsula esse padrão, tornando o código mais simples e expressivo.

🚪 __enter__() e __exit__()

Para criar um context manager utilizando uma classe, normalmente implementamos dois métodos especiais:

  • __enter__() — executado ao entrar no contexto.
  • __exit__() — executado ao sair do contexto.
__enter__() → entrada

código do with → utilização

__exit__() → saída

🧱 Criando nosso primeiro Context Manager

Vamos criar uma classe que exibe mensagens quando entramos e saímos de um contexto.

contexto.py

class MeuContexto:
     def __enter__(self):
         print( "Entrando no contexto" )
         return self
     def __exit__( self, exc_type, exc_value, traceback):
         print( "Saindo do contexto" )

Agora podemos utilizar a classe com with:

usar_contexto.py
1
2
3
with MeuContexto():
     print( "Executando código" )
Terminal
> Entrando no contexto
> Executando código
> Saindo do contexto

⚠️ Context Managers e exceções

O método __exit__() recebe informações sobre uma possível exceção que ocorreu dentro do bloco with.

Os três parâmetros principais são:

  • exc_type — tipo da exceção.
  • exc_value — objeto da exceção.
  • traceback — informações do traceback.

         print( "Fim" )
         print(exc_type)

🚫 Controlando exceções

O retorno de __exit__() também pode determinar se uma exceção será suprimida.

Se __exit__() retornar True, a exceção pode ser considerada tratada e não continuará sendo propagada.

suprimir.py
1
2
3
4
5
6
7
class IgnorarErro:
     def __enter__(self):
         return self
     def __exit__( self, exc_type, exc_value, traceback):
         return True
⚠️ Atenção:

Suprimir exceções indiscriminadamente pode esconder erros importantes. Esse recurso deve ser utilizado somente quando fizer sentido para o comportamento do programa.

🧰 contextlib

Python também possui o módulo contextlib, que fornece ferramentas para criar e trabalhar com context managers.

Uma das ferramentas mais úteis é o decorator @contextmanager.

✨ @contextmanager

Com @contextmanager, podemos criar um context manager utilizando uma função e yield.

contexto.py
1
2
3
4
5
6
7
8
from contextlib import contextmanager
@contextmanager
def meu_contexto():
     print( "Início" )
     yield
     print( "Fim" )

Podemos utilizar a função da mesma maneira que qualquer context manager:

main.py
1
2
3
with meu_contexto():
     print( "Executando" )
💡 Relação importante:

yield divide a função em dois momentos:

Antes do yield → entrada no contexto.

Depois do yield → saída do contexto.

📁 Context Managers e arquivos

O uso de with open() é provavelmente o exemplo mais conhecido de context manager em Python.

4

     arquivo.write( "Olá, Python!" )

Quando a execução sai do bloco with, o arquivo é fechado automaticamente.

🌎 Exemplos de utilização

Context managers aparecem em diversas situações no desenvolvimento de software.

  • Abrir e fechar arquivos.
  • Abrir e fechar conexões.
  • Controlar transações.
  • Adquirir e liberar locks.
  • Medir tempo de execução.

import time

     def __exit__( self, exc_type, exc_value, traceback):

✅ Boas práticas

Context managers devem ser utilizados quando existe algum recurso ou estado que precisa ser corretamente preparado e depois restaurado ou liberado.

  • Prefira with para recursos que precisam ser liberados.
  • Evite esconder exceções sem necessidade.
  • Mantenha o context manager simples.
  • Utilize nomes que deixem claro o propósito.
  • Use contextlib quando uma classe inteira for desnecessária.
💡 Regra prática:

Se seu código segue repetidamente o padrão:

preparar → usar → limpar

provavelmente um context manager pode tornar esse código mais seguro e organizado.
