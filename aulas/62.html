Visualização de dados

Nesta aula, vamos aprender como transformar dados em gráficos utilizando Python. A visualização de dados facilita a identificação de padrões, tendências, comparações e comportamentos que podem ser difíceis de perceber apenas olhando para uma tabela.

🎯 Objetivo da aula:

Aprender os conceitos básicos de visualização de dados utilizando Matplotlib e Seaborn, criando diferentes tipos de gráficos.

📊 O que é visualização de dados?

Visualização de dados é a representação de informações utilizando elementos gráficos, como barras, linhas, pontos e setores.

Em vez de analisar apenas números em uma tabela, podemos utilizar um gráfico para enxergar rapidamente:

  • Comparações entre categorias.
  • Tendências ao longo do tempo.
  • Distribuição dos dados.
  • Relações entre diferentes informações.
  • Valores que podem estar fora do padrão.
💡 Pense como QA:

Um gráfico pode ajudar a identificar rapidamente comportamentos anormais em resultados de testes, como aumento no tempo de execução ou crescimento da quantidade de falhas.

📈 Matplotlib

O Matplotlib é uma das principais bibliotecas Python para criação de gráficos. Ela permite criar gráficos de linhas, barras, dispersão, histogramas e diversos outros tipos de visualização.

Para utilizar a biblioteca, podemos importar o módulo pyplot:

import matplotlib.pyplot as plt
meses = [ "Jan" , "Fev" , "Mar" , "Abr" ]
vendas = [10, 15, 12, 20]
plt.plot(meses, vendas)

O comando plot() cria um gráfico de linhas. Para exibir o gráfico, utilizamos show().

import matplotlib.pyplot as plt
meses = [ "Jan" , "Fev" , "Mar" , "Abr" ]
vendas = [10, 15, 12, 20]
plt.plot(meses, vendas)
plt.title( "Vendas por mês" )
plt.xlabel( "Mês" )
plt.show()

📊 Gráfico de barras

Gráficos de barras são muito utilizados para comparar valores entre diferentes categorias. Em QA, podemos utilizá-los para comparar, por exemplo, a quantidade de testes que passaram e falharam.

barras.py
1
2
3
4
5
6
7
import matplotlib.pyplot as plt
status = [ "Passou" , "Falhou" ]
quantidade = [85, 15]
plt.bar(status, quantidade)
plt.show()
💡 Quando utilizar?

Use gráficos de barras quando quiser comparar categorias diferentes.

Use gráficos de linhas quando quiser observar uma evolução ou tendência.

🎨 Seaborn

📚 Principais tipos de gráficos

  • Gráfico de linha — utilizado para tendências e evolução.
  • Gráfico de barras — utilizado para comparar categorias.
  • Gráfico de dispersão — utilizado para observar relações entre variáveis.
  • Histograma — utilizado para visualizar a distribuição dos dados.
  • Gráfico de setores — utilizado para visualizar partes de um todo.

🎯 Benefício para QA:

Em vez de analisar dezenas ou centenas de linhas de resultados, um gráfico pode mostrar rapidamente a proporção de testes aprovados, falhos e bloqueados.

Isso torna relatórios e análises mais rápidos de entender.

✅ Boas práticas

  • Escolha o tipo de gráfico adequado para a informação.
  • Utilize títulos claros.
  • Identifique os eixos quando necessário.
  • Evite excesso de informações.
  • Utilize cores de forma consistente.
  • Sempre considere quem vai interpretar o gráfico.
💡 Regra simples:

O gráfico deve facilitar a compreensão dos dados, e não tornar a informação mais complicada.
