A primeira função a aprender no Python é o print()

O comando print() é uma das primeiras coisas que você aprende em Python. Ele é utilizado para mostrar informações na tela, como textos, números e resultados de operações.

💡 Para lembrar: Sempre que você quiser pedir para o Python mostrar alguma informação no terminal, provavelmente utilizará o comando print().
