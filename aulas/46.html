Criando APIs com Python

Nesta aula, você vai aprender como criar sua própria API utilizando Python. Vamos conhecer os conceitos básicos de Flask e FastAPI, criar rotas e endpoints e retornar dados em formato JSON.

🌐 O que é uma API?

Uma API permite que diferentes aplicações troquem informações através de regras previamente definidas.

Quando criamos uma API, podemos disponibilizar informações e funcionalidades para que outros sistemas possam utilizá-las.

🌶️ Introdução ao Flask

O Flask é um framework web leve e bastante utilizado para criar aplicações e APIs em Python.

Ele permite criar uma aplicação web definindo rotas que respondem a diferentes requisições.

from flask import Flask
app = Flask( __name__)
@app.route( "/")
def inicio():
     return "API funcionando!"

A função Flask() cria nossa aplicação.

O decorator @app.route() define uma rota que poderá ser acessada através de uma URL.

🛣️ Rotas

Uma rota define o caminho que o cliente deve acessar para utilizar determinado recurso da API.

⚖️ Flask ou FastAPI?

Os dois frameworks podem ser utilizados para criar APIs em Python.

Flask

• Framework leve e flexível.
• Muito utilizado em aplicações web.
• Possui um ecossistema bastante conhecido.
• Permite escolher diversas ferramentas para complementar o projeto.

FastAPI

• Focado na criação de APIs modernas.
• Utiliza type hints do Python.
• Possui validação de dados integrada.
• Gera documentação interativa automaticamente.

🧪 APIs e QA

Para quem trabalha com QA, entender como uma API é criada ajuda a compreender melhor o comportamento dos endpoints que serão testados.

Ao testar uma API, podemos verificar:

  • Método HTTP utilizado.
  • URL e rota.
  • Status code.
  • Headers.
  • Corpo da requisição.
  • Estrutura do JSON.
  • Dados retornados.
  • Comportamento em situações de erro.
🎯 Pense como QA:

Uma API não deve ser testada apenas quando tudo funciona.

Também devemos verificar o que acontece quando enviamos dados inválidos, recursos inexistentes ou requisições incompletas.

📝 Exercício

Imagine que você precisa criar uma API simples para gerenciar produtos.

Pense nos endpoints que seriam necessários para:

  • Listar produtos.
  • Buscar um produto específico.
  • Criar um produto.
  • Atualizar um produto.
  • Excluir um produto.
💡 Uma possível estrutura:

GET /produtos
Lista os produtos.

GET /produtos/1
Busca o produto de ID 1.

POST /produtos
Cria um novo produto.

PUT /produtos/1
Atualiza o produto de ID 1.

DELETE /produtos/1
Remove o produto de ID 1.
