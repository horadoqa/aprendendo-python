Entrada e saída em Python

Nesta aula, você vai aprender como criar programas que recebem informações do usuário e exibem resultados na tela. Vamos conhecer a função input(), aprender diferentes formas de formatar strings, utilizar f-strings e criar pequenos programas interativos.

⌨️ A função input()

A função input() permite que o programa solicite uma informação ao usuário. Quando o programa encontra um input(), ele aguarda o usuário digitar alguma coisa e pressionar Enter.

💡 Para lembrar:

O input() sempre retorna o valor digitado pelo usuário como uma string. Se precisarmos trabalhar com números, devemos converter o valor utilizando, por exemplo, int() ou float().

💻 Código

input.py
1
2
3
4
5
6
nome = input( "Digite seu nome: ")
print( "Olá!")
print(nome)
idade = input( "Digite sua idade: ")
print(idade)
# idade ainda é uma string

▶ Resultado

Terminal
> Digite seu nome: Maria
> Olá!
> Maria
> Digite sua idade: 25
> 25

🔄 Recebendo números

Como o input() retorna uma string, precisamos converter o valor quando quisermos realizar operações matemáticas. Para números inteiros, utilizamos int(). Para números decimais, utilizamos float().

numeros.py
1
2
3
4
5
6
idade = int( input( "Digite sua idade: "))
print( idade + 1)
altura = float( input( "Digite sua altura: "))
print( altura)
# Agora podemos realizar cálculos
print( idade * 2)
💡 Exemplo:

Se o usuário digitar 25, o input() recebe o texto "25". Ao utilizar int(), transformamos esse texto no número inteiro 25.

📝 Formatação de strings

Muitas vezes precisamos juntar textos e valores para apresentar uma mensagem ao usuário. Python possui diferentes maneiras de fazer isso. Uma forma simples é utilizar o operador + para concatenar strings.

strings.py
1
2
3
4
5
nome = "Maria"
profissao = "QA"
mensagem = "Meu nome é " + nome
mensagem += " e sou " + profissao
print(mensagem)
Terminal
> Meu nome é Maria e sou QA

✨ f-strings

As f-strings são uma maneira simples e moderna de inserir variáveis dentro de textos. Basta colocar a letra f antes da string e utilizar chaves {} para inserir valores.

💡 Para lembrar:

Em uma f-string, tudo que estiver entre {} será interpretado pelo Python como uma expressão.
f_strings.py
1
2
3
4
5
6
nome = "Maria"
idade = 25
profissao = "QA"
mensagem = f "Olá, {nome}!"
print( f"Você tem {idade} anos.")
print( f"Você trabalha como {profissao}.")

▶ Resultado

Terminal
> Olá, Maria!
> Você tem 25 anos.
> Você trabalha como QA.

🚀 Desafio

Crie um programa que pergunte ao usuário:

  • Seu nome;
  • Sua idade;
  • Sua cidade;
  • Seu hobby favorito.

Depois, utilize uma f-string para apresentar uma mensagem personalizada contendo todas essas informações.

💡 Dica:

Você pode utilizar um input() para cada informação e guardar cada resposta em uma variável. Depois, utilize uma f-string para montar a mensagem.

🧠 Resumo da aula

O que você aprendeu:

• input() permite receber informações do usuário.
• O valor retornado por input() é uma string.
• Podemos utilizar int() e float() para converter entradas numéricas.
• Strings podem ser concatenadas utilizando +.
• F-strings facilitam a inserção de variáveis dentro de textos.
• Podemos combinar input(), conversões e f-strings para criar programas interativos.
• Pequenos programas interativos são uma ótima forma de praticar os conceitos básicos de Python.
