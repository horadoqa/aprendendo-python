Comprehension em Python

Nesta aula, você vai aprender como utilizar comprehension para criar novas coleções de forma mais simples e expressiva. Vamos conhecer list comprehension, dictionary comprehension e set comprehension.

📋 List comprehension

List comprehension é uma forma compacta de criar uma lista a partir de outra sequência. Em vez de escrever várias linhas utilizando um for, podemos realizar a mesma tarefa em uma única expressão.

💡 Estrutura básica:

[expressão for item in sequência]

A expressão define o valor que será colocado na nova lista.

🔄 Forma tradicional

Imagine que queremos criar uma lista contendo o dobro dos números de 1 até 5. Podemos fazer isso utilizando um for tradicional:

lista_for.py
1
2
3
4
5
6
numeros = [1, 2, 3, 4, 5]
dobrados = []
for numero in numeros:
     dobrados.append( numero * 2)
print (dobrados)
Terminal
> [2, 4, 6, 8, 10]

⚡ Utilizando list comprehension

Podemos escrever a mesma lógica utilizando uma list comprehension:

list_comprehension.py
1
2
3
4
numeros = [1, 2, 3, 4, 5]
dobrados = [ numero * 2 for numero in numeros ]
print (dobrados)
Terminal
> [2, 4, 6, 8, 10]
💡 Para lembrar:

Pense na list comprehension como:

"Para cada item, faça alguma coisa e coloque o resultado em uma nova lista."

🔎 List comprehension com condição

Também podemos utilizar uma condição if dentro da compreensão. Por exemplo, podemos criar uma lista contendo somente os números pares.

pares.py
1
2
3
4
numeros = [1, 2, 3, 4, 5, 6]
pares = [ numero for numero in numeros if numero % 2 == 0 ]
print (pares)
Terminal
> [2, 4, 6]

📖 Dictionary comprehension

Assim como podemos criar listas utilizando compreensões, também podemos criar dicionários. Essa técnica é chamada de dictionary comprehension.

💡 Estrutura básica:

{chave: valor for item in sequência}

Por exemplo, podemos criar um dicionário onde cada número é uma chave e seu dobro é o valor.

dictionary_comprehension.py
1
2
3
4
numeros = [1, 2, 3, 4]
resultado = { numero: numero * 2 for numero in numeros }
print (resultado)
Terminal
> {1: 2, 2: 4, 3: 6, 4: 8}

Nesse exemplo:

  • O número é utilizado como chave.
  • O dobro do número é utilizado como valor.

🔎 Dictionary comprehension com condição

Também podemos utilizar condições para decidir quais elementos serão adicionados ao dicionário.

filtro_dicionario.py
1
2
3
4
numeros = [1, 2, 3, 4, 5, 6]
pares = { numero: numero * 2 for numero in numeros if numero % 2 == 0 }
print (pares)
Terminal
> {2: 4, 4: 8, 6: 12}

🔵 Set comprehension

Também podemos criar conjuntos utilizando compreensões. Essa técnica é chamada de set comprehension. O resultado será um set, que não mantém elementos duplicados.

💡 Estrutura básica:

{expressão for item in sequência}

A principal diferença visual é que utilizamos chaves { }, mas sem utilizar chave: valor como acontece nos dicionários.
set_comprehension.py
1
2
3
4
numeros = [1, 2, 3, 4, 5]
quadrados = { numero ** 2 for numero in numeros }
print (quadrados)
Terminal
> {1, 4, 9, 16, 25}

♻️ Removendo duplicados

Como conjuntos não armazenam elementos duplicados, podemos utilizar uma set comprehension para transformar e eliminar repetições ao mesmo tempo.

duplicados.py
1
2
3
4
5
numeros = [1, 2, 2, 3, 3, 3, 4]
unicos = { numero for numero in numeros }
print (unicos)
Terminal
> {1, 2, 3, 4}

🆚 Tipos de compreensão

As três principais formas de compreensão estudadas nesta aula trabalham com estruturas diferentes.

  • List comprehension — cria uma list.
  • Dictionary comprehension — cria um dict com chave: valor.
  • Set comprehension — cria um set e não mantém elementos duplicados.

🧪 Compreensões aplicadas a QA

Compreensões são bastante úteis em automação de testes porque permitem transformar e filtrar dados de forma compacta. Por exemplo, podemos extrair somente os nomes de usuários aprovados em uma lista de resultados.

resultados_qa.py
1
2
3
4
5
6
7
8
testes = [
     { "nome" : "Login" , "aprovado" : True },
     { "nome" : "Cadastro" , "aprovado" : False },
     { "nome" : "Logout" , "aprovado" : True }
]
aprovados = [ teste[ "nome" ] for teste in testes if teste[ "aprovado" ] ]
print (aprovados)
Terminal
> ['Login', 'Logout']
💡 Pense como QA:

Imagine uma lista contendo dezenas ou centenas de resultados de testes.

Compreensões podem ajudar a filtrar rapidamente os casos aprovados, extrair informações específicas ou transformar os dados para uma nova estrutura.

⚠️ Evitando exageros

Compreensões deixam o código compacto, mas isso não significa que devemos colocar toda a lógica possível dentro de uma única linha. Se uma compreensão ficar difícil de entender, utilizar um for tradicional pode ser uma escolha melhor.

💡 Boa prática:

Prefira código que seja fácil de ler e entender.

Uma linha curta não é necessariamente melhor do que algumas linhas bem organizadas.
