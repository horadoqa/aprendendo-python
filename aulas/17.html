Funções como objetos em Python

Em Python, funções também são objetos. Isso significa que podemos armazenar uma função em uma variável, passar uma função como argumento para outra função e criar pequenas funções utilizando lambda.

📦 Funções dentro de variáveis

Em Python, podemos criar uma função normalmente e depois armazená-la em uma variável. A variável passa a fazer referência à função e pode ser utilizada para executá-la.

💡 Para lembrar:

Funções podem ser tratadas como valores.

Assim como podemos armazenar um número ou uma string em uma variável, também podemos armazenar uma função.
variavel_funcao.py

def saudacao ():
     return "Olá, QA!"
mensagem = saudacao

Observe que utilizamos:

  • mensagem = saudacao para armazenar a função.
  • mensagem() para executar a função.
⚠️ Atenção:

saudacao e saudacao() não são a mesma coisa.

saudacao representa a própria função.

saudacao() executa a função e obtém seu resultado.

🔄 Funções como argumentos

Como funções são objetos, podemos passá-las como argumentos para outras funções. Isso permite criar funções mais flexíveis e reutilizáveis.

A função executar() recebe outra função como argumento. Nesse exemplo, passamos teste_login para ela.

💡 Pense como QA:

Imagine uma função responsável por executar um teste.

Em vez de criar uma função diferente para cada teste, podemos criar uma função genérica que recebe o teste que deverá ser executado.

⚡ lambda

lambda permite criar pequenas funções de forma rápida e compacta. Uma função lambda normalmente possui uma expressão simples e retorna automaticamente o resultado dessa expressão.

💡 Estrutura:

lambda parâmetros: expressão

A expressão depois dos dois pontos é o resultado retornado pela função.

💡 Quando usar lambda?

Lambdas são úteis quando precisamos de uma função pequena e simples que será utilizada em um determinado contexto.

Para regras mais complexas, uma função criada com def geralmente deixa o código mais claro.

🧪 Funções aplicadas a QA

Esse conceito pode ser útil em automação de testes quando queremos criar funções genéricas para executar diferentes validações. Podemos, por exemplo, criar uma função que recebe uma regra de validação como argumento.

💡 Pense como QA:

A função validar() não precisa saber qual regra será utilizada.

Ela recebe a regra como argumento e executa essa regra sobre o valor informado.

Isso permite reutilizar a mesma estrutura para diferentes validações.

🆚 def x lambda

Os dois recursos podem criar funções, mas são utilizados em situações diferentes.

  • def — ideal para funções maiores, reutilizáveis e com várias instruções.
  • lambda — ideal para funções pequenas e simples.
  • def — permite utilizar várias instruções e documentação.
  • lambda — possui uma única expressão.

🚀 Desafio

Crie uma função chamada aplicar_regra que receba dois argumentos:

  • Um valor chamado numero.
  • Uma função chamada regra.

A função deve executar a regra recebida e retornar o resultado. Depois, utilize uma lambda para verificar se um número é maior que 10.
