Parâmetros avançados em Python

Nesta aula, você vai aprender recursos que tornam as funções mais flexíveis e reutilizáveis. Vamos conhecer os valores padrão, os argumentos nomeados, *args e **kwargs.

⚙️ Valores padrão

Podemos definir um valor padrão para um parâmetro. Quando a função for chamada sem informar esse argumento, Python utilizará automaticamente o valor definido.

💡 Para lembrar:

Um valor padrão funciona como uma opção que a função já possui caso nenhuma outra seja informada.
padrao.py
1
2
3
4

8
def saudacao ( nome, "Visitante" ):
     print ( "Olá," , nome)
saudacao ( "Maria" )
saudacao ()
Terminal
> Olá, Maria
> Olá, Visitante

No primeiro exemplo, o argumento "Maria" substitui o valor padrão. Na segunda chamada, nenhum argumento foi informado e Python utilizou "Visitante".

🏷️ Argumentos nomeados

Argumentos nomeados permitem informar explicitamente qual parâmetro estamos preenchendo. Para isso, utilizamos o nome do parâmetro seguido por =.

nomeados.py

3

def cadastrar_usuario ( nome, idade):
     print ( nome, idade)
cadastrar_usuario ( idade=25, nome= "Ana" )
Terminal
> Ana 25
💡 Vantagem:

Com argumentos nomeados, podemos deixar o código mais claro e também alterar a ordem dos argumentos.

cadastrar_usuario(idade=25, nome="Ana")

Nesse caso, a ordem não precisa ser a mesma da definição da função.

📦 *args

O *args permite que uma função receba uma quantidade variável de argumentos posicionais. Os valores recebidos ficam disponíveis dentro da função como uma tupla.

args.py
1
2
3
4
5
6
7
8
def somar (*numeros):
     total = 0
     for numero in numeros:
         total += numero
     return total
print ( somar ( 10, 20, 30))
Terminal
> 60

Podemos passar dois, três, quatro ou quantos argumentos forem necessários. O *args reúne todos esses argumentos em uma tupla.

💡 Importante:

O nome args é uma convenção.

Tecnicamente, poderíamos utilizar outro nome, mas *args é o padrão mais utilizado pelos desenvolvedores Python.

🗂️ **kwargs

O **kwargs permite receber uma quantidade variável de argumentos nomeados. Esses valores ficam disponíveis dentro da função como um dicionário.

kwargs.py
1
2
3
4
5
6
7
8
def cadastrar_teste (**dados):
     print (dados)
cadastrar_teste (
     sistema= "Login" ,
     ambiente= "Homologação"
)
Terminal
> {'sistema': 'Login', 'ambiente': 'Homologação'}
💡 Para lembrar:

*args → vários argumentos posicionais.

**kwargs → vários argumentos nomeados.

*args normalmente resulta em uma tupla.

**kwargs normalmente resulta em um dicionário.

🔀 Combinando parâmetros

Podemos combinar parâmetros normais, valores padrão, *args e **kwargs em uma mesma função.

def executar_teste ( nome, ambiente= "Homologação" , *passos, **configuracoes):
     print ( "Teste:" , nome)
     print ( "Ambiente:" , ambiente)
     for passo in passos:
         print (passo)
     print (configuracoes)
⚠️ Atenção:

A combinação desses recursos deve respeitar a ordem esperada pela sintaxe do Python.

Não é necessário decorar todas as combinações agora. O mais importante nesta aula é entender o papel de cada recurso.

🧪 Aplicando em QA

Esses recursos podem ser bastante úteis em testes automatizados. Por exemplo, podemos criar uma função capaz de receber diferentes configurações de um teste sem precisar criar uma nova função para cada cenário.

🚀 Desafio

Crie uma função chamada registrar_teste que receba:

  • Um parâmetro obrigatório chamado nome.
  • Um parâmetro ambiente com valor padrão "Homologação".
  • Vários passos utilizando *args.
  • Informações adicionais utilizando **kwargs.

Depois, exiba todas essas informações utilizando print().

🧠 Resumo da aula

O que você aprendeu:

• Podemos definir valores padrão para parâmetros.
• Argumentos nomeados permitem informar explicitamente o parâmetro que receberá cada valor.
• *args recebe vários argumentos posicionais e os armazena em uma tupla.
• **kwargs recebe vários argumentos nomeados e os armazena em um dicionário.
• Esses recursos tornam as funções mais flexíveis e reutilizáveis.
• Em automação de testes, parâmetros avançados podem facilitar a criação de funções reutilizáveis para diferentes cenários.
