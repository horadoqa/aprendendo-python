Arquivos de texto em Python

Nesta aula, você vai aprender como trabalhar com arquivos de texto em Python. Vamos aprender como abrir, ler e escrever arquivos, além de conhecer a forma recomendada de trabalhar com arquivos utilizando with open().

📄 Trabalhando com arquivos

Arquivos de texto permitem armazenar informações que podem ser utilizadas posteriormente pelo programa.

Podemos utilizar arquivos para guardar nomes, configurações, resultados de testes, logs, informações de usuários e muitos outros dados.

💡 Para lembrar:

Uma variável guarda informações enquanto o programa está sendo executado.

Um arquivo pode guardar informações para serem utilizadas mesmo depois que o programa for encerrado.

📂 Abrindo arquivos

Para abrir um arquivo em Python, utilizamos a função open().

O primeiro argumento é o nome ou caminho do arquivo. O segundo argumento define o modo de abertura.

💡 Principais modos:

"r" — leitura do arquivo.
"w" — escrita no arquivo.
"a" — adicionar conteúdo ao final do arquivo.

📖 Lendo um arquivo

Para ler o conteúdo de um arquivo, podemos utilizar o método read().

leitura.py
1
2
3
4
5
6
arquivo = open ( "mensagem.txt" , "r" )
conteudo = arquivo. read ()
print (conteudo)
arquivo.close()

Nesse exemplo, o arquivo mensagem.txt é aberto no modo de leitura. Depois, read() obtém todo o conteúdo do arquivo.

⚠️ Atenção:

Quando utilizamos open() dessa maneira, precisamos fechar o arquivo com close() depois de terminar seu uso.

🔒 Fechando arquivos

O método close() fecha o arquivo que foi aberto.

fechar.py
1
2
3
4
arquivo = open ( "dados.txt" , "r" )
conteudo = arquivo. read ()
print (conteudo)
arquivo.close()

⭐ Usando with open()

Em Python, a forma mais recomendada de trabalhar com arquivos é utilizar with open().

Com essa estrutura, Python gerencia o fechamento do arquivo automaticamente depois que o bloco termina.

with_open.py
1
2
3
4
5
with open ( "mensagem.txt" , "r" ) as arquivo:
     conteudo = arquivo. read ()
     print (conteudo)
# O arquivo será fechado automaticamente
💡 Boa prática:

Prefira with open() em vez de abrir e fechar arquivos manualmente.

Isso torna o código mais seguro e evita esquecer de fechar o arquivo.

✏️ Escrevendo em arquivos

Para escrever conteúdo em um arquivo, podemos utilizar o modo "w".

O método write() permite adicionar texto ao arquivo.

escrita.py
1
2
3
4
5
with open ( "mensagem.txt" , "w" ) as arquivo:
     arquivo. write ( "Olá, Python!" )
# O arquivo será fechado # automaticamente
⚠️ Atenção ao modo "w":

O modo "w" escreve no arquivo e pode substituir o conteúdo que já existia.

Se você precisa preservar o conteúdo existente e adicionar novas informações, utilize o modo "a".

➕ Adicionando conteúdo

O modo "a" permite adicionar informações ao final do arquivo sem substituir o conteúdo existente.

adicionar.py
1
2
3
4
with open ( "log.txt" , "a" ) as arquivo:
     arquivo. write ( "Novo registro\n" )
# Conteúdo anterior é preservado

📚 Lendo linha por linha

Também podemos percorrer o arquivo utilizando um loop for. Essa abordagem é útil quando queremos trabalhar com cada linha separadamente.

linhas.py
1
2
3
4
5
with open ( "nomes.txt" , "r" ) as arquivo:
     for linha in arquivo:
         print (linha)
# Cada linha é processada # separadamente

📑 Lendo todas as linhas

O método readlines() retorna as linhas do arquivo em uma lista.

readlines.py
1
2
3
4
5
with open ( "nomes.txt" , "r" ) as arquivo:
     linhas = arquivo. readlines ()
     for linha in linhas:
         print (linha)

↩️ Quebra de linha

O caractere especial \n representa uma quebra de linha. Ele é muito utilizado quando estamos escrevendo várias linhas em um arquivo.

     arquivo. write ( "Maria\n" )
     arquivo. write ( "João\n" )
     arquivo. write ( "Ana\n" )

🧪 Exemplo prático

Podemos combinar entrada de dados com arquivos para criar pequenos programas úteis. Por exemplo, podemos solicitar o nome de uma pessoa e salvar a informação em um arquivo.

🧪 Arquivos no QA

Arquivos de texto também podem ser muito úteis em projetos de QA e automação.

Podemos utilizar arquivos para armazenar dados de teste, resultados, configurações e registros de execução.

💡 Exemplos no QA:

• Guardar dados utilizados em testes.
• Ler uma lista de usuários para uma automação.
• Registrar resultados de uma execução.
• Criar arquivos de log.
• Armazenar configurações simples.
• Ler cenários de teste de um arquivo.

🚀 Desafio

Crie um programa que solicite três nomes ao usuário e salve todos eles em um arquivo chamado nomes.txt.

🎯 Requisitos:

• Solicite três nomes utilizando input().
• Utilize with open().
• Abra o arquivo no modo "w".
• Salve cada nome em uma linha diferente.
• Ao final, mostre uma mensagem informando que os nomes foram salvos.
