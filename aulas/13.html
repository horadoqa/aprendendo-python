Estruturas de dados na prática

Nesta aula, vamos combinar as estruturas de dados que aprendemos até agora para criar estruturas mais completas e próximas de situações encontradas em programas reais. Vamos trabalhar com listas de dicionários, dicionários com listas e aprender a percorrer estruturas complexas utilizando loops.

📋 Listas de dicionários

Uma lista pode armazenar vários dicionários. Essa estrutura é muito útil quando temos vários registros que possuem as mesmas informações. Por exemplo, podemos representar uma lista de usuários, produtos, alunos ou chamados de QA.

💡 Pense assim:

A lista representa vários registros.

Cada dicionário representa um registro individual.

🔎 Acessando dados

Como temos uma lista contendo dicionários, utilizamos primeiro o índice da lista e depois a chave do dicionário. Por exemplo:

usuarios[0]["nome"]

usuarios[0] acessa o primeiro dicionário da lista.

["nome"] acessa o valor associado à chave "nome".

🔄 Percorrendo uma lista de dicionários

Podemos utilizar um loop for para percorrer todos os dicionários armazenados na lista. Dessa forma, conseguimos trabalhar com cada registro individualmente.

usuarios = [
{ "nome": "Ana", "idade": 25 },
{ "nome": "Carlos", "idade": 30 },
{ "nome": "Maria", "idade": 28 }
]
for usuario in usuarios:
     print( usuario[ "nome"])
Terminal
> Ana
> Carlos
> Maria
💡 Para lembrar:

O for percorre cada dicionário da lista.

A variável usuario representa o dicionário atual.

Assim podemos acessar seus valores usando usuario["nome"], usuario["idade"], etc.

🔍 Acessando listas dentro de dicionários

Para acessar um elemento de uma lista que está dentro de um dicionário, utilizamos a chave do dicionário e depois o índice da lista.

aluno = {
"nome": "Ana",
"notas": [8, 9, 10]
}
print( aluno[ "notas"])
print( aluno[ "notas"][0])
Terminal
> [8, 9, 10]
> 8
💡 Regra simples:

aluno["notas"] → acessa a lista.

aluno["notas"][0] → acessa o primeiro elemento da lista.

🧩 Estruturas mais complexas

Podemos combinar várias estruturas ao mesmo tempo. Por exemplo, podemos ter uma lista de alunos, onde cada aluno é um dicionário e possui uma lista de notas.

Estrutura:

Lista

Dicionário
↓

Lista de notas

💡 Por que isso é importante para QA?

Dados de testes, respostas de APIs, arquivos JSON, informações de usuários e resultados de automação frequentemente utilizam estruturas semelhantes.

Saber navegar por listas e dicionários é essencial para trabalhar com dados durante a automação de testes.

🚀 Desafio

Crie uma estrutura para armazenar informações de três testes automatizados. Cada teste deve possuir:

• nome do teste;
• status do teste;
• uma lista de etapas executadas.

🧠 Resumo da aula

O que você aprendeu:

• Uma lista pode armazenar vários dicionários.
• Um dicionário pode armazenar listas como valores.
• Podemos combinar listas e dicionários para representar estruturas complexas.
• lista[0]["chave"] acessa um valor dentro de um dicionário armazenado em uma lista.
• dicionario["chave"][0] acessa um elemento de uma lista armazenada em um dicionário.
• Podemos utilizar for para percorrer listas e dicionários.
• Loops aninhados permitem percorrer estruturas ainda mais complexas.
• Estruturas desse tipo são muito utilizadas para representar dados de aplicações, APIs e testes automatizados.
