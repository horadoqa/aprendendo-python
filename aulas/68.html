Introdução a redes neurais

Nesta aula, vamos conhecer um dos conceitos mais importantes da Inteligência Artificial moderna: as redes neurais artificiais. Vamos entender o que é um neurônio artificial, como as camadas são organizadas e como uma rede neural aprende durante o treinamento.

🎯 Objetivo da aula:

Entender a estrutura básica de uma rede neural e compreender, de forma prática, como ela transforma entradas em previsões.

🧠 O que é uma rede neural?

Uma rede neural artificial é um modelo computacional formado por unidades chamadas neurônios artificiais. Esses neurônios são organizados em camadas e trabalham juntos para encontrar padrões nos dados.

Uma estrutura simples pode ser representada assim:

Entrada → Camada oculta → Saída

📥 Dados
↓
🧠 Processamento
↓
📤 Previsão

Redes maiores podem possuir várias camadas ocultas e milhares ou até milhões de parâmetros.

🔵 1. Neurônio artificial

O neurônio é uma das unidades fundamentais de uma rede neural. Ele recebe valores de entrada, aplica pesos, adiciona um valor chamado bias e passa o resultado por uma função de ativação.

De forma simplificada:

saída = ativação( entrada × peso + bias )

Imagine que temos duas entradas:

entradas.py
1
2
x1 = 2
x2 = 3

Podemos ter um peso associado a cada entrada:

pesos.py
1
2
3
w1 = 0.5
w2 = 0.8
bias = 0.1

O neurônio pode calcular uma soma ponderada:

neuronio.py
1
2
3
soma = x1 * w1 + x2 * w2 + bias
print(soma)
Terminal
> 3.5

Esse cálculo é uma versão simplificada do que acontece dentro de um neurônio artificial.

💡 Os pesos são importantes.

Durante o treinamento, a rede neural ajusta seus pesos para melhorar suas previsões.

⚡ Função de ativação

Depois de calcular a soma ponderada, o neurônio pode aplicar uma função de ativação. Ela ajuda a rede neural a aprender relações não lineares nos dados.

Uma função bastante conhecida é a ReLU.

ReLU(x) = max(0, x)

Se o valor for negativo, retorna 0.
Se for positivo, mantém o valor.

🧱 2. Camadas

Os neurônios são organizados em camadas. Uma rede neural básica possui três tipos principais de camadas:

  • Camada de entrada
  • Camadas ocultas
  • Camada de saída
📥 Entrada
Recebe os dados.

↓

🧠 Camadas ocultas
Encontram padrões nos dados.

↓

📤 Saída
Produz o resultado.

📥 Camada de entrada

A camada de entrada recebe as características utilizadas pelo modelo.

Por exemplo, para prever o preço de uma casa, poderíamos utilizar:

  • Área.
  • Número de quartos.
  • Idade do imóvel.

Nesse caso, teríamos três valores de entrada.

[120, 3, 10]

Área = 120 m²
Quartos = 3
Idade = 10 anos

🧠 Camadas ocultas

As camadas ocultas ficam entre a entrada e a saída. São elas que realizam grande parte das transformações necessárias para encontrar padrões nos dados.

Uma rede poderia possuir, por exemplo:

Entrada → 1ª camada oculta → 2ª camada oculta → Saída

Uma rede com muitas camadas pode ser chamada de Deep Neural Network.

💡 Deep Learning

Deep Learning é uma área de Machine Learning que utiliza redes neurais com múltiplas camadas para aprender representações complexas dos dados.

📤 Camada de saída

A camada de saída produz o resultado final da rede. O formato dessa camada depende do problema.

Por exemplo, em uma classificação binária podemos ter uma saída indicando duas possibilidades:

0 → Não
1 → Sim

Já em um problema de classificação com três classes, poderíamos ter três valores de saída.

Classe A
Classe B
Classe C

🎓 3. Treinamento

Agora chegamos a uma das partes mais importantes: como uma rede neural aprende?

Durante o treinamento, a rede recebe exemplos e tenta produzir previsões. Essas previsões são comparadas com os valores corretos.

Dados → Rede neural → Previsão → Comparação com resposta correta → Ajuste dos pesos

📉 Função de perda

Para saber o quanto a previsão está distante do resultado esperado, utilizamos uma função de perda, também chamada de loss function.

De maneira simplificada:

Loss pequena = previsão próxima do esperado

Loss grande = previsão distante do esperado

Durante o treinamento, o objetivo normalmente é encontrar parâmetros que reduzam essa perda.

⚙️ Ajustando os pesos

Uma rede neural possui muitos parâmetros, principalmente pesos e biases. O treinamento procura ajustar esses valores para que a rede produza previsões melhores.

Antes do treinamento
Pesos → valores iniciais

↓

Durante o treinamento
Pesos são ajustados

↓

Depois do treinamento
Pesos aprendidos

🔄 Épocas

Uma época representa, de forma simplificada, uma passagem completa pelo conjunto de treinamento.

Podemos treinar uma rede por várias épocas:

↓

A cada época, os parâmetros podem ser ajustados para tentar reduzir a perda.

🐍 Criando uma rede neural com Python

Existem diversas bibliotecas para trabalhar com redes neurais. Nesta aula, vamos utilizar o scikit-learn para conhecer o conceito de forma simples.

from sklearn.neural_network import MLPClassifier
X = [
     [0, 0],
     [0, 1],
     [1, 0],
     [1, 1]
]
y = [0, 1, 1, 0]
modelo = MLPClassifier( hidden_layer_sizes=(4,), max_iter=1000)

Nesse exemplo, utilizamos uma rede neural do tipo MLP, que significa Multi-Layer Perceptron.

O parâmetro:

hidden_layer_sizes=(4,)

indica uma camada oculta contendo 4 neurônios.

🏋️ Treinando a rede

Assim como fizemos com outros modelos do scikit-learn, utilizamos fit().

🔄 O ciclo de uma rede neural

1️⃣ Entrada
A rede recebe os dados.

2️⃣ Forward pass
Os dados passam pelos neurônios e camadas até produzir uma previsão.

3️⃣ Cálculo da perda
A previsão é comparada com o resultado esperado.

4️⃣ Ajuste dos parâmetros
O algoritmo ajusta os parâmetros da rede para tentar melhorar o resultado.

5️⃣ Repetição
O processo é repetido durante o treinamento.

🔁 Backpropagation

Um dos conceitos fundamentais no treinamento de redes neurais é o backpropagation.

De maneira simplificada, ele permite calcular como os parâmetros da rede contribuíram para o erro e utilizar essa informação para ajustar os pesos.

Previsão → Erro → Backpropagation → Ajuste dos pesos

O algoritmo de otimização utiliza essas informações para atualizar os parâmetros da rede.

📉 Gradient Descent

Um conceito importante relacionado ao treinamento é o Gradient Descent.

A ideia simplificada é encontrar valores dos parâmetros que reduzam a função de perda.

Loss ↓
encontrar uma direção que reduza o erro
↓
atualizar os pesos
↓
repetir
