Trabalhando com arquivos CSV

Nesta aula, você vai aprender a trabalhar com arquivos CSV em Python. Vamos aprender como ler e escrever arquivos CSV utilizando o módulo csv da biblioteca padrão do Python.

📊 O que é CSV?

CSV significa Comma-Separated Values, ou "valores separados por vírgula".

É um formato de arquivo muito utilizado para armazenar dados organizados em linhas e colunas. Cada linha normalmente representa um registro e cada coluna representa uma informação desse registro.

💡 Exemplo:

Um arquivo chamado usuarios.csv pode conter:

nome,idade,cidade
Maria,25,Rio de Janeiro
João,30,São Paulo
Ana,28,Belo Horizonte

🐍 O módulo csv

Python possui um módulo chamado csv que facilita o trabalho com arquivos nesse formato.

Para utilizar o módulo, basta fazer sua importação:

importacao.py
1
2
import csv
💡 Para lembrar:

O módulo csv faz parte da biblioteca padrão do Python.

Isso significa que não precisamos instalar uma biblioteca externa para utilizá-lo.

📖 Lendo um arquivo CSV

Para ler um CSV, podemos utilizar csv.reader(). Ele permite percorrer as linhas do arquivo uma por uma.

import csv
with open ( "usuarios.csv" , "r" ) as arquivo:
     leitor = csv. reader (arquivo)

🗂️ Lendo CSV como dicionário

Quando o CSV possui um cabeçalho, podemos utilizar csv.DictReader(). Nesse caso, cada linha será representada como um dicionário, utilizando os nomes das colunas como chaves.

dict_reader.py

import csv
with open ( "usuarios.csv" , "r" ) as arquivo:
     leitor = csv. DictReader (arquivo)
     for usuario in leitor:
         print ( usuario[ "nome" ])
💡 Vantagem:

Com DictReader, podemos acessar os valores utilizando o nome da coluna em vez de trabalhar diretamente com posições.

Por exemplo: usuario["nome"].

✏️ Escrevendo um arquivo CSV

Para criar um CSV, podemos utilizar csv.writer(). O método writerow() escreve uma linha no arquivo.

import csv
with open ( "usuarios.csv" , "w" , newline= "" ) as arquivo:
     escritor = csv. writer (arquivo)
     escritor. writerow ([ "nome" , "idade" ])
     escritor. writerow ([ "Maria" , "25" ])
     escritor. writerow ([ "João" , "30" ])

📝 Escrevendo dicionários

Assim como podemos ler CSVs como dicionários, também podemos escrever dados nesse formato utilizando csv.DictWriter().

import csv
campos = [ "nome" , "idade" ]
with open ( "usuarios.csv" , "w" , newline= "" ) as arquivo:
     escritor = csv. DictWriter ( arquivo, fieldnames=campos)
     escritor. writeheader ()
     escritor. writerow ({ "nome" : "Maria" , "idade" : "25" })
     escritor. writerow ({ "nome" : "João" , "idade" : "30" })
💡 Para lembrar:

csv.reader() trabalha com linhas como listas.

csv.DictReader() trabalha com cada linha como um dicionário.

csv.writer() escreve listas no CSV.

csv.DictWriter() escreve dicionários no CSV.

🧪 CSV no QA

Arquivos CSV são bastante úteis em testes e automações porque permitem armazenar vários conjuntos de dados de forma organizada.

Por exemplo, podemos utilizar um CSV para armazenar diferentes usuários e utilizar cada linha como um cenário de teste.

dados_teste.py

import csv
with open ( "dados_teste.csv" , "r" ) as arquivo:
     leitor = csv. DictReader (arquivo)
     for usuario in leitor:
         nome = usuario[ "nome" ]
         print ( "Testando:" , nome)
🎯 Exemplo de uso em testes:

Um arquivo CSV pode conter dezenas ou centenas de usuários.

O programa pode percorrer cada linha e executar o mesmo teste utilizando diferentes dados.

Essa técnica é conhecida como teste orientado a dados.

🚀 Desafio

Crie um programa que leia um arquivo produtos.csv contendo as colunas produto e preco.

🎯 Requisitos:

• Utilize o módulo csv.
• Utilize DictReader.
• Percorra todos os produtos.
• Mostre o nome e o preço de cada produto.
• Ao final, informe quantos produtos foram encontrados.

🧠 Resumo da aula

O que você aprendeu:

• CSV é um formato utilizado para armazenar dados em linhas e colunas.
• O módulo csv faz parte da biblioteca padrão do Python.
• csv.reader() permite ler linhas de um CSV como listas.
• csv.DictReader() permite ler linhas como dicionários.
• csv.writer() permite escrever listas em arquivos CSV.
• csv.DictWriter() permite escrever dicionários em arquivos CSV.
• writerow() escreve uma linha.
• writeheader() escreve o cabeçalho de um CSV.
• O parâmetro newline="" é recomendado ao abrir CSVs para escrita.
• CSVs são muito úteis para armazenar dados de testes e criar automações orientadas a dados.
