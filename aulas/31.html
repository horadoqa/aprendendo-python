AULA 31

Construtores e estado do objeto

Nesta aula, você vai aprender como utilizar o construtor __init__() para inicializar objetos e como os atributos representam o estado de cada objeto.

🏗️ O que é um construtor?

Quando criamos um objeto a partir de uma classe, muitas vezes precisamos definir alguns valores iniciais. É nesse momento que o método __init__() entra em ação.

O __init__() é executado automaticamente sempre que um novo objeto da classe é criado.

💡 Para lembrar:

O __init__() é utilizado para preparar e inicializar o objeto no momento em que ele é criado.

💻 Criando um construtor

O construtor recebe self e pode receber outros parâmetros necessários para inicializar o objeto.

aluno.py

class Aluno:
     def __init__ ( self , nome):
         self .nome = nome
aluno = Aluno( "Maria" )
print ( aluno.nome)

▶ Resultado

Terminal
> Maria

🔎 O que acontece?

Quando executamos:

exemplo.py
1
aluno = Aluno( "Maria" )

O Python cria um novo objeto da classe Aluno e executa automaticamente o método __init__().

O valor "Maria" é recebido pelo parâmetro nome e armazenado no atributo self.nome.

🧠 Fluxo:

Criar objeto → executar __init__() → receber valores → inicializar atributos → objeto pronto para ser utilizado.

📦 Inicializando vários atributos

Um construtor pode receber vários parâmetros para definir diferentes características do objeto.

🔄 Estado do objeto

O estado de um objeto é formado pelos valores armazenados em seus atributos naquele momento.

Por exemplo, um produto pode começar com estoque = 10. Depois de uma venda, esse valor pode mudar para 9.

💡 Importante:

O objeto continua sendo o mesmo, mas seu estado mudou porque os valores de seus atributos foram alterados.

👥 Cada objeto possui seu próprio estado

Quando criamos vários objetos da mesma classe, cada um possui seus próprios valores de atributos.

class Cliente:
     def __init__ ( self , nome):
         self .nome = nome
cliente1 = Cliente( "Maria" )
cliente2 = Cliente( "João" )
print ( cliente1.nome)
print ( cliente2.nome)

▶ Resultado

Terminal
> Maria
> João

Mesmo sendo criados a partir da mesma classe, cliente1 e cliente2 possuem estados independentes.

🧠 Pense assim:

A classe define a estrutura.

Cada objeto recebe seus próprios valores.

Por isso, alterar o atributo de um objeto não altera automaticamente o atributo de outro objeto.

⚙️ Valores padrão no construtor

Também podemos definir valores padrão para determinados atributos. Assim, o objeto pode ser criado mesmo quando aquele valor não for informado.

🧪 Construtores no QA

Em automação de testes, construtores são muito úteis para preparar objetos com as informações necessárias para cada teste.

Por exemplo, podemos criar uma classe que represente um usuário de teste.

print ( teste.usuario)
print ( teste.senha)

🧠 Resumo da aula

O que você aprendeu:

• __init__() é executado quando um objeto é criado.
• O construtor é utilizado para inicializar atributos.
• self representa o próprio objeto.
• Um construtor pode receber vários parâmetros.
• Podemos utilizar valores padrão nos parâmetros.
• O estado do objeto é formado pelos valores atuais de seus atributos.
• Cada objeto possui seu próprio estado.
• Alterar um objeto não altera automaticamente os outros objetos.
• Construtores são muito úteis para preparar objetos utilizados em automação de testes.
