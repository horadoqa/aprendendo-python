Programação assíncrona

Nesta aula, vamos conhecer a programação assíncrona em Python. Vamos aprender como utilizar async, await e asyncio para executar tarefas que envolvem espera, como chamadas de rede, arquivos e outras operações de entrada e saída.

🎯 Objetivo da aula:

Entender como funciona a programação assíncrona e criar programas capazes de realizar várias tarefas de forma eficiente enquanto aguardam operações que demoram para terminar.

⚡ O que é programação assíncrona?

Em um programa tradicional, uma tarefa normalmente é executada e precisamos esperar que ela termine antes de continuar para a próxima.

Em determinadas situações, porém, uma tarefa passa grande parte do tempo apenas esperando. Por exemplo:

  • Esperar uma resposta de uma API.
  • Esperar uma conexão de rede.
  • Esperar um arquivo.
  • Esperar um banco de dados.
  • Esperar um temporizador.

Durante esse período de espera, podemos permitir que outras tarefas sejam executadas.

💡 Ideia principal:

Programação assíncrona permite que o programa aproveite períodos de espera para executar outras tarefas.

🐢 Código síncrono

Imagine duas tarefas que precisam esperar alguns segundos. Em um código síncrono, uma tarefa termina antes da outra começar.

sincronamente.py

import time
def tarefa(nome):
     print( f"{nome} começou" )
     time.sleep(2)
     print( f"{nome} terminou" )

Se chamarmos duas tarefas sequencialmente, precisamos esperar a primeira terminar para começar a segunda.

🚀 1. async

A palavra-chave async é utilizada para definir uma função assíncrona.

async.py
1
2
3
async def tarefa():
     print( "Executando tarefa" )
     return "Concluído"

Uma função definida com async def é uma coroutine function. Ao chamá-la, ela produz uma coroutine, que precisa ser executada pelo mecanismo assíncrono.

⚠️ Atenção:

Apenas chamar uma função assíncrona não significa que ela será executada imediatamente.

⏳ 2. await

A palavra-chave await indica que queremos aguardar o resultado de uma operação assíncrona.

Ela só pode ser utilizada dentro de uma função assíncrona.

await.py
1
2
3
4
5
import asyncio
async def tarefa():
     await asyncio.sleep(2)
     print( "Tarefa concluída" )
💡 Ideia:

await permite que a coroutine espere uma operação assíncrona sem bloquear a execução das outras tarefas que estão sendo gerenciadas pelo event loop.

🔄 3. asyncio

O módulo asyncio fornece ferramentas para trabalhar com programação assíncrona em Python.

Entre os recursos disponíveis estão:

  • Coroutines.
  • Tasks.
  • Event loop.
  • Timers.
  • Execução concorrente de operações assíncronas.

🔄 Event loop

O event loop é o mecanismo responsável por gerenciar a execução das tarefas assíncronas.

Coroutine
↓
Event Loop
↓
Executa uma tarefa
↓
Tarefa aguarda I/O
↓
Executa outra tarefa

Dessa maneira, o programa consegue utilizar melhor o tempo em que determinadas operações estão aguardando respostas.

🌐 Programação assíncrona e APIs

Um dos usos mais comuns da programação assíncrona é trabalhar com operações de rede.

Imagine um programa que precisa consultar várias APIs. Fazer essas requisições de maneira sequencial pode desperdiçar tempo enquanto o programa espera as respostas.

Exemplo:

API A → esperando resposta
API B → pode começar
API C → pode começar

O programa pode aproveitar o tempo de espera.

Bibliotecas assíncronas de HTTP podem ser utilizadas para esse tipo de aplicação.

🎯 Quando utilizar programação assíncrona?

A programação assíncrona é especialmente interessante quando o programa realiza muitas operações de entrada e saída.

  • Requisições HTTP.
  • APIs.
  • WebSockets.
  • Banco de dados assíncrono.
  • Sistemas que precisam lidar com muitas conexões.
  • Operações de I/O.
💡 Regra prática:

Asyncio é especialmente útil quando o programa passa bastante tempo esperando.

🚫 Quando async não é a melhor escolha?

Programação assíncrona não torna automaticamente qualquer código mais rápido.

Para tarefas fortemente dependentes de processamento da CPU, outras estratégias podem ser mais adequadas, como multiprocessing ou bibliotecas especializadas.

⚠️ Atenção:

Asyncio é excelente para concorrência baseada em operações de I/O, mas não substitui todas as formas de paralelismo.

🧠 Como pensar em async

async def → define uma coroutine

await → aguarda uma operação assíncrona

asyncio → gerencia a execução assíncrona

create_task() → agenda uma tarefa

gather() → aguarda várias tarefas
