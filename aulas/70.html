Projeto de IA

Nesta aula vamos reunir vários conceitos aprendidos durante o curso para construir um projeto completo de Inteligência Artificial utilizando Python e PyTorch.

Vamos passar por todas as etapas de um projeto: preparação dos dados, criação do modelo, treinamento, avaliação, previsões, salvamento e carregamento do modelo.

🎯 Objetivo da aula:

Criar um projeto de Inteligência Artificial do início ao fim, entendendo o fluxo completo de treinamento e utilização de um modelo.

🚀 O projeto

Nosso modelo será treinado para prever uma saída com base em uma entrada numérica. Para manter o projeto simples, vamos utilizar uma relação conhecida entre os dados:

y = 2x + 1

Embora esse exemplo seja simples, a estrutura utilizada aqui é parecida com a encontrada em projetos maiores de Machine Learning e Deep Learning.

📊 Dados → 🧹 Preparação → 🧠 Modelo → 🔄 Treinamento → 📈 Avaliação → 🔮 Previsão → 💾 Salvamento

📁 1. Organizando o projeto

Antes de começar a programar, é importante organizar os arquivos do projeto.

Uma estrutura simples pode ser:

projeto_ia/
├── dados.py
├── modelo.py
├── treinamento.py
├── previsao.py
├── modelo.pth
└── requirements.txt

Cada arquivo possui uma responsabilidade.

  • dados.py → preparação dos dados.
  • modelo.py → definição da rede neural.
  • treinamento.py → treinamento do modelo.
  • previsao.py → utilização do modelo.
  • modelo.pth → parâmetros salvos.
  • requirements.txt → dependências.

📈 7. Avaliando o modelo

Depois do treinamento, precisamos verificar se o modelo consegue trabalhar corretamente com dados que não foram utilizados durante o treinamento.

avaliacao.py
1
2
3
4
5
6
modelo.eval()
with torch.no_grad():
     previsao = modelo(X_teste)
     loss = criterio( previsao, y_teste)
     print(loss.item())
💡 Por que utilizar eval()?

O método eval() coloca o modelo em modo de avaliação.

Já o torch.no_grad() evita o cálculo desnecessário de gradientes durante a avaliação.

Depois de treinar um modelo, não precisamos necessariamente treiná-lo novamente toda vez que quisermos utilizá-lo.

import torch
import torch.nn as nn
X = torch.tensor([
     [1.0], [2.0], [3.0], [4.0]
])
y = torch.tensor([
     [3.0], [5.0], [7.0], [9.0]
])
modelo = nn.Linear(1, 1)
criterio = nn.MSELoss()
optimizer = torch.optim.Adam(
     modelo.parameters(), lr=0.01
)
for epoch in range(1000):
     previsao = modelo(X)
     loss = criterio( previsao, y)
     optimizer.zero_grad()
     loss.backward()
     optimizer.step()
torch.save( modelo.state_dict(), "modelo.pth")
modelo.eval()
entrada = torch.tensor([[6.0]])
with torch.no_grad():
     resultado = modelo(entrada)
     print(resultado)

✅ 13. Boas práticas

Projetos de Inteligência Artificial podem crescer rapidamente. Por isso, organização é tão importante quanto o próprio modelo.

  • Separe os dados do código do modelo.
  • Utilize ambientes virtuais.
  • Registre as dependências do projeto.
  • Separe treinamento e previsão.
  • Avalie o modelo utilizando dados que não foram usados no treinamento.
  • Salve os parâmetros do modelo.
  • Utilize nomes claros para arquivos e variáveis.
  • Documente as etapas importantes.
