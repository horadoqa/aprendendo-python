Conceitos de Machine Learning

Nesta aula, vamos conhecer os principais conceitos de Machine Learning, ou aprendizado de máquina. Vamos entender como os dados são utilizados para criar modelos capazes de encontrar padrões e realizar previsões.

🎯 Objetivo da aula:

Entender como um problema de Machine Learning é estruturado e conhecer os conceitos de dados, features, labels, treino e teste.

🤖 O que é Machine Learning?

Machine Learning é uma área da inteligência artificial que permite que sistemas aprendam padrões a partir de dados para realizar previsões ou tomar decisões.

Em vez de programarmos manualmente todas as regras, fornecemos exemplos para que um algoritmo consiga aprender uma relação entre os dados.

💡 Exemplo simples:

Imagine que queremos prever o preço de uma casa. Podemos fornecer ao modelo informações como tamanho, quantidade de quartos e localização, juntamente com o preço conhecido de várias casas. O modelo poderá aprender padrões presentes nesses exemplos e utilizar esse conhecimento para estimar o preço de uma nova casa.

📊 1. Dados

Os dados são a matéria-prima de um modelo de Machine Learning. Eles podem representar pessoas, produtos, vendas, imagens, transações, sensores ou praticamente qualquer outro tipo de informação.

Um conjunto de dados geralmente é organizado em linhas e colunas. Cada linha representa uma observação e cada coluna representa uma característica dessa observação.

🧩 2. Features

Features, também chamadas de características ou atributos, são as informações utilizadas pelo modelo para realizar uma previsão.

No exemplo das casas, algumas possíveis features seriam:

  • Tamanho da casa.
  • Quantidade de quartos.
  • Quantidade de banheiros.
  • Localização.
  • Idade do imóvel.
💡 Para lembrar:

Features = informações usadas pelo modelo para aprender e fazer previsões.

No exemplo de previsão de preços de casas, o label seria o preço da casa.

🧠 4. Treino

Durante o treinamento, o algoritmo recebe exemplos e procura padrões nos dados.

Em um problema supervisionado, normalmente temos as features e os respectivos labels. O modelo utiliza esses exemplos para aprender uma relação entre as entradas e os resultados.

💡 Pense assim:

É como ensinar um aluno utilizando vários exemplos. Quanto mais representativos forem os exemplos, maiores serão as chances de o modelo aprender padrões úteis.

🧪 5. Teste

Depois do treinamento, precisamos verificar se o modelo consegue funcionar bem com dados que ele ainda não viu. Para isso, separamos parte dos dados para realizar o teste.

O conjunto de teste serve para avaliar a capacidade de generalização do modelo.

✂️ Separando treino e teste

Uma prática comum é separar os dados em dois conjuntos:

  • Dados de treino — utilizados para ensinar o modelo.
  • Dados de teste — utilizados para avaliar o modelo.

from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test =
    train_test_split(
         features,
         labels,
         test_size=0.2
    )

Nesse exemplo, test_size=0.2 indica que aproximadamente 20% dos dados serão utilizados para teste e os demais para treinamento.

⚠️ Importante:

O conjunto de teste deve representar dados que o modelo não utilizou durante o aprendizado. Se utilizarmos os mesmos dados para treinar e avaliar o modelo, podemos obter uma avaliação enganosa.

🔄 Fluxo básico de Machine Learning

Podemos resumir o processo estudado nesta aula:

Dados → Features → Labels → Treino → Teste → Avaliação

Primeiro temos os dados. A partir deles identificamos as features e o label. Depois dividimos os dados em conjuntos de treino e teste. O modelo aprende utilizando os dados de treino e posteriormente é avaliado utilizando dados que ficaram separados.

🎯 Por que separar os dados?

Imagine que você está estudando para uma prova. Se você decorar exatamente as questões que estarão na prova, poderá ter um bom resultado sem realmente compreender o conteúdo.

Em Machine Learning acontece algo semelhante. O objetivo não é simplesmente memorizar os dados utilizados no treinamento, mas aprender padrões que possam ser aplicados a novos dados.

🧠 Conceito importante:

Um bom modelo deve conseguir generalizar o que aprendeu para dados que ainda não conhece.

🧠 Resumo da aula

O que você aprendeu:

• Dados são a matéria-prima do Machine Learning.
• Features são as características utilizadas como entrada do modelo.
• Labels representam os resultados que queremos prever.
• O treinamento é utilizado para que o modelo aprenda padrões.
• O teste é utilizado para avaliar o modelo com dados que não participaram do treinamento.
• A separação entre treino e teste ajuda a verificar a capacidade de generalização do modelo.
• train_test_split() pode ser utilizado para separar os dados.
