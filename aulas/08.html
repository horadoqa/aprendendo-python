Strings em Python

Nesta aula, você vai aprender a trabalhar com strings, que são utilizadas para representar textos em Python. Vamos conhecer como acessar caracteres através de índices, selecionar partes de um texto utilizando slicing e manipular strings através de diversos métodos. Também vamos aprender a utilizar split(), join(), replace() e strip().

🔤 O que são Strings?

Uma string é uma sequência de caracteres utilizada para representar textos. Em Python, podemos criar uma string utilizando aspas simples ou aspas duplas.

strings.py
1
2
3
4
5
6
nome = "Maria"
cidade = 'Petrópolis'
print(nome)
print(cidade)
💡 Para lembrar:

Strings são sequências de caracteres. Isso significa que cada letra, número, espaço ou símbolo ocupa uma posição dentro do texto.

🔢 Índices

Cada caractere de uma string possui uma posição, chamada de índice. Em Python, a contagem começa em 0. Portanto, o primeiro caractere está no índice 0, o segundo no índice 1 e assim por diante.

💡 Exemplo:

Na palavra "Python":

P → 0
y → 1
t → 2
h → 3
o → 4
n → 5
indices.py
1
2
3
4
5
6
7
palavra = "Python"
print(palavra[0])
print(palavra[1])
print(palavra[2])
print(palavra[5])

▶ Resultado

Terminal
> P
> y
> t
> n

🔙 Índices negativos

Python também permite acessar uma string começando pelo final. Para isso, utilizamos índices negativos. O índice -1 representa o último caractere, -2 representa o penúltimo e assim por diante.

indices_negativos.py
1
2
3
4
5
palavra = "Python"
print(palavra[-1])
print(palavra[-2])
Terminal
> n
> o

✂️ Slicing

O slicing permite selecionar uma parte de uma string. A sintaxe básica é:

texto[inicio:fim]

O índice inicial é incluído, mas o índice final não é incluído.

slicing.py
1
2
3
4
5
6
palavra = "Python"
print(palavra[0:3])
print(palavra[2:6])
print(palavra[:3])
print(palavra[3:])

▶ Resultado

Terminal
> Pyt
> thon
> Pyt
> hon

🛠️ Métodos de Strings

Python possui diversos métodos prontos para trabalhar com strings. Eles permitem transformar, pesquisar, dividir e limpar textos de maneira simples.

💡 Alguns métodos comuns:

upper() → transforma em letras maiúsculas.
lower() → transforma em letras minúsculas.
title() → coloca a primeira letra de cada palavra em maiúscula.
capitalize() → coloca a primeira letra da string em maiúscula.
metodos.py
1
2
3
4
5
6
7
8
texto = "python é incrível"
print( texto.upper())
print( texto.lower())
print( texto.title())
print( texto.capitalize())
# Métodos retornam uma nova string

✂️ split()

O método split() divide uma string em várias partes e retorna uma lista. Por padrão, a divisão acontece nos espaços.

split.py
1
2
3
4
5
frase = "Python é muito legal"
palavras = frase.split()
print(palavras)
Terminal
> ['Python', 'é', 'muito', 'legal']
💡 Podemos escolher o separador:

texto.split(",")

Nesse caso, a string será dividida sempre que uma vírgula for encontrada.

🔗 join()

O método join() faz o caminho contrário do split(). Ele junta vários elementos de uma lista em uma única string, utilizando um separador definido pelo programador.

join.py
1
2
3
4
5
palavras = [ "Python", "é", "legal" ]
frase = " ".join(palavras)
print(frase)
Terminal
> Python é legal
💡 split() x join()

split() divide uma string em partes.

join() junta várias strings em uma única string.

🔄 replace()

O método replace() permite substituir uma parte de uma string por outra. Ele é muito útil para corrigir, modificar ou padronizar textos.

replace.py
1
2
3
4
5
frase = "Eu gosto de Java"
frase = frase.replace( "Java", "Python")
print(frase)
Terminal
> Eu gosto de Python

🧹 strip()

O método strip() remove espaços em branco no início e no final de uma string. Ele é especialmente útil quando recebemos dados digitados pelo usuário.

strip.py
1
2
3
4
5
nome = " Maria "
nome = nome.strip()
print( f"Olá, {nome}!")
Terminal
> Olá, Maria!
💡 Outros métodos relacionados:

lstrip() remove espaços do início.
rstrip() remove espaços do final.
strip() remove espaços do início e do final.

🎮 Programa prático

Agora vamos juntar vários conceitos da aula. O programa recebe uma frase do usuário, remove espaços extras, substitui uma palavra e depois separa a frase em palavras.

tratamento.py

frase = input( "Digite uma frase: ")
frase = frase.strip()
frase = frase.replace( "Python", "PYTHON")

🚀 Desafio

Crie um programa que receba o nome completo de uma pessoa e faça as seguintes operações:

  • Remova espaços extras no início e no final utilizando strip().
  • Separe o nome em partes utilizando split().
  • Mostre o primeiro nome utilizando índice.
  • Mostre o último nome utilizando índice negativo.
  • Mostre o nome completo novamente utilizando join().
  • Substitua uma palavra do nome por outra utilizando replace().
💡 Dica:

Você pode começar com:

nome = input("Digite seu nome completo: ")

Depois, use os métodos aprendidos nesta aula para manipular o texto.
