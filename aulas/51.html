PostgreSQL

Nesta aula, você vai conhecer o PostgreSQL, um poderoso sistema de gerenciamento de banco de dados relacional, e aprender como conectar uma aplicação Python a um banco PostgreSQL. Também veremos conceitos importantes como conexão, cursor, comandos SQL e consultas.

💡 Para lembrar:

PostgreSQL é um banco de dados relacional.

Diferente do SQLite, normalmente utilizamos o PostgreSQL como um serviço de banco de dados, que pode ser executado localmente ou em um servidor.

🐘 O que é PostgreSQL?

O PostgreSQL é um sistema de gerenciamento de banco de dados relacional de código aberto. Ele utiliza SQL para trabalhar com dados organizados em tabelas e oferece recursos avançados para aplicações modernas.

Em uma aplicação, o PostgreSQL pode ser utilizado para armazenar informações como usuários, produtos, pedidos, pagamentos e resultados de testes.

🗂️ Banco de dados relacional

Em um banco relacional, os dados são organizados principalmente em tabelas. Cada tabela possui colunas que representam os atributos dos dados e linhas que representam os registros.

Exemplo:

Uma tabela usuarios pode possuir:

id → identificador do usuário
nome → nome do usuário
email → e-mail do usuário

📋 Criando uma tabela

Podemos utilizar SQL para criar tabelas no PostgreSQL.

🐍 Python + PostgreSQL

Para conectar Python ao PostgreSQL, precisamos utilizar um driver que permita que o programa converse com o banco de dados. Um dos drivers mais utilizados é o psycopg.

💡 Importante:

Diferente do SQLite, o PostgreSQL não faz parte da biblioteca padrão do Python.

Por isso, precisamos instalar um driver para realizar a comunicação entre Python e PostgreSQL.

📦 Instalando o driver

O pacote pode ser instalado utilizando o pip.

Terminal
1
pip install "psycopg[binary]"

🔌 Criando uma conexão

Depois de instalar o driver, podemos criar uma conexão com o PostgreSQL utilizando psycopg.connect().

import psycopg
conexao = psycopg.connect(
     "dbname=loja user=postgres password=1234 host=localhost port=5432"
)
print ( "Conectado!" )
conexao.close()
⚠️ Atenção:

Em aplicações reais, evite deixar senhas diretamente no código-fonte.

Mais adiante, veremos formas melhores de trabalhar com configurações e credenciais.

⚙️ Dados da conexão

Uma conexão com PostgreSQL normalmente precisa de informações como:

  • dbname — nome do banco.
  • user — usuário do banco.
  • password — senha.
  • host — endereço do servidor.
  • port — porta utilizada pelo PostgreSQL.
💡 Porta padrão:

A porta padrão normalmente utilizada pelo PostgreSQL é a 5432.

🖱️ Cursor

🛡️ Segurança:

Utilize parâmetros para enviar valores ao banco.

Evite montar SQL utilizando concatenação ou interpolação de strings com dados fornecidos pelo usuário.

Isso ajuda a reduzir riscos de SQL Injection.

Para consultar registros, utilizamos SELECT e podemos recuperar os resultados com fetchall().

Tenha atenção especial com comandos UPDATE e DELETE.

Uma consulta sem WHERE pode alterar ou remover vários registros de uma vez.

⚖️ PostgreSQL x SQLite

Os dois bancos são relacionais, mas possuem características diferentes.

  • SQLite — excelente para aplicações locais, estudos, protótipos e testes simples.
  • PostgreSQL — indicado para aplicações que precisam de um banco servidor mais completo e recursos avançados.
💡 Pense assim:

SQLite → banco local baseado em arquivo.

PostgreSQL → banco servidor para aplicações mais robustas.

🧪 PostgreSQL para QA

Para QA, saber trabalhar com PostgreSQL é muito útil para validar aplicações que dependem de dados persistentes.

Com Python podemos automatizar consultas, preparar dados de teste e validar resultados diretamente no banco.

Exemplo de fluxo:

1. Criar os dados necessários para o teste.

2. Executar a funcionalidade da aplicação.

3. Consultar o PostgreSQL.

4. Comparar o resultado obtido com o resultado esperado.

5. Limpar os dados utilizados no teste.
