Trabalhando com JSON em Python

Nesta aula, você vai aprender a trabalhar com arquivos e dados no formato JSON. Vamos conhecer o módulo json, aprender a utilizar json.load() e json.dump(), além de entender por que JSON é tão utilizado na comunicação entre aplicações e APIs.

🧩 O que é JSON?

JSON significa JavaScript Object Notation. Apesar do nome fazer referência ao JavaScript, JSON é um formato muito utilizado para trocar dados entre diferentes sistemas e linguagens de programação.

Os dados são organizados principalmente utilizando estruturas semelhantes a dicionários e listas do Python.

💡 Exemplo:

Um objeto JSON pode representar um usuário:

{
  "nome": "Maria",
  "idade": 25,
  "ativo": true
}

🐍 JSON e Python

Muitas estruturas do JSON possuem equivalentes diretos em Python.

  • Objeto JSON → dicionário em Python.
  • Array JSON → lista em Python.
  • String JSON → str em Python.
  • Número JSON → int ou float.
  • true / false → True / False.
  • null → None.
💡 Atenção:

JSON utiliza true, false e null.

Em Python, utilizamos True, False e None.

📖 Lendo JSON com json.load()

Quando temos um arquivo JSON salvo no computador, podemos utilizar json.load() para ler seu conteúdo e transformar os dados em estruturas Python.

Por exemplo, imagine que o arquivo usuario.json possui:

usuario.json
{
  "nome": "Maria",
  "idade": 25,
  "email": "maria@email.com"
}

Podemos ler esse arquivo com json.load():

🌐 APIs e JSON

JSON é um dos formatos mais utilizados para transportar dados entre aplicações. Por isso, ele aparece frequentemente quando trabalhamos com APIs.

Uma API pode receber uma requisição e devolver uma resposta contendo dados em JSON.

💡 Exemplo de resposta de uma API:

{
  "id": 101,
  "nome": "Maria",
  "email": "maria@email.com",
  "ativo": true
}

🧪 JSON em testes de API

Para quem trabalha com QA, JSON é especialmente importante porque APIs frequentemente utilizam esse formato para enviar e receber dados.
