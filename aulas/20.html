Módulos em Python

Nesta aula, você vai aprender como organizar seu código utilizando módulos. Vamos conhecer o comando import, aprender a criar nossos próprios módulos e entender como utilizar from ... import.

📦 O que são módulos?

Um módulo é, basicamente, um arquivo Python que contém código que pode ser reutilizado em outros arquivos. Esse código pode conter funções, variáveis, classes e outras estruturas.

💡 Para lembrar:

Pense em um módulo como uma "caixa de ferramentas".

Em vez de colocar todas as funções do seu projeto em um único arquivo, podemos separar cada conjunto de funcionalidades em módulos diferentes.

📥 import

O comando import permite utilizar um módulo dentro de outro arquivo Python. Python já possui diversos módulos disponíveis na biblioteca padrão.

Um exemplo bastante conhecido é o módulo math, que possui diversas funções matemáticas.

import.py

import math
resultado = math.sqrt(25)
print (resultado)
Terminal
> 5.0

Quando utilizamos import math, podemos acessar as funções do módulo utilizando o nome do módulo seguido de um ponto.

Exemplo:

math.sqrt(25)

Aqui:

math é o módulo.
sqrt() é uma função disponível nesse módulo.

🛠️ Outros módulos da biblioteca padrão

Python possui muitos módulos prontos que podemos utilizar nos nossos programas. Alguns exemplos são:

  • math — operações matemáticas.
  • random — geração de valores aleatórios.
  • datetime — datas e horários.
  • os — interação com recursos do sistema operacional.

🎲 Exemplo com random

O módulo random pode ser utilizado para gerar valores aleatórios.

random.py
1
2
3
4
5

import random
numero = random.randint(1, 10)
print (numero)
Terminal
> 7
💡 Observação:

Como o valor é aleatório, o resultado pode ser diferente a cada execução.

O exemplo acima pode retornar qualquer número inteiro entre 1 e 10.

🧱 Criando seus próprios módulos

Também podemos criar nossos próprios módulos. Basta criar um arquivo com extensão .py contendo as funções ou variáveis que queremos reutilizar.

Imagine que nosso projeto possui a seguinte estrutura:

projeto/
├── calculadora.py
└── main.py

O arquivo calculadora.py será nosso módulo.

calculadora.py
1
2
3
4

def somar (a, b):
     return a + b
def subtrair (a, b):
     return a - b
def multiplicar (a, b):
     return a * b

Agora podemos importar esse módulo em outro arquivo.

📤 Importando seu módulo

main.py
1
2
3
4
5
6
import calculadora
resultado = calculadora.somar(10, 5)
print (resultado)
Terminal
> 15

O Python procura o módulo no caminho disponível para importação. Quando encontra o arquivo calculadora.py, podemos acessar suas funções utilizando:

calculadora.somar(10, 5)

Dessa forma, mantemos o código da calculadora separado do código principal do programa.

🎯 from ... import

Também podemos importar diretamente uma função específica de um módulo utilizando from ... import.

main.py
1
2
3
4
5
6
from calculadora import somar
resultado = somar (10, 5)
print (resultado)
Terminal
> 15

Nesse caso, importamos somente a função somar. Por isso, podemos chamá-la diretamente sem escrever calculadora.somar().

📚 Importando várias funções

Podemos importar mais de uma função do mesmo módulo.

main.py
1
2
3
4
5
6
7
from calculadora import somar, subtrair
print ( somar (10, 5))

Terminal
> 15
> 5

🆚 import x from ... import

As duas formas permitem utilizar recursos de outros módulos, mas possuem uma diferença na maneira como acessamos esses recursos.

  • import calculadora
    Importa o módulo inteiro.

    Exemplo:
    calculadora.somar(10, 5)
  • from calculadora import somar
    Importa somente a função desejada.

    Exemplo:
    somar(10, 5)

🏷️ Apelidos com as

Podemos criar um apelido para um módulo utilizando as. Isso pode ser útil quando o nome do módulo é muito grande ou quando queremos deixar o código mais prático.

alias.py
1
2
3
4
5
import calculadora as calc
resultado = calc.somar(10, 5)
print (resultado)

🧪 Módulos na automação de QA

A organização em módulos é muito importante em projetos de automação de testes. Podemos separar responsabilidades diferentes em arquivos distintos.

💡 Exemplo de organização:

projeto_qa/
├── testes_login.py
├── testes_cadastro.py
├── validacoes.py
├── dados.py
└── main.py

Dessa forma, cada arquivo pode ter uma responsabilidade específica.

Por exemplo, podemos criar um módulo contendo funções de validação:

validacoes.py
1
2
3
4
5
6
def validar_status (status):
     return status == 200
def validar_resposta (resposta):
     return resposta != None

Depois, podemos reutilizar essas funções em nossos testes:

teste_api.py
1
2
3
4
5
6
from validacoes import validar_status
status = 200
if validar_status (status):
     print ( "Teste aprovado" )
Terminal
> Teste aprovado
💡 Pense como QA:

Imagine um projeto com centenas de testes.

Se todas as funções de apoio estiverem em um único arquivo gigante, a manutenção ficará complicada.

Separar funcionalidades em módulos ajuda a manter o projeto organizado, reutilizável e mais fácil de manter.

  • multiplicar(a, b)

🧠 Resumo da aula

O que você aprendeu:

• Um módulo é um arquivo Python que pode ser reutilizado em outros arquivos.
• import permite importar um módulo inteiro.
• Podemos acessar recursos do módulo utilizando modulo.funcao().
• Podemos criar nossos próprios módulos utilizando arquivos .py.
• from ... import permite importar funções ou outros recursos específicos.
• Podemos importar vários recursos de um mesmo módulo.
• as permite criar um apelido para um módulo ou recurso importado.
• A utilização de módulos ajuda a organizar, reutilizar e manter o código.
• Em projetos de QA, módulos podem separar validações, dados, testes e funções auxiliares.
