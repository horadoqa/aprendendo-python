Datas e horários em Python

Nesta aula, você vai aprender como trabalhar com datas e horários em Python. Vamos conhecer o módulo datetime, aprender a formatar datas e horários e calcular diferenças entre datas.

📅 O módulo datetime

Python possui o módulo datetime, que fornece recursos para trabalhar com datas, horários e intervalos de tempo.

Para utilizar o módulo, podemos importá-lo da seguinte maneira:

datetime.py
1
2
import datetime

🕐 Data e hora atuais

Podemos utilizar datetime.datetime.now() para obter a data e o horário atuais do computador.

agora.py
1
2
3
4
import datetime
agora = datetime.datetime. now ()
print (agora)

▶ Resultado

Terminal
> 2026-08-20 14:30:45.123456

O resultado depende da data e do horário em que o programa é executado.

💡 Para lembrar:

datetime.datetime.now() retorna um objeto contendo a data e o horário atuais.

📆 Trabalhando apenas com a data

Quando precisamos apenas da data atual, podemos utilizar date.today().

data.py
1
2
3
4
from datetime import date
hoje = date. today ()
print (hoje)
Terminal
> 2026-08-20

🗓️ Criando uma data

Também podemos criar uma data específica informando o ano, o mês e o dia.

criar_data.py
1
2
3
from datetime import date
aniversario = date( 2000, 5, 15)
print (aniversario)
💡 Estrutura:

date(ano, mês, dia)

Exemplo: date(2000, 5, 15) representa 15 de maio de 2000.

🎨 Formatação de datas

Por padrão, Python apresenta datas no formato YYYY-MM-DD. Podemos utilizar strftime() para escolher como queremos exibir a data.

formatar.py
1
2
3
4
5
from datetime import datetime
agora = datetime. now ()
data = agora. strftime ( "%d/%m/%Y" )
print (data)
Terminal
> 20/08/2026

🔤 Principais códigos de formatação

O método strftime() utiliza códigos especiais para representar diferentes partes da data e do horário.

  • %d — dia com dois dígitos.
  • %m — mês com dois dígitos.
  • %Y — ano com quatro dígitos.
  • %H — hora no formato de 24 horas.
  • %M — minutos.
  • %S — segundos.
💡 Exemplo:

"%d/%m/%Y %H:%M:%S"

Pode produzir:

20/08/2026 14:30:45

🔄 Convertendo texto em data

O método strptime() permite transformar um texto em um objeto de data e hora.

converter_data.py
1
2
3
4
5
from datetime import datetime
texto = "20/08/2026"
data = datetime. strptime ( texto, "%d/%m/%Y" )
print (data)
🧠 Para lembrar:

strftime() → transforma uma data em texto.

strptime() → transforma um texto em data.

⏱️ Diferença entre datas

Uma das funcionalidades mais úteis do datetime é calcular a diferença entre duas datas.

Quando subtraímos uma data de outra, Python retorna um objeto chamado timedelta.

diferenca.py
1
2
3
4
5
6
from datetime import date
inicio = date( 2026, 8, 1)
fim = date( 2026, 8, 20)
diferenca = fim - inicio
print ( diferenca.days)

▶ Resultado

Terminal
> 19

Nesse exemplo, existem 19 dias entre 01/08/2026 e 20/08/2026.

⏳ Trabalhando com timedelta

O objeto timedelta representa uma duração ou intervalo de tempo. Podemos utilizá-lo para adicionar ou remover períodos de uma data.

timedelta.py
1
2
3
4
5
6
from datetime import date, timedelta
hoje = date( 2026, 8, 20)
futuro = hoje + timedelta(days=7)
print (futuro)
Terminal
> 2026-08-27

🧪 Datas e horários no QA

Datas e horários aparecem com frequência em testes de software. Podemos utilizar o módulo datetime para validar prazos, datas de criação, vencimentos e duração de testes.

🎯 Exemplos no QA:

• Verificar se uma data de vencimento está correta.
• Calcular a duração de uma execução de teste.
• Validar timestamps retornados por uma API.
• Verificar se um cadastro foi criado na data esperada.
• Comparar datas de início e fim de processos.
• Criar dados de teste com datas relativas.

🔍 Validando um prazo

Podemos comparar uma data atual com uma data de vencimento para descobrir se um prazo já passou.

validar_prazo.py

2

hoje = date. today ()
vencimento = date( 2026, 12, 31)
if hoje <= vencimento:
     print ( "Prazo válido" )

Crie um programa que calcule quantos dias faltam para uma data importante.

🎯 Requisitos:

• Utilize o módulo datetime.
• Crie uma data futura.

• Calcule a diferença entre as duas datas.
