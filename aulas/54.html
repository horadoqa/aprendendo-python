Automação de arquivos

Nesta aula, vamos aprender como utilizar Python para automatizar tarefas relacionadas a arquivos e pastas. Vamos trabalhar com renomeação de arquivos, organização automática de diretórios e processamento de documentos.

🎯 Objetivo da aula:

Automatizar tarefas repetitivas envolvendo arquivos e diretórios, reduzindo o trabalho manual e tornando processos mais rápidos, organizados e confiáveis.

📁 Por que automatizar arquivos?

Imagine uma pasta contendo centenas de arquivos com nomes desorganizados. Fazer alterações manualmente pode consumir muito tempo e aumentar a possibilidade de erros.

Com Python, podemos criar scripts capazes de realizar essas tarefas automaticamente.

💡 Exemplos:

• Renomear centenas de arquivos.
• Separar arquivos por extensão.
• Criar pastas automaticamente.
• Mover arquivos para diretórios específicos.
• Processar documentos em lote.
• Localizar arquivos específicos.
• Gerar relatórios automaticamente.

🐍 Trabalhando com pathlib

O módulo pathlib fornece uma maneira moderna e prática de trabalhar com arquivos e diretórios em Python.

Com ele podemos criar caminhos, verificar se arquivos existem, listar diretórios, mover, renomear e excluir arquivos.

from pathlib import Path
pasta = Path( "arquivos" )
imagens = pasta / "imagens"
documentos = pasta / "documentos"
imagens.mkdir( exist_ok=True)
documentos.mkdir( exist_ok=True)
for arquivo in pasta.iterdir():
     if arquivo.is_file():
         if arquivo.suffix in [ ".jpg" , ".png" ]:
             arquivo.replace( imagens / arquivo.name)
         elif arquivo.suffix == ".pdf" :
             arquivo.replace( documentos / arquivo.name)

🔄 Renomeando arquivos em lote

Também podemos percorrer vários arquivos e aplicar uma regra de nomenclatura.

renomear_lote.py

from pathlib import Path
pasta = Path( "imagens" )
for numero, arquivo in enumerate (
     pasta.glob( "*.jpg" ), start=1):
     novo_nome = pasta / f"imagem_{numero}.jpg"
     arquivo.rename(novo_nome)
💡 Atenção ao processamento em lote:

Antes de executar scripts que alteram muitos arquivos, faça testes com uma cópia dos dados.

Uma regra incorreta pode renomear, mover ou modificar arquivos de maneira inesperada.

🛠️ Projeto prático — Organizador de downloads

Vamos imaginar uma pasta de downloads contendo diferentes tipos de arquivos. Podemos criar um script que identifica a extensão de cada arquivo e o move para a pasta adequada.

from pathlib import Path
origem = Path( "downloads" )
categorias = {
     ".pdf" : "documentos" ,
     ".txt" : "documentos" ,
     ".jpg" : "imagens" ,
     ".png" : "imagens"
}
for arquivo in origem.iterdir():
     if not arquivo.is_file():
         continue
     pasta_nome = categorias.get( arquivo.suffix)
     if pasta_nome:
         destino = origem / pasta_nome
         destino.mkdir( exist_ok=True)
         arquivo.replace( destino / arquivo.name)

🧪 Automação de arquivos para QA

A automação de arquivos pode ser muito útil em atividades de QA e automação de testes.

  • Organizar evidências de testes.
  • Renomear screenshots automaticamente.
  • Separar relatórios por projeto.
  • Processar arquivos de resultados.
  • Criar diretórios para cada execução.
  • Mover logs para pastas específicas.
  • Preparar arquivos para execução de testes.
💡 Exemplo para automação de testes:

Após executar uma suíte de testes, um script Python pode criar automaticamente uma pasta com a data da execução e armazenar nela os screenshots, logs e relatórios gerados.

✅ Boas práticas

  • Sempre valide se o arquivo existe antes de manipulá-lo.
  • Evite sobrescrever arquivos sem confirmação.
  • Utilize caminhos independentes do sistema operacional.
  • Faça testes utilizando cópias dos arquivos.
  • Registre as operações realizadas pelo script.
  • Trate possíveis erros durante a automação.
  • Mantenha scripts de automação simples e organizados.
