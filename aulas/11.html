Dicionários em Python

Nesta aula, você vai aprender a trabalhar com dicionários, uma estrutura de dados muito utilizada para armazenar informações organizadas em pares de chave e valor. Vamos aprender como criar dicionários, acessar informações, utilizar get(), visualizar chaves e valores com keys() e values(), percorrer os dados com items() e também alterar e remover informações.

🗂️ O que é um dicionário?

Um dicionário é uma estrutura que armazena informações no formato de chave e valor. Cada chave funciona como um identificador para encontrar o valor correspondente.

💡 Para lembrar:

Pense em um dicionário como uma ficha de cadastro.

nome → é a chave.
"Maria" → é o valor.

A estrutura fica assim:

chave → valor

📦 Criando um dicionário

Os dicionários são criados utilizando chaves {}. Cada informação possui uma chave e um valor separados por dois pontos :.

dicionarios.py
1
2
3
4
5
6
7
pessoa = {
     "nome": "Maria",
     "idade": 25,
     "profissao": "QA"
}
print(pessoa)

▶ Resultado

Terminal
> {'nome': 'Maria', 'idade': 25, 'profissao': 'QA'}

🔎 Acessando valores

Para acessar um valor de um dicionário, utilizamos sua chave entre colchetes.

acesso.py
1
2
3
4
5
6
pessoa = { "nome": "Maria", "idade": 25 }
print( pessoa[ "nome"])
print( pessoa[ "idade"])
Terminal
> Maria
> 25

🛡️ get()

O método get() permite acessar um valor utilizando sua chave. Uma vantagem é que podemos informar um valor padrão caso a chave não exista.

get.py
1
2
3
4
5
6
7
pessoa = {
     "nome": "Maria",
     "idade": 25
}
print( pessoa.get( "nome"))
print( pessoa.get( "cidade", "Não informado"))
Terminal
> Maria
> Não informado
💡 Diferença:

pessoa["cidade"] gera um erro se a chave não existir.

pessoa.get("cidade", "Não informado") permite definir um valor padrão.

🔑 keys()

O método keys() retorna todas as chaves existentes no dicionário.

keys.py
1
2
3
4
5
pessoa = { "nome": "Maria", "idade": 25, "profissao": "QA" }
print( pessoa.keys())
Terminal
> dict_keys(['nome', 'idade', 'profissao'])

💎 values()

O método values() retorna todos os valores armazenados no dicionário.

values.py
1
2
3
4
5
pessoa = { "nome": "Maria", "idade": 25, "profissao": "QA" }
print( pessoa.values())
Terminal
> dict_values(['Maria', 25, 'QA'])

🔄 items()

O método items() permite acessar as chaves e os valores ao mesmo tempo. Ele é muito utilizado junto com o for para percorrer um dicionário.

items.py
1
2
3
4
5
6
7
8
pessoa = {
     "nome": "Maria",
     "idade": 25,
     "profissao": "QA"
}
for chave, valor in pessoa.items():
     print( chave, valor)
Terminal
> nome Maria
> idade 25
> profissao QA

✏️ Alterando valores

Podemos alterar o valor de uma chave simplesmente atribuindo um novo valor a ela. Se a chave já existir, seu valor será atualizado.

alteracao.py
1
2
3
4
5
6
pessoa = { "nome": "Maria", "idade": 25 }
pessoa[ "idade"] = 26
print( pessoa[ "idade"])
Terminal
> 26

➕ Adicionando informações

Para adicionar uma nova informação, basta utilizar uma chave que ainda não existe.

adicionar.py
1

3
4

pessoa = { "nome": "Maria" }
pessoa[ "cidade"] = "Petrópolis"
print(pessoa)
Terminal
> {'nome': 'Maria', 'cidade': 'Petrópolis'}

🗑️ Removendo informações

Podemos remover informações de um dicionário utilizando o comando del. Também podemos utilizar pop() quando queremos remover uma chave e, ao mesmo tempo, obter o valor removido.

remocao.py
1
2
3
4
5
6
7
8
pessoa = {
     "nome": "Maria",
     "idade": 25,
     "cidade": "Petrópolis"
}
del pessoa[ "cidade"]
Terminal
> {'nome': 'Maria', 'idade': 25}

📤 Removendo com pop()

O método pop() remove uma chave do dicionário e retorna o valor associado a ela.

     "idade": 25
}

> 25

🚀 Desafio

Crie um programa para armazenar informações de um produto utilizando um dicionário.

O programa deve:

• Criar um dicionário com nome, preço, categoria e estoque.
• Exibir o nome do produto.
• Utilizar get() para consultar uma informação.
• Exibir todas as chaves utilizando keys().
• Exibir todos os valores utilizando values().
• Percorrer o dicionário utilizando items().
• Alterar o preço do produto.
• Adicionar uma nova informação ao dicionário.
• Remover uma informação utilizando pop() ou del.
