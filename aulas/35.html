Métodos especiais

Nesta aula, você vai aprender sobre os métodos especiais do Python, também conhecidos como dunder methods. Eles são métodos que possuem dois underscores no início e no final do nome, como __str__ e __len__.

Esses métodos permitem definir como nossos objetos devem se comportar quando utilizamos operações comuns do Python.

⚙️ O que são métodos especiais?

Métodos especiais são métodos que possuem nomes específicos reconhecidos pelo Python. Eles são chamados automaticamente em determinadas situações.

💡 Para lembrar:

Os métodos especiais normalmente possuem o formato:

__nome__

Por isso também são chamados de dunder methods (double underscore).

📝 __str__

O método __str__ define uma representação amigável do objeto. Ele é utilizado, por exemplo, quando passamos um objeto para print().

class Pessoa:
     def __init__ ( self , nome, idade):
         self .nome = nome
         self .idade = idade
     def __str__ ( self ):
         return f"{self.nome} - {self.idade} anos"
pessoa = Pessoa( "Maria" , 25)

Agora, quando utilizarmos print(pessoa), o Python utilizará automaticamente o método __str__.

▶ Resultado

🔎 __repr__

O método __repr__ define uma representação mais técnica do objeto. Ele é muito útil durante o desenvolvimento e debugging, pois deve ajudar a identificar o estado do objeto.

class Produto:
     def __init__ ( self , nome, preco):
         self .nome = nome
         self .preco = preco
     def __repr__ ( self ):
         return f"Produto(nome={self.nome!r}, preco={self.preco})"
produto = Produto( "Mouse" , 100)

O __repr__ normalmente apresenta informações úteis para quem está desenvolvendo ou investigando o código.

⚖️ __eq__

O método __eq__ define como dois objetos devem ser comparados utilizando o operador ==.

class Usuario:
     def __init__ ( self , email):
         self .email = email
     def __eq__ ( self , outro):
         return self .email == outro.email
usuario1 = Usuario( "qa@email.com" )
usuario2 = Usuario( "qa@email.com" )
print (usuario1 == usuario2)

▶ Resultado

Sem uma implementação personalizada de __eq__, objetos de uma classe normalmente são comparados pela identidade. Ao implementar esse método, podemos definir quais características determinam se dois objetos devem ser considerados iguais.

🛠️ Outros dunder methods

O Python possui muitos outros métodos especiais. Eles permitem personalizar o comportamento dos objetos em diferentes situações.

  • __init__ — inicializa o objeto.
  • __str__ — define a representação amigável do objeto.
  • __repr__ — define uma representação mais técnica do objeto.
  • __len__ — define o comportamento utilizado por len().
  • __eq__ — define a comparação com ==.
  • __lt__ — permite personalizar a comparação com <.
  • __gt__ — permite personalizar a comparação com >.
  • __add__ — define o comportamento do operador +.

➕ __add__

Também podemos personalizar operadores matemáticos. O método __add__, por exemplo, é utilizado quando usamos o operador +.

class Ponto:
     def __init__ ( self , valor):
         self .valor = valor
     def __add__ ( self , outro):
         return Ponto( self .valor + outro.valor)
resultado = Ponto(10) + Ponto(5)

Nesse exemplo, o operador + foi personalizado para somar os valores armazenados nos objetos.

🧪 Métodos especiais no QA

Os métodos especiais podem ser bastante úteis em projetos de automação e testes. Eles ajudam a criar objetos mais fáceis de utilizar, comparar e investigar durante a execução dos testes.

💡 Exemplo:

Um objeto que representa um usuário pode utilizar __str__ para exibir informações amigáveis no log.

Já o __eq__ pode permitir comparar dois usuários de acordo com um identificador, como e-mail ou ID.

• Crie o método __eq__ para comparar dois produtos pelo nome e preço.
