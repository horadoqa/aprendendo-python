Escopo de variáveis em Python

Nesta aula, você vai entender o conceito de escopo e descobrir onde uma variável pode ser utilizada dentro de um programa. Vamos estudar variáveis locais, variáveis globais, a palavra-chave global e algumas boas práticas para trabalhar com variáveis.

🔎 O que é escopo?

Escopo é a região do programa onde uma variável pode ser acessada. Em Python, uma variável criada dentro de uma função normalmente pertence ao escopo daquela função.

💡 Para lembrar:

Pense no escopo como uma área de acesso.

Uma variável criada dentro de uma função pode existir somente dentro daquela função.

Já uma variável criada fora de uma função pode ser acessada em diferentes partes do programa, dependendo do contexto.

📦 Variáveis locais

Uma variável local é criada dentro de uma função e pode ser utilizada normalmente apenas dentro daquela função.

🌎 Variáveis globais

Uma variável global é criada fora das funções. Ela pode ser acessada dentro de uma função, desde que não exista uma variável local com o mesmo nome.

Como sistema foi criada fora da função, ela é uma variável global. A função consegue ler o valor dessa variável.

🆚 Local x Global

Uma variável local e uma variável global podem possuir o mesmo nome. Nesse caso, dentro da função, a variável local terá prioridade.

🌐 A palavra-chave global

Por padrão, uma função consegue ler uma variável global, mas para alterar diretamente essa variável dentro da função precisamos utilizar a palavra-chave global.

⚠️ Cuidado com o uso de global:

Embora global seja uma ferramenta válida da linguagem, seu uso excessivo pode deixar o código mais difícil de entender e manter.

✅ Boas práticas

Ao trabalhar com escopo, algumas práticas ajudam a deixar o código mais organizado e previsível.

  • Prefira variáveis locais sempre que possível.
  • Evite criar muitas variáveis globais.
  • Evite utilizar global sem necessidade.
  • Prefira passar informações para funções por meio de parâmetros.
  • Utilize nomes de variáveis claros e significativos.
  • Faça cada função possuir uma responsabilidade bem definida.

⭐ Uma abordagem melhor

Em vez de modificar diretamente uma variável global, normalmente é melhor passar o valor para uma função e retornar o resultado.

Nesse exemplo, a função não precisa conhecer ou modificar diretamente uma variável global. Ela recebe um valor, realiza uma operação e devolve o novo valor. Essa abordagem costuma tornar o código mais fácil de testar, reutilizar e manter.

🧪 Escopo aplicado a QA

Em automação de testes, entender escopo é especialmente importante. Variáveis locais ajudam a manter dados específicos de cada teste isolados, enquanto variáveis globais podem criar dependências difíceis de identificar.

💡 Pense como QA:

Quanto mais independente for uma função, mais fácil será testá-la.

Uma função que recebe seus dados por parâmetros e retorna um resultado previsível tende a ser mais simples de validar e reutilizar.

🚀 Desafio

Crie uma função chamada calcular_resultado que receba uma nota por parâmetro. A função deve:

  • Receber a nota como parâmetro.
  • Criar uma variável local chamada resultado.
  • Armazenar em resultado o texto "Aprovado" quando a nota for maior ou igual a 7.
  • Armazenar "Reprovado" caso contrário.
  • Utilizar return para devolver o resultado.

Depois, chame a função e armazene o resultado em uma variável fora da função.

🧠 Resumo da aula

O que você aprendeu:

• Escopo define onde uma variável pode ser acessada.
• Variáveis criadas dentro de funções são normalmente locais.
• Variáveis criadas fora das funções podem ser globais.
• Uma função pode ler uma variável global.
• global permite alterar uma variável global dentro de uma função.
• O uso excessivo de variáveis globais pode dificultar a manutenção do código.
• É recomendado preferir parâmetros e return para compartilhar dados entre funções.
• Funções independentes são mais fáceis de testar e reutilizar em automação de QA.
