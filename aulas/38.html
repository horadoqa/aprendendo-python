Ambientes virtuais

Nesta aula, você vai aprender como criar e utilizar ambientes virtuais em projetos Python. Vamos conhecer o venv, entender o que são dependências e aprender a utilizar o pip para instalar e gerenciar pacotes.

Ambientes virtuais são muito importantes em projetos profissionais porque permitem que cada projeto tenha suas próprias dependências, evitando conflitos entre diferentes aplicações.

💡 Para lembrar:

Pense no ambiente virtual como uma "caixa isolada" para o seu projeto Python.

Cada projeto pode ter seus próprios pacotes e versões sem interferir nos outros projetos.

📦 O que são ambientes virtuais?

Um ambiente virtual é um ambiente isolado onde podemos instalar os pacotes necessários para um determinado projeto.

Imagine que você possui dois projetos:

  • Projeto A utiliza uma versão específica de uma biblioteca.
  • Projeto B utiliza outra versão da mesma biblioteca.

Sem isolamento, essas versões podem entrar em conflito. Com ambientes virtuais, cada projeto pode possuir suas próprias dependências.

✅ Vantagens:

• Isolamento entre projetos.
• Controle das versões das bibliotecas.
• Menor risco de conflitos.
• Projetos mais fáceis de reproduzir.
• Ambientes mais organizados.
• Maior facilidade para trabalhar em equipe.

🐍 Criando um ambiente com venv

O Python possui uma ferramenta própria para criação de ambientes virtuais chamada venv.

Primeiro, abra o terminal na pasta do seu projeto e execute:

Terminal
1
python -m venv .venv

Nesse comando:

  • python executa o interpretador Python.
  • -m venv solicita a execução do módulo venv.
  • .venv é o nome da pasta onde o ambiente virtual será criado.
💡 Dica:

O nome .venv é bastante utilizado por convenção, mas você pode escolher outro nome.

📁 Estrutura do projeto

Depois de criar o ambiente virtual, podemos ter uma estrutura semelhante a esta:

projeto
1
2
3
4
5
6
projeto/
├── .venv/
├── tests/
├── src/
├── requirements.txt
└── main.py

A pasta .venv contém o ambiente virtual do projeto. Normalmente ela não deve ser enviada para o repositório Git, pois pode ser recriada a partir das dependências do projeto.

▶ Ativando o ambiente virtual

Depois de criar o ambiente, precisamos ativá-lo para que os comandos Python e os pacotes instalados sejam executados dentro desse ambiente.

No Windows utilizando o PowerShell:

PowerShell
1
.\.venv\Scripts\Activate.ps1

No Windows utilizando o Prompt de Comando:

CMD
1
.venv\Scripts\activate

No Linux ou macOS:

Terminal
1
source .venv/bin/activate
💡 Como saber se foi ativado?

Normalmente o nome do ambiente aparece no início da linha do terminal:

(.venv) C:\projeto>

📥 O que é o pip?

O pip é o gerenciador de pacotes utilizado para instalar e gerenciar bibliotecas Python.

Por exemplo, podemos utilizar o pip para instalar uma biblioteca:

Terminal
1
python -m pip install requests

Nesse exemplo, estamos instalando a biblioteca requests no ambiente virtual ativo.

💡 Boa prática:

Prefira utilizar python -m pip em vez de simplesmente pip, pois isso ajuda a garantir que o pip utilizado pertence ao mesmo interpretador Python que você está utilizando.

🛠️ Principais comandos do pip

  • uninstall — remove um pacote.
  • list — mostra os pacotes instalados.
  • show — mostra informações sobre um pacote.
  • freeze — mostra os pacotes instalados com suas versões.
  • --upgrade — atualiza um pacote.

📋 O que são dependências?

Dependências são bibliotecas e pacotes externos necessários para que o projeto funcione corretamente.

Imagine um projeto de automação que utiliza:

  • pytest
  • requests
  • selenium

Essas bibliotecas podem ser consideradas dependências do projeto.

📄 requirements.txt

Uma prática muito comum em projetos Python é registrar as dependências em um arquivo chamado requirements.txt.

requirements.txt
1
2
3
pytest==8.4.1
requests==2.32.4
selenium==4.34.2

O arquivo registra quais pacotes o projeto precisa e, quando especificadas, as versões desejadas. Dessa forma, outra pessoa pode recriar o ambiente do projeto com mais facilidade.

💾 Gerando requirements.txt

Podemos utilizar o comando pip freeze para gerar uma lista das dependências instaladas.

Terminal
1
python -m pip freeze > requirements.txt

O operador > redireciona a saída do comando para o arquivo requirements.txt.

📥 Instalando as dependências

Quando recebemos um projeto que possui um arquivo requirements.txt, podemos instalar todas as dependências de uma vez.

Terminal
1
python -m pip install -r requirements.txt
💡 Fluxo comum:

1. Criar o ambiente virtual.
2. Ativar o ambiente.
3. Instalar as dependências.
4. Executar o projeto ou os testes.

🧪 Ambientes virtuais no QA

Em automação de testes, ambientes virtuais são especialmente importantes. Um projeto pode depender de várias bibliotecas, como frameworks de testes, ferramentas de automação de navegador, clientes HTTP e bibliotecas auxiliares.

Um projeto de automação pode ter, por exemplo:

requirements.txt
1
2
3
4
pytest
requests
selenium
pytest-html

Com o arquivo de dependências, outro profissional consegue configurar o ambiente necessário para executar os mesmos testes.

🚫 Não versionar o ambiente virtual

A pasta .venv normalmente não deve ser adicionada ao Git. Em seu lugar, versionamos os arquivos necessários para recriar o ambiente, como o requirements.txt.

.gitignore
1
2
3
.venv/
__pycache__/
*.pyc
💡 Boa prática:

O repositório deve conter o código e as informações necessárias para recriar o ambiente, e não a pasta completa do ambiente virtual.

⏹️ Desativando o ambiente

Quando terminarmos de trabalhar no projeto, podemos desativar o ambiente virtual utilizando:

Terminal
1
deactivate

🚀 Desafio

Crie um pequeno projeto Python chamado projeto_qa e prepare um ambiente virtual para ele.

🎯 Requisitos:

• Crie uma pasta para o projeto.
• Crie um ambiente virtual chamado .venv.
• Ative o ambiente virtual.
• Instale o pytest.
• Instale pelo menos mais uma biblioteca Python.
• Gere o arquivo requirements.txt.
• Crie um arquivo Python simples.
• Execute o arquivo dentro do ambiente virtual.
• Adicione .venv/ ao .gitignore.
• Desative o ambiente ao finalizar.

🧠 Resumo da aula

O que você aprendeu:

• Ambientes virtuais isolam as dependências de diferentes projetos.
• venv é uma ferramenta disponível no Python para criar ambientes virtuais.
• O ambiente pode ser ativado e desativado conforme a necessidade.
• pip é utilizado para instalar e gerenciar pacotes Python.
• pip list mostra os pacotes instalados.
• pip freeze permite registrar as dependências e versões instaladas.
• requirements.txt facilita a reprodução do ambiente do projeto.
• A pasta .venv normalmente deve ser adicionada ao .gitignore.
• Ambientes virtuais são fundamentais para manter projetos Python organizados e reproduzíveis.
