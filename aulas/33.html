Herança

Nesta aula, você vai aprender o conceito de herança na Programação Orientada a Objetos. Vamos entender como criar classes pai e classes filha e como utilizar super() para aproveitar comportamentos da classe pai.

🌳 O que é herança?

Herança é um recurso da Programação Orientada a Objetos que permite criar uma nova classe baseada em outra classe.

A classe que fornece os comportamentos é chamada de classe pai. A classe que herda esses comportamentos é chamada de classe filha.

💡 Para lembrar:

Pense em herança como uma relação entre classes.

A classe filha pode aproveitar atributos e métodos da classe pai e também pode adicionar seus próprios comportamentos.

Vamos começar criando uma classe chamada Animal. Ela terá um método que representa um comportamento comum aos animais.

🦸 O que é super()?

A função super() permite acessar métodos e comportamentos da classe pai a partir da classe filha.

Ela é muito utilizada quando queremos aproveitar o código da classe pai e adicionar novos comportamentos na classe filha.

💡 Para lembrar:

super() significa, de forma simples:

"Quero utilizar o comportamento da classe pai."

🏗️ Utilizando super() no __init__

Um dos usos mais comuns de super() acontece dentro do método __init__.

Dessa forma, a classe filha pode aproveitar o construtor da classe pai e depois adicionar seus próprios atributos.

class Pessoa:
     def __init__ ( self , nome):
         self .nome = nome
class Funcionario(Pessoa):
     def __init__ ( self , nome, cargo):
         super (). __init__ (nome)
         self .cargo = cargo
funcionario = Funcionario( "Maria" , "QA" )
print ( funcionario.nome)
print ( funcionario.cargo)

▶ Resultado

Terminal
> Maria
> QA

Nesse exemplo, Funcionario herda de Pessoa. O super().__init__(nome) chama o construtor da classe pai e inicializa o atributo nome.

🧪 Herança no QA

A herança pode ser muito útil em automação de testes para compartilhar comportamentos comuns entre diferentes classes.

Por exemplo, podemos criar uma classe base para testes que possua métodos comuns, como abrir uma página ou realizar login. Classes específicas podem herdar esses métodos e adicionar comportamentos próprios.

         self . abrir_sistema ()
         print ( "Executando teste de login" )

🧠 Resumo da aula

O que você aprendeu:

• Herança permite criar uma classe baseada em outra classe.
• A classe que fornece os comportamentos é a classe pai.
• A classe que herda os comportamentos é a classe filha.
• A classe filha pode utilizar métodos da classe pai.
• A classe filha também pode criar seus próprios atributos e métodos.
• super() permite acessar comportamentos da classe pai.
• super().__init__() é utilizado frequentemente para aproveitar o construtor da classe pai.
• super() também pode chamar métodos da classe pai.
• Herança ajuda a reutilizar código e organizar melhor aplicações orientadas a objetos.
