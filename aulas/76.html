Programação funcional

Nesta aula, vamos conhecer alguns conceitos importantes da programação funcional em Python. Vamos aprender como utilizar as funções map, filter e reduce para transformar, selecionar e combinar dados.

🎯 Objetivo da aula:

Aprender a utilizar map(), filter() e reduce(), entendendo quando cada uma dessas funções pode ser útil.

🧠 O que é programação funcional?

A programação funcional é um paradigma de programação que utiliza funções como uma das principais ferramentas para transformar e processar dados.

Python permite utilizar vários conceitos da programação funcional, como:

  • Funções como valores.
  • Funções de ordem superior.
  • map().
  • filter().
  • reduce().
  • Funções lambda.
💡 Ideia principal:

Em vez de escrever sempre loops manualmente, podemos utilizar funções para descrever transformações e operações sobre coleções de dados.

🔧 Funções como valores

Em Python, funções são objetos. Isso significa que podemos armazená-las em variáveis, passá-las como argumentos para outras funções e retorná-las como resultado.

funcoes.py
1
2
3
4

def dobro(numero):
     return numero * 2
funcao = dobro
print(funcao(5))
Terminal
> 10

A variável funcao passou a apontar para a função dobro. Por isso podemos chamá-la normalmente.

⚡ Funções lambda

As funções lambda são pequenas funções que normalmente são utilizadas quando precisamos de uma função simples e rápida.

lambda.py
1
2
dobro = lambda x: x * 2
print(dobro(5))
Terminal
> 10

🗺️ 1. map()

A função map() aplica uma função a cada elemento de um iterável.

Dados → Função → Novos dados

Por exemplo, podemos multiplicar todos os números de uma lista por 2.

map.py
1
2
3
4
numeros = [1, 2, 3, 4, 5]
resultado = map(
     lambda x: x * 2, numeros
)

O resultado de map() é um iterador. Podemos convertê-lo para uma lista:

map.py
1
2
resultado = list(resultado)
print(resultado)
Terminal
> [2, 4, 6, 8, 10]

🔄 map() com uma função própria

Não precisamos utilizar obrigatoriamente uma função lambda. Podemos passar uma função criada anteriormente.

map_funcao.py
1
2
3
4
5
6
def dobro(numero):
     return numero * 2
numeros = [1, 2, 3, 4]
resultado = list( map(dobro, numeros))
print(resultado)
Terminal
> [2, 4, 6, 8]
💡 Quando utilizar map()?

Quando queremos aplicar a mesma transformação a todos os elementos de uma coleção.

🔎 2. filter()

A função filter() é utilizada para selecionar elementos que atendem a uma determinada condição.

Dados → Condição → Elementos selecionados

Por exemplo, podemos selecionar apenas os números pares de uma lista.

filter.py
1
2
3
4
numeros = [1, 2, 3, 4, 5, 6]
resultado = filter(
     lambda x: x % 2 == 0, numeros
)

Assim como map(), o resultado de filter() é um iterador. Podemos convertê-lo para uma lista:

filter.py
1
2
resultado = list(resultado)
print(resultado)
Terminal
> [2, 4, 6]

🧩 filter() com função própria

filter_funcao.py
1
2
3
4
5
6
def maior_que_dez(numero):
     return numero > 10
numeros = [5, 10, 15, 20]
resultado = list( filter(
     maior_que_dez, numeros))
Terminal
> [15, 20]
💡 Quando utilizar filter()?

Quando queremos manter somente os elementos que atendem a uma condição.

➗ 3. reduce()

A função reduce() permite combinar os elementos de uma sequência progressivamente até obter um único resultado.

Diferentemente de map(), que transforma elementos, e filter(), que seleciona elementos, reduce() acumula os valores.

Valor 1 + Valor 2
↓
Resultado + Valor 3
↓
Resultado + Valor 4
↓
Resultado final

A função reduce() está disponível no módulo functools.

reduce.py
1
2
3
4
5
from functools import reduce
numeros = [1, 2, 3, 4, 5]
resultado = reduce(
     lambda a, b: a + b, numeros)

Podemos imprimir o resultado:

reduce.py
1
print(resultado)
Terminal
> 15

✖️ reduce() com multiplicação

Também podemos utilizar reduce() para multiplicar todos os valores.

multiplicacao.py
1
2
3
4
5
from functools import reduce
numeros = [1, 2, 3, 4]
resultado = reduce(
     lambda a, b: a * b, numeros)
Terminal
> 24
💡 Quando utilizar reduce()?

Quando precisamos transformar vários elementos em um único resultado acumulado.

🔗 Combinando map(), filter() e reduce()

Uma das possibilidades mais interessantes da programação funcional é combinar diferentes operações.

Por exemplo, podemos:

  1. Selecionar números pares.
  2. Multiplicar cada número por 2.
  3. Somar todos os resultados.
combinando.py
1
2
3
4
5
6
7
8
9
from functools import reduce
numeros = [1, 2, 3, 4, 5, 6]
pares = filter(
     lambda x: x % 2 == 0, numeros)
dobrados = map(
     lambda x: x * 2, pares)
resultado = reduce(
     lambda a, b: a + b, dobrados)
combinando.py
1
print(resultado)
Terminal
> 24
🔍 O que aconteceu?

Números originais:
[1, 2, 3, 4, 5, 6]

filter():
[2, 4, 6]

map():
[4, 8, 12]

reduce():
4 + 8 + 12 = 24

⚖️ map() vs filter() vs reduce()

🗺️ map()
Transforma elementos.

🔎 filter()
Seleciona elementos.

➕ reduce()
Combina elementos em um resultado.

🔄 Programação funcional vs for

Muitas operações realizadas com map() e filter() também podem ser feitas utilizando loops tradicionais.

Por exemplo, para dobrar os valores:

for.py
1
2
3
4
numeros = [1, 2, 3, 4]
resultado = []
for numero in numeros:
     resultado.append(numero * 2)

Com map(), podemos escrever:

map.py
1
resultado = list( map( lambda x: x * 2, numeros))
⚠️ Atenção:

Programação funcional não significa que map(), filter() e reduce() sejam sempre melhores. Em Python, muitas vezes uma compreensão de lista ou um for pode ser mais simples e legível.

🧮 map() com vários iteráveis

O map() também pode receber mais de um iterável. Nesse caso, a função precisa receber os valores correspondentes.

🔤 filter() com strings

O filter() também pode ser utilizado com textos. Podemos, por exemplo, selecionar apenas nomes com mais de cinco caracteres.

nomes.py
1
2
3
4
nomes = [ "Ana", "Carlos", "Mariana", "João" ]
resultado = list(filter(
     lambda nome: len(nome) > 5, nomes))
Terminal
> ['Carlos', 'Mariana']

🎯 Valor inicial no reduce()

O reduce() também pode receber um terceiro argumento: o valor inicial do acumulador.

reduce_inicial.py
1
2
3
4
5
from functools import reduce
numeros = [1, 2, 3]
resultado = reduce(
     lambda a, b: a + b, numeros, 10)
Terminal
> 16

O cálculo começa com o valor inicial 10:

10 + 1 + 2 + 3 = 16

⚠️ Cuidados com programação funcional

Embora essas funções sejam muito úteis, devemos priorizar a clareza do código.

Uma expressão funcional muito complexa pode ser mais difícil de entender do que um simples loop.

💡 Regra prática:

Prefira a solução que seja mais clara e fácil de manter.

Python valoriza bastante a legibilidade.

🏆 Exercício 4 — Combinando funções

  1. Utilize filter() para selecionar apenas os números pares.
