Web Scraping

Nesta aula, vamos aprender os conceitos básicos de Web Scraping utilizando Python. Web Scraping é o processo de coletar informações disponíveis em páginas da internet de forma automatizada. Vamos conhecer a biblioteca BeautifulSoup, aprender a localizar elementos HTML e extrair informações de uma página.

🎯 Objetivo da aula:

Aprender a acessar uma página HTML, interpretar sua estrutura e extrair informações específicas utilizando Python.

🌐 O que é Web Scraping?

Web Scraping é uma técnica utilizada para extrair informações de páginas da internet de maneira automatizada.

Em vez de copiar informações manualmente, podemos criar um programa que acessa uma página, identifica os elementos desejados e coleta seus dados.

💡 Exemplos de dados que podem ser extraídos:

• Títulos de páginas.
• Notícias.
• Preços publicados.
• Links.
• Nomes de produtos.
• Informações públicas.
• Resultados disponíveis em páginas HTML.

🍲 Conhecendo o BeautifulSoup

O BeautifulSoup é uma biblioteca Python que facilita a análise de documentos HTML e XML. Ela permite localizar elementos da página e acessar seus textos e atributos.

Para instalar a biblioteca, podemos utilizar:

1
pip install beautifulsoup4
💡 Atenção:

A biblioteca é instalada como beautifulsoup4, mas normalmente é importada no código como bs4.

Podemos criar um pequeno documento HTML e utilizar o BeautifulSoup para analisá-lo.

🔎 Localizando elementos

O método find() pode ser utilizado para localizar o primeiro elemento que corresponde a uma determinada tag.

from bs4 import BeautifulSoup
html = """ <h1>Python</h1> <p>Aprendendo Scraping</p> """
soup = BeautifulSoup( html, "html.parser" )
titulo = soup.find( "h1" )
print (titulo.text)

💡 Importante:

Uma requisição HTTP pode falhar. Por isso, programas reais devem verificar o status da resposta e tratar possíveis erros.

🛠️ Projeto prático — Coletor de títulos

Vamos criar um pequeno programa que recebe um documento HTML e coleta todos os títulos h2 encontrados na página.

from bs4 import BeautifulSoup
html = """ <h2>Python</h2> <h2>Automação</h2> <h2>QA</h2> """
soup = BeautifulSoup( html, "html.parser" )
titulos = soup.find_all( "h2" )
for titulo in titulos:
     texto = titulo.get_text( strip=True)
     print (texto)

⚠️ Cuidados e limites

Web Scraping não significa que podemos coletar qualquer informação de qualquer site sem restrições. Antes de automatizar uma coleta, é importante entender as regras e condições do site.

  • Verifique os termos de uso do site.
  • Respeite as políticas de acesso e o robots.txt quando aplicável.
  • Evite enviar uma quantidade excessiva de requisições.
  • Utilize intervalos entre requisições quando necessário.
  • Não tente contornar mecanismos de segurança ou autenticação.
  • Evite coletar dados pessoais ou informações sensíveis sem uma base legal adequada.
  • Prefira APIs oficiais quando elas estiverem disponíveis.
🛡️ Regra de ouro:

Scraping deve ser utilizado de forma responsável.

O fato de uma informação estar visível em uma página não significa que ela possa ser coletada, armazenada ou utilizada sem considerar as regras aplicáveis.

🧪 Web Scraping para QA

O Web Scraping também pode ser útil em atividades de QA. Podemos utilizar a técnica para coletar informações públicas e verificar se determinadas informações estão presentes em uma página.

  • Validar títulos de páginas.
  • Verificar links disponíveis.
  • Conferir informações públicas.
  • Comparar conteúdo esperado e encontrado.
  • Coletar dados para testes.
  • Criar verificações automatizadas de conteúdo.
💡 Exemplo:

Um teste automatizado pode acessar uma página pública, localizar o título principal e verificar se ele corresponde ao valor esperado.
