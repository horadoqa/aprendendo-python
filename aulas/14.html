Criando funções em Python

Nesta aula, você vai aprender a criar suas próprias funções utilizando def. Também vamos entender como utilizar parâmetros, argumentos e return para criar códigos mais organizados, reutilizáveis e fáceis de manter.

🧩 O que são funções?

Uma função é um bloco de código criado para realizar uma tarefa específica. Em vez de repetir o mesmo código várias vezes, podemos colocá-lo dentro de uma função e executá-lo sempre que necessário.

💡 Para lembrar:

Pense em uma função como uma pequena "máquina".

Você fornece informações para ela, ela executa uma tarefa e pode devolver um resultado.

🛠️ Criando uma função com def

Para criar uma função em Python, utilizamos a palavra-chave def, seguida do nome da função e dos parênteses.

funcao.py

def saudacao():
     print( "Olá, seja bem-vindo!" )

A palavra def indica que estamos criando uma função. O nome saudacao identifica a função. Os parênteses () podem receber parâmetros. O código indentado abaixo da função representa o que ela irá executar.

📥 Parâmetros

Parâmetros são informações que uma função espera receber. Eles ficam dentro dos parênteses na definição da função.

parametros.py

💡 Parâmetro:

O parâmetro é a variável definida na criação da função.

Neste exemplo:

nome é o parâmetro da função.

💡 Para diferenciar:

Parâmetro → aparece na definição da função.

Argumento → é o valor enviado quando chamamos a função.

def saudacao(nome):
nome → parâmetro.

saudacao("Ana")
"Ana" → argumento.

↩️ Retornando valores com return

O return permite que uma função devolva um resultado para o código que a chamou. Isso é diferente de simplesmente utilizar print().

💡 Importante:

print() apenas exibe uma informação.

return devolve um valor que pode ser armazenado em uma variável ou utilizado em outra operação.
return.py
1
2
3
4
5
6
7
def somar( numero1, numero2):
     return numero1 + numero2
resultado = somar (10, 20)
print (resultado)
Terminal
> 30

🆚 print() x return

Veja a diferença entre apenas mostrar um resultado e realmente devolver esse resultado.

def mostrar():
     print(10)
def devolver():
     return 10

Resumo:

print() → mostra o valor na tela.

return → devolve o valor para ser utilizado pelo programa.

🧪 Funções aplicadas a QA

Funções são muito importantes em automação de testes porque permitem transformar ações repetitivas em blocos reutilizáveis. Por exemplo, podemos criar uma função para verificar se um teste foi aprovado.

def verificar_status (status):
     if status == "Aprovado" :
         return True
     return False
resultado = verificar_status ( "Aprovado" )
print (resultado)
Terminal
> True
💡 Por que funções são importantes para QA?

Em automação de testes, várias ações podem ser repetidas.

Podemos criar funções para ações como:

• Fazer login.
• Validar um status.
• Calcular resultados.
• Criar dados de teste.
• Validar respostas de uma API.

Dessa forma, o código fica mais organizado, reutilizável e fácil de manter.
