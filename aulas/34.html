Polimorfismo

Nesta aula, você vai aprender o conceito de polimorfismo na Programação Orientada a Objetos. Vamos entender como diferentes objetos podem responder ao mesmo método de maneiras diferentes utilizando sobrescrita de métodos e o conceito de duck typing.

🔄 O que é polimorfismo?

A palavra polimorfismo significa "muitas formas". Na Programação Orientada a Objetos, o polimorfismo permite que objetos diferentes respondam ao mesmo método de maneiras diferentes.

Isso permite escrever códigos mais flexíveis, porque podemos trabalhar com diferentes objetos utilizando uma mesma interface ou comportamento.

💡 Para lembrar:

O mesmo método pode existir em diferentes classes, mas cada classe pode implementar esse método de uma maneira diferente.

🔁 Sobrescrita de métodos

A sobrescrita de métodos acontece quando uma classe filha cria um método com o mesmo nome de um método existente na classe pai.

Dessa forma, a classe filha pode fornecer seu próprio comportamento para aquele método.

🧩 Uma mesma interface

Podemos criar uma função que recebe um objeto e simplesmente chama o método emitir_som(). A função não precisa saber exatamente qual é o tipo do objeto.

🦆 Duck typing

Duck typing é uma característica importante da linguagem Python. A ideia pode ser resumida pela seguinte frase:

💡 "Se anda como um pato e faz quack como um pato, então podemos tratá-lo como um pato."

Em Python, não precisamos necessariamente verificar a classe de um objeto. O mais importante é saber se o objeto possui o comportamento que precisamos utilizar.

A função fazer_falar() não verifica se o objeto é um cachorro ou uma pessoa. Ela apenas espera que o objeto tenha um método chamado falar().

🧪 Polimorfismo no QA

O polimorfismo é bastante útil em automação de testes. Podemos, por exemplo, trabalhar com diferentes tipos de navegadores que possuem comportamentos semelhantes.

class Firefox:

         print ( "Abrindo Firefox" )
def iniciar_teste (navegador):
     navegador. abrir ()
iniciar_teste (Chrome())

A função iniciar_teste() pode receber diferentes objetos, desde que eles possuam o método abrir(). Essa flexibilidade é uma das grandes vantagens do polimorfismo e do duck typing em Python.

✅ Boas práticas

Ao utilizar polimorfismo:

• Prefira interfaces e comportamentos claros.
• Evite verificar o tipo do objeto sem necessidade.
• Aproveite o duck typing quando fizer sentido.
• Mantenha os métodos com responsabilidades bem definidas.
• Utilize herança quando existir uma relação realmente adequada entre as classes.

🚀 Desafio

Crie duas classes chamadas Pix e Cartao. As duas classes devem possuir um método chamado pagar(), mas cada uma deve apresentar uma mensagem diferente.

🎯 Requisitos:

• Crie a classe Pix.
• Crie a classe Cartao.
• Crie o método pagar() nas duas classes.
• Faça cada classe implementar o método de forma diferente.
• Crie uma função chamada realizar_pagamento().
• A função deve receber um objeto e chamar pagar().
• Teste a função passando objetos das duas classes.

🧠 Resumo da aula

O que você aprendeu:

• Polimorfismo significa que diferentes objetos podem responder ao mesmo método de formas diferentes.
• A sobrescrita permite que uma classe filha implemente novamente um método da classe pai.
• O mesmo método pode possuir comportamentos diferentes em classes diferentes.
• Duck typing permite trabalhar com objetos baseando-se em seus comportamentos.
• Em Python, muitas vezes importa mais o que o objeto consegue fazer do que o tipo exato dele.
• Polimorfismo ajuda a criar códigos mais flexíveis e reutilizáveis.
• Esses conceitos são muito úteis em automação de testes e projetos de QA.
