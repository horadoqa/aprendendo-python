Limpeza de dados

Nesta aula, vamos aprender a preparar e organizar dados utilizando o Pandas. Na prática, dados reais podem conter informações ausentes, registros duplicados e valores armazenados em formatos incorretos. Vamos aprender como identificar e tratar esses problemas antes de realizar análises.

🎯 Objetivo da aula:

Aprender a identificar problemas em conjuntos de dados e utilizar o Pandas para corrigir valores ausentes, remover duplicados e converter tipos de dados.

🧹 O que é limpeza de dados?

Limpeza de dados é o processo de identificar e corrigir problemas encontrados em um conjunto de informações. Antes de analisar os dados, é importante verificar se eles estão completos, consistentes e no formato esperado.

Alguns problemas comuns são:

  • Valores ausentes.
  • Registros duplicados.
  • Tipos de dados incorretos.
  • Valores inconsistentes.
  • Informações armazenadas no formato errado.
💡 Pense como QA:

Antes de validar um sistema, precisamos garantir que os dados utilizados nos testes estão corretos. Dados inconsistentes podem gerar resultados incorretos e dificultar a identificação de problemas reais.

❓ Valores ausentes

Valores ausentes acontecem quando uma informação não foi preenchida ou não está disponível. No Pandas, esses valores normalmente aparecem como NaN ou None.

Podemos utilizar isnull() para identificar valores ausentes.

ausentes.py
1
2
3
print (df.isnull())
print (df.isnull().sum())
💡 Para lembrar:

isnull() identifica quais valores estão ausentes.

Já isnull().sum() pode ser utilizado para contar quantos valores ausentes existem em cada coluna.

🗑️ Removendo valores ausentes

Quando um registro possui dados ausentes, uma das possibilidades é removê-lo utilizando dropna().

remover.py
1
2
df_limpo = df.dropna()
print (df_limpo)

Nesse caso, as linhas que possuem valores ausentes serão removidas.

⚠️ Atenção:

Nem sempre devemos simplesmente excluir os dados. Dependendo do contexto, podemos substituir o valor ausente por uma informação adequada.

✏️ Preenchendo valores ausentes

O método fillna() permite substituir valores ausentes por outro valor.

preencher.py
1
2
3
4
df[ "idade" ] = df[ "idade" ].fillna(0)
print (df)

Também podemos utilizar estatísticas para preencher determinados valores. Por exemplo, podemos substituir uma idade ausente pela média das idades existentes:

media.py
1
2
3
media = df[ "idade" ].mean()
df[ "idade" ] = df[ "idade" ].fillna(media)
print (df)

👥 Dados duplicados

Registros duplicados são linhas que aparecem mais de uma vez no conjunto de dados. Eles podem acontecer, por exemplo, quando um sistema importa o mesmo registro várias vezes.

Para identificar duplicados, podemos utilizar duplicated().

duplicados.py
1
2
3
duplicados = df.duplicated()
print (duplicados)

O método retorna True para registros que foram identificados como duplicados.

🧹 Removendo duplicados

Depois de identificar registros duplicados, podemos removê-los utilizando drop_duplicates().

limpar_duplicados.py
1
2
df_limpo = df.drop_duplicates()
print (df_limpo)
💡 Boa prática:

Antes de remover registros duplicados, verifique se eles realmente representam dados repetidos. Em alguns casos, duas linhas iguais podem ser informações válidas.

🔄 Conversão de tipos

Outro problema muito comum é quando uma coluna possui valores armazenados no tipo incorreto. Por exemplo, uma idade pode estar armazenada como texto quando deveria ser um número.

tipos.py
1
2
3
4
5
df = pd.DataFrame({
     "idade" : [ "25" , "30" , "22" ]
})
df[ "idade" ] = df[ "idade" ].astype(int)

O método astype() permite converter uma coluna para um tipo específico.

📌 Exemplos:

astype(int) → número inteiro.
astype(float) → número decimal.
astype(str) → texto.

🔢 Convertendo valores numéricos

Quando os dados podem conter valores inválidos, pd.to_numeric() pode ser uma opção mais segura. Com errors="coerce", valores que não podem ser convertidos se tornam ausentes.

conversao.py
1
2
3
4
df = pd.DataFrame({
     "nota" : [ "8.5" , "7.0" , "erro" ]
})
df[ "nota" ] = pd.to_numeric( df[ "nota" ], errors= "coerce" )
Terminal
> 0    8.5
> 1    7.0
> 2    NaN

🧼 Processo completo de limpeza

Em um projeto real, podemos combinar diferentes técnicas de limpeza em uma sequência.

import pandas as pd

df = df.drop_duplicates()
df[ "idade" ] = pd.to_numeric(
     df[ "idade" ], errors= "coerce"
)
df = df.dropna()
🧠 Ordem de pensamento:

1. Carregar os dados.
2. Verificar os tipos.
3. Identificar valores ausentes.
4. Identificar duplicados.
5. Corrigir os tipos incorretos.
6. Tratar ou remover valores ausentes.
7. Validar novamente os dados.

🧪 Limpeza de dados no QA

A limpeza de dados pode ser muito útil em atividades de QA e automação. Imagine que você recebeu um arquivo contendo resultados de testes automatizados.

Antes de gerar um relatório, podemos verificar:

  • Se existem testes duplicados.
  • Se existem resultados sem status.
  • Se o tempo de execução está realmente armazenado como número.
  • Se existem informações inválidas.
  • Se todos os registros estão no formato esperado.
🎯 Exemplo prático:

Se uma coluna de status deveria conter apenas "Passou" ou "Falhou", podemos limpar os dados antes de calcular a taxa de aprovação.

Isso evita que valores incorretos distorçam nossos resultados.
