Dataclasses

Nesta aula, você vai aprender a utilizar dataclasses, um recurso do Python que facilita a criação de classes utilizadas principalmente para armazenar dados. Vamos conhecer o decorator @dataclass e entender quando ele pode tornar nosso código mais simples e organizado.

📦 O que são Dataclasses?

Uma dataclass é uma classe criada para representar dados de forma simples. Quando criamos uma classe tradicional, muitas vezes precisamos escrever manualmente métodos como __init__, __repr__ e __eq__.

O módulo dataclasses permite que o Python gere automaticamente vários desses métodos para nós.

💡 Para lembrar:

Dataclasses são especialmente úteis quando a principal responsabilidade de uma classe é armazenar dados.

🏷️ @dataclass

Para transformar uma classe em uma dataclass, utilizamos o decorator @dataclass, disponível no módulo dataclasses.

usuario.py

from dataclasses import dataclass
@dataclass
class Usuario:
     nome: str
     idade: int
usuario = Usuario( "Maria" , 25)

Observe que não precisamos escrever o método __init__ manualmente. O decorator @dataclass faz isso automaticamente com base nos atributos declarados.

▶ Resultado

exemplo.py

> Usuario(nome='Maria', idade=25)
> Maria

A dataclass também fornece automaticamente uma representação útil do objeto. Isso acontece porque o Python gera métodos especiais, como __repr__, para a classe.

🏷️ Type hints

As dataclasses normalmente utilizam type hints para indicar o tipo esperado de cada atributo.

teste.py
1
2
3
4

6
7
from dataclasses import dataclass
@dataclass
class Teste:
     nome: str
     aprovado: bool
     tentativas: int

Nesse exemplo, cada atributo possui uma indicação do tipo esperado. Isso melhora a legibilidade e ajuda ferramentas de desenvolvimento a identificar possíveis problemas.

🎯 Valores padrão

Também podemos definir valores padrão para os atributos da dataclass.

Nesse caso, se o valor de aprovado não for informado, o Python utilizará False.

🤔 Quando utilizar Dataclasses?

Dataclasses são uma ótima escolha quando precisamos criar classes cuja principal função é representar e transportar dados.

✅ Bons casos de uso:

• Objetos que representam dados de usuários.
• Configurações de sistemas.
• Resultados de testes automatizados.
• Dados recebidos de APIs.
• Registros de produtos, pedidos ou clientes.
• Estruturas utilizadas para transportar informações entre diferentes partes do sistema.
⚠️ Quando talvez não seja necessário:

Se a classe possui muitos comportamentos complexos, regras de negócio ou uma lógica muito específica, uma classe tradicional pode ser mais adequada.

🧪 Dataclasses no QA

Dataclasses podem ser muito úteis em automação de testes para representar dados de teste de maneira organizada. Por exemplo, podemos criar uma estrutura para armazenar os dados necessários para testar um cadastro de usuário.

from dataclasses import dataclass
@dataclass
class DadosUsuario:
     nome: str
     email: str
     senha: str
dados = DadosUsuario( "Maria" , "maria@email.com" , "123456" )

Dessa forma, os dados utilizados pelos testes ficam agrupados em um objeto claro e organizado. Isso pode facilitar a manutenção de testes automatizados e a reutilização dos dados.

🚀 Desafio

Crie uma dataclass chamada Teste para representar um caso de teste automatizado.

🎯 Requisitos:

• Utilize o decorator @dataclass.
• Crie os atributos nome, categoria e aprovado.
• Utilize type hints nos atributos.
• Defina False como valor padrão para aprovado.
• Crie pelo menos dois objetos Teste.
• Exiba os objetos utilizando print().
• Compare os objetos utilizando ==.
