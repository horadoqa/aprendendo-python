Decorators

Nesta aula, vamos aprender um recurso muito poderoso do Python chamado Decorator. Decorators permitem adicionar comportamentos a funções e métodos sem precisar alterar diretamente o código original.

🎯 Objetivo da aula:

Entender como decorators funcionam, criar decorators personalizados e aprender como utilizar a sintaxe @decorator.

🎨 O que é um Decorator?

Um decorator é uma função que recebe outra função como argumento e retorna uma nova função com algum comportamento adicional.

Função original → Decorator → Nova função

Isso permite adicionar funcionalidades sem modificar diretamente a função original.

🧠 Funções também são objetos

def meu_decorator(funcao):

✨ A sintaxe @

O Python possui uma sintaxe especial para utilizar decorators.

Em vez de escrever:

com_at.py

💡 Importante:

A sintaxe:

@meu_decorator

é equivalente a aplicar o decorator manualmente depois da definição da função.

🔄 A função wrapper

A função interna normalmente recebe o nome wrapper. Ela é responsável por executar a função original adicionando o novo comportamento.

📋 Decorators com argumentos

E se a função original receber argumentos? Nesse caso, o wrapper precisa conseguir recebê-los também.

Podemos utilizar *args e **kwargs para aceitar diferentes tipos de argumentos.

↩️ Preservando o retorno

Um decorator não precisa apenas executar uma função. Ele também pode retornar o resultado produzido por ela.

def decorator(funcao):

🧩 functools.wraps

Quando usamos decorators, algumas informações da função original podem ser substituídas pela função wrapper. Para preservar essas informações, podemos utilizar functools.wraps.

wraps.py
1
2
3
4
5
6
7
8
9
from functools import wraps
def decorator(funcao):
     @wraps(funcao)
     def wrapper(*args, **kwargs):
         return funcao(*args, **kwargs)
     return wrapper
💡 Boa prática:

Ao criar decorators reais, normalmente utilizamos @wraps(funcao) para preservar metadados da função original.

🎛️ Decorators que recebem argumentos

Também podemos criar decorators configuráveis. Nesse caso, temos uma função externa que recebe os argumentos e retorna o decorator.

decorator_configuravel.py
1
2

8

def repetir(quantidade):
     def decorator(funcao):
         def wrapper():
             for _ in range(quantidade):
                 funcao()
         return wrapper
     return decorator
@repetir(3)

🚀 Onde decorators são utilizados?

Decorators aparecem frequentemente em projetos reais de Python.

  • Logging.
  • Medição de tempo.
  • Autenticação.
  • Controle de acesso.
  • Cache.
  • Validação.
  • Monitoramento.
  • APIs e frameworks web.
🌐 Exemplo:

Frameworks como Flask e FastAPI utilizam decorators para definir rotas e comportamentos das aplicações.
