Exceções em Python

Nesta aula, você vai aprender como lidar com erros durante a execução de um programa utilizando exceções. Vamos conhecer try, except, else e finally.

⚠️ O que são exceções?

Uma exceção acontece quando o Python encontra uma situação inesperada durante a execução do programa. Quando uma exceção não é tratada, o programa normalmente é interrompido e o Python exibe uma mensagem de erro.

Por exemplo, tentar dividir um número por zero gera uma exceção:

erro.py
1
2
3
4
numero = 10
divisor = 0
resultado = numero / divisor
print (resultado)
Terminal
! ZeroDivisionError
💡 Para lembrar:

Uma exceção não é necessariamente um problema que precisa ser ignorado.

Ela representa uma situação que o programa precisa saber como tratar.

🛡️ try

O bloco try é utilizado para colocar o código que pode gerar uma exceção.

Se uma exceção acontecer dentro do try, o Python poderá procurar um bloco except capaz de tratar aquele erro.

try.py
1
2
3
4
5
6
try :
     numero = 10 / 2
     print (numero)
# O código acima será executado
# normalmente se não houver erro

🚨 except

O bloco except define o que deve acontecer quando uma determinada exceção ocorre.

Podemos especificar qual tipo de exceção queremos tratar.

except.py
1
2
3
4
5
6
7
try :
     numero = 10 / 0
except ZeroDivisionError:
     print ( "Não é possível dividir por zero." )
Terminal
> Não é possível dividir por zero.
💡 Dica:

Sempre que possível, trate exceções específicas.

É melhor tratar ValueError, ZeroDivisionError ou FileNotFoundError de maneira específica do que capturar qualquer erro indiscriminadamente.

🔢 Exemplo com ValueError

O ValueError pode acontecer quando uma função recebe um valor do tipo correto, mas que não pode ser utilizado naquela operação.

Um exemplo comum acontece ao tentar converter um texto que não representa um número para int.

except ValueError:
     print ( "Valor inválido." )

✅ else

O bloco else é executado quando nenhuma exceção acontece dentro do try.

Ele é útil quando queremos executar uma ação somente se o código protegido pelo try funcionar corretamente.

     print ( "Conversão realizada!" )

🔒 finally

O bloco finally é executado independentemente de ter ocorrido uma exceção ou não.

Ele é muito utilizado para ações que precisam acontecer no final de uma operação, como liberar recursos ou realizar uma limpeza.

finally.py
1
2
3
4
5

try :
     numero = 10 / 2
except ZeroDivisionError:
     print ( "Erro na divisão." )
finally :
     print ( "Operação finalizada." )
Terminal
> Operação finalizada.
💡 Para lembrar:

O finally é executado mesmo quando ocorre uma exceção.

Ele é especialmente útil quando existe alguma tarefa que precisa ser finalizada independentemente do resultado da operação.

🧪 Exceções na automação de QA

O tratamento de exceções é muito importante em automação de testes. Durante a execução de um teste, podem acontecer situações inesperadas, como elementos que não foram encontrados, arquivos inexistentes, respostas inválidas ou problemas de comunicação.

💡 Pense como QA:

Imagine que um teste tenta abrir um arquivo com dados para execução.

Se o arquivo não existir, podemos tratar a exceção e apresentar uma mensagem mais clara em vez de simplesmente deixar o programa quebrar.
teste.py
1
2

4

try :
     arquivo = open ( "dados.csv" )
     print ( "Arquivo encontrado." )
except FileNotFoundError:
     print ( "Arquivo não encontrado." )
finally :
     print ( "Execução finalizada." )

✅ Boas práticas

O tratamento de exceções deve ajudar o programa, e não esconder problemas.

  • Trate exceções específicas sempre que possível.
  • Evite utilizar except vazio sem saber exatamente quais erros podem acontecer.
  • Utilize mensagens claras para facilitar a identificação do problema.
  • Utilize finally quando uma ação precisar acontecer independentemente do resultado.
  • Não use exceções para substituir condições normais de programação.

🧠 Resumo da aula

O que você aprendeu:

• Exceções representam situações inesperadas durante a execução do programa.
• try contém o código que pode gerar uma exceção.
• except permite tratar uma exceção específica.
• else é executado quando nenhuma exceção acontece.
• finally é executado independentemente de ocorrer uma exceção.
• ValueError pode acontecer quando um valor inválido é utilizado em uma operação.
• ZeroDivisionError acontece ao tentar dividir por zero.
• FileNotFoundError acontece quando um arquivo não é encontrado.
• O tratamento de exceções é importante para criar programas mais robustos.
