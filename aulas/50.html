SQLite

Nesta aula, você vai aprender como utilizar o SQLite para criar e trabalhar com um banco de dados local utilizando Python. Vamos aprender como criar uma conexão, criar tabelas, inserir dados, consultar registros e fechar corretamente a conexão com o banco.

💡 Para lembrar:

SQLite é um banco de dados relacional leve, local e baseado em arquivo.

Diferente de bancos que dependem de um servidor separado, o SQLite pode armazenar todo o banco em um único arquivo.

🗄️ O que é SQLite?

O SQLite é um banco de dados relacional que pode ser incorporado diretamente em aplicações. Ele utiliza arquivos para armazenar os dados, tornando sua utilização simples para projetos pequenos, testes, estudos e aplicações locais.

Exemplo:

Um banco chamado:
app.db

pode armazenar tabelas, registros e toda a estrutura necessária para a aplicação.

⭐ Por que utilizar SQLite?

  • Não exige um servidor de banco separado.
  • Os dados podem ficar armazenados em um único arquivo.
  • É simples de configurar.
  • É excelente para estudos e protótipos.
  • Python possui suporte ao SQLite através do módulo sqlite3.
💡 Importante:

SQLite não significa que o banco não seja relacional.

Ele suporta tabelas, relacionamentos, consultas SQL e diversas funcionalidades de bancos relacionais.

🔌 Conectando ao SQLite

O Python possui o módulo sqlite3, que permite trabalhar com bancos SQLite sem precisar instalar uma biblioteca externa.

conexao.py

import sqlite3
conexao = sqlite3.connect( "app.db" )
conexao.close()

O método connect() abre uma conexão com o banco. Se o arquivo ainda não existir, o SQLite poderá criá-lo.

🔄 Fluxo básico:

Python → sqlite3.connect() → Banco SQLite

Depois das operações:

conexao.close()

Essa parte da instrução evita que o programa tente criar novamente uma tabela que já existe.

💾 Salvando alterações

Operações que alteram os dados precisam ser confirmadas na transação. Para isso, podemos utilizar commit().

commit.py
1
2
3
4
5
6
import sqlite3
conexao = sqlite3.connect( "app.db" )
cursor = conexao.cursor()
cursor.execute( "CREATE TABLE IF NOT EXISTS produtos (id INTEGER PRIMARY KEY, nome TEXT)" )
conexao.commit()
conexao.close()

➕ Inserindo dados

Podemos utilizar SQL para inserir registros na tabela. Para valores fornecidos pelo programa, devemos utilizar parâmetros em vez de montar a consulta concatenando strings.

     "INSERT INTO produtos (nome) VALUES (?)" ,
     (nome,)
)

🛡️ Segurança:

O uso de parâmetros como ? ajuda a evitar problemas de SQL Injection.

Evite montar comandos SQL concatenando diretamente valores recebidos do usuário.

fetchall()

Retorna todos os registros encontrados pela consulta.

Também podemos utilizar fetchone() quando queremos obter apenas um registro por vez.
